# frontend/e2e/mcp-apps/phase-0

## Purpose

The `phase0-app-renderer-harness` is an isolated, provider-free Browser MCP Client and `ImMcpAppHostAdapter` lane. It uses local Chrome, a separate loopback sandbox origin, and the named backend fixture; it is not imported by the production SPA.

## Files

| File | Role |
|---|---|
| `ImMcpAppHostAdapter.tsx` | DEC-002 Host adapter that validates resource metadata and owns both iframe policy/lifecycle layers. |
| `phase0-app-renderer-harness.spec.ts` | P0 Browser protocol, one-call, origin/CSP/source, permission, teardown, and existing refresh-hydration assertions. |
| `phase0-app-renderer-harness.tsx` | Browser Client and Host adapter mount around an already completed tool result. |
| `sandbox-proxy.html` | Separate-origin proxy with revision-bound source/schema/policy validation and inner CSP construction. |
| `phase0_sandbox_server.mjs` | Local proxy server, server-owned Permissions-Policy response, and content-free evidence capture. |

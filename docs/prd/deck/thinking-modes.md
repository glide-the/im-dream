# 思维模式

## 背景与问题

[Notion 项目定位](https://app.notion.com/p/ink-and-memory-38f30b7547c3804cb8a0d1250a3b8ae2?source=copy_link#e4f30b7547c3837ab5d4815f3f1b0e37)将 Ink & Memory 定位于个人思维模式的整理，并以 Deck 承载思维模式。面对需求时，解决问题的路径、对应方案以及 Skills、MCP、Plugin 的组合构成不同的思维模式。

现有界面在同一对象上混用“卡组”“Deck”“Deck Name”，无法持续表达这一定位。本次统一名称与相关描述，不增加新的业务流程。

## 目标与边界

- 中文产品名称为“思维模式”；英文界面沿用 Deck。
- 统一导航、设置页签、入口列表、预览、维护弹窗、版本面板、Chat 选择器、Dream 信息入口和失败反馈。
- 延续已有名称、说明、Agent、插件引用、启停、草稿、内容版本及 Chat/Dream 入口。用户创建的名称、说明和服务端系统模板正文按原值显示，不改写历史数据。
- `DeckManager`、`Deck`、`deck_id`、`/api/decks`、`/story-workspace/decks`、`tab=deck`、翻译键和样式类名保持原样。
- 概念定义不代表已实现自动组合 Skills/MCP/Plugin、自动发现解决路径、多智能体协作或反馈统计。本次不实现这些能力，不修改 Runtime、权限、数据库或资源策略。

## 概念与规则

### 产品概念

**思维模式**是用户针对某类需求整理的思考方向、解决路径与执行方式。**Deck** 是现有实现中的承载形式，保存名称与说明，并关联 Agent、插件引用及相关运行配置。用户通过已有 Chat 或 Dream 入口使用这些配置。

Skills、MCP、Plugin 是概念定义中的能力组合要素。当前维护弹窗实际提供“概览、Agents、Claude 插件”，不因此新增 Skills 或 MCP 配置栏目，也不暗示它们已经与每个 Deck 建立自动绑定。

Agent 表示思维模式中已有的角色配置；内容版本记录配置内容；运行插件版本表示独立的运行事实。三者不作为“思维模式”的同义词。

### 中文文案规则

| 场景 | 中文用语 | 实现来源 |
| --- | --- | --- |
| 导航、工作台页签、首页栏目 | 思维模式 | `nav.decks`、`settings.sections.work`、`deck.home` |
| 用户与系统分组 | 可用思维模式、系统思维模式 | `deck.home` |
| 创建与维护 | 新建思维模式、思维模式名称、说明、思维模式信息 | `deck.defaults`、`deck.details` |
| 内容历史 | 思维模式内容版本、当前思维模式内容 | `deck.versions` |
| 对话选择与来源信息 | 不使用思维模式、思维模式信息 | `chat.deck` |
| 失败与恢复 | 思维模式加载失败、保存失败、无访问权限等具体反馈 | 原有翻译与 hook 失败分支 |

文案按当前语言分别渲染。中文界面不追加“Deck”作为重复标签，代码和接口说明可以使用 Deck。说明文字仅表达当前操作所需的信息，不加入协议、迁移或未来能力说明。

### 数据和状态

名称调整只发生在界面文案。Admin 继续负责业务持久化、主体权限和 schema capability 校验，Dream 继续通过现有公开生产接口消费数据；没有新的写入或迁移。

| 状态或事实 | 现有判定 | 用户操作与反馈 |
| --- | --- | --- |
| 用户思维模式可用 | `enabled=true`、版本 capability 存在、`deck_version>0`、已发布且无草稿变更 | 首页展示，可打开预览 |
| 系统思维模式 | `is_system` 或现行系统展示 policy | 默认展示，预览只读 |
| 停用、未发布或有草稿变更 | 现有服务端字段和前端投影 | 在工作台设置中管理 |
| 首次加载失败 | 原有读取失败 | 原有错误区显示“思维模式加载失败”，可重试 |
| 刷新失败 | 原有列表仍在组件状态中 | 保留列表与滚动位置，显示失败反馈 |
| 保存中、保存失败 | 原有 mutation/hook 状态 | 保留输入，显示失败；成功后刷新草稿事实 |
| 内容版本缺失或冲突 | 原有 capability / revision 校验 | 原有版本功能拒绝或刷新流程，不伪造成功 |
| 删除受相关对话阻止 | 原有服务端冲突与相关对话读取 | 查看相关对话，按原有规则处理 |

创建默认值仍由 `deck.defaults` 和既有图标、颜色配置提供；新建记录的默认名称改为“新建思维模式”。保存草稿、运行配置和内容版本的状态仍分别由现行接口报告，不新增 default、desired、effective 或 revision 的计算规则。

## 用户流程与页面骨架

现行实现为 `DeckManager` → `DeckLaunchPanel` / `DeckPreviewPanel` / `DeckSettingsPanel`。首页打开预览，用户思维模式可以从设置进入维护；创建成功后直接打开维护弹窗。普通表单保存、启停和栏目切换沿用现有操作，不新增确认。

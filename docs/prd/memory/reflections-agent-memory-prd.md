# Reflections L2 蒸馏与 L3 记忆回应

## 背景与问题

Reflections 已有 echoes、traits、patterns 三个分析视角、任务执行、报告保存和历史阅读。用户要求补充每次回顾到 `memory_distillation.md` 的转换及 Agent 读取，然后实现 L3 主题、策略和行为设置。分析视角不对应三个新的页面或 Tools。

方案比较与 Notion 正文证据见[设计判断](../../exec/reflections-l2-l3-design-review-20261015.md)。选择保存报告后自动转换、按需读取和一个设置栏目：省去提取确认页面，不把历史分析变成个人事实库，不让 L3 标签覆盖当前用户任务。

## 目标与边界

当前分支已实现：报告→L2 文件→同版本 L3 文件→当前任务判定→固定允许回应方式；用户在现有 Settings 的“记忆回应”中保存偏好。正式业务图和工具合同见[交互设计](../../design/memory/reflections-agent-memory-interaction-design.md)。[执行记录](../../exec/reflections-l2-l3-implementation-20261015.md)区分技术验证和真实验收。

正常 Admin 尚未提供 `dream.memory.v1`。代码实现不代表已在正常服务激活或通过真实模型验收。Admin Drizzle 是共享 schema 的唯一发布者；本轮 migration 只在明确命名隔离库执行，正常账户、订阅、账本和历史报告未改写。

不修改 AnalysisView、报告、时间轴、Deck 编辑器或原分析调度。Deck 保持分组职责，执行选择仍是 `{deckId, agentId}`。不新增个人事实 CRUD、标签编辑、自动心理诊断、阈值配置、人工提取确认或额外蒸馏模型调用。批准稿保留在[实现前版本](reflections-agent-memory-prd-pre-implementation-20261015-history.md)，更早错误方案也保留在[历史稿](reflections-agent-memory-prd-pre-l2-l3-20261015-history.md)。

## 概念与规则

- L1：原始日记与冻结分析来源，沿用已有合同。
- L2：用户主动回顾。保存报告后，后台按已完成栏目整理原有观察、证据、置信度和来源，去重后生成每报告独立的 `memory_distillation.md`。首版是来源整理，不另推断人物、任务、承诺或隐藏诉求。
- L3：从该 L2 版本的原有片段匹配固定四主题、十六标签，生成 `memory_theme.md`。这些仍是历史分析线索；没有匹配时记录 `[]`，不是失败。
- 策略：Host 绑定当前消息、Thread 和 owner，每轮重新读取设置并冻结快照；只有当前表达与选定历史来源匹配时才返回允许动作。混合主题不能确定单一回应时跳过。拒绝或否认分析在当前 Thread 内生效，不写入长期心理事实。

能力发布时刻之后的新报告自动发现；本轮不批量回填历史报告。无报告不生成 artifact；有报告但无有效观察为 empty。部分失败只整理实际完成栏目。来源变化不改写历史版本；修正从现有来源编辑与重新回顾开始，得到新报告。读取时缺少文件可恢复已经保存的规范字节，不重新分析。

## 用户入口与交互

唯一新增页面为 `/story-workspace/settings/behavior`，沿用 Settings 导航、搜索、桌面侧栏和窄屏外壳。总开关默认关闭；关闭时主题控件禁用但保留选择。开启后可改变每主题的启用及回应方式。

| 主题 | 默认方式 | 其他允许方式 |
| --- | --- | --- |
| 挫败 | 先回应感受，再提供帮助 | 直接帮助；任务不明确时询问需要哪种支持 |
| 防御 | 尊重距离，不追问心理话题 | 直接帮助；任务不明确时询问支持方式 |
| 压力 | 梳理优先顺序和下一步 | 先回应感受再帮助；任务不明确时询问支持方式 |
| 价值 | 结合目标解释选择与取舍 | 简短回应当前表达的需要；直接帮助 |

“恢复默认”只更新草稿。“保存”提交原 revision 与请求 ID，成功反馈“已保存，下一次回应使用此设置”。正在生成的回应保持原快照。相同设置不增加 revision，重复请求返回原结果。

读取失败提供重新读取，不显示虚构默认值覆盖已有配置。保存结果未知保留同账户原命令，重开可核实回执或重试同一次保存。冲突保留草稿、读取并展示其他位置保存的值，用户核对后保存或主动加载最新设置。没有重复确认弹窗。

报告阅读及分析发起继续使用原入口。Agent 用目录和读取工具展示持久记忆及其报告、时间、置信度和来源。现行页面没有按 report_id 直达某报告的 URL 合同：返回现有 Reflections 历史并按真实分析时间定位，不拼造深链；Notion 来源只使用现有摘要中保存的 URL。

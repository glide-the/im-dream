# docs/deploy/

## 架构概述
发布体系文档入口，区分本地直跑、Docker 容器和 Google Cloud Run 三类发布路径。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| README.md | 发布文档入口 | 三类发布路径分流、平台脚本入口、对比表、推荐目录大纲和维护规则 |
| overview.md | Cloud Run 部署主文档 | 现有完整云发布流程：存储初始化、环境变量配置、发版步骤、数据持久化说明 |
| data-sync.md | 云数据同步 | 本地与 GCS bucket 之间的数据上传、下载、备份和查看方法 |
| release-system-design.md | 发布体系设计稿 | 当前问题判断、三类发布方案、文档/脚本改造计划、验收清单 |
| ../../deploy/sync-data.sh | 同步脚本 | 上传本地 SQLite 数据到 GCS 并自动重启后端服务 |

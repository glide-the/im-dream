# 第二阶段：外部链接管理结构骨架

## 背景与问题

本阶段依据两张参考截图和[第一阶段需求稿](1_prd_draft.md)，将“设置 → 外部链接 → AI对话或笔记分类 → 单条管理”收敛为页面结构。
参考概览提供类别、数量、预览和箭头的层级；参考列表提供返回、平铺记录、细分隔线和右侧更多入口。
正式产品需求位于[外部链接管理](../../../../prd/sharing/external-links.md)，正文已同步本阶段骨架。

## 目标与边界

- 用户从既有设置栏目进入两类概览，在分类列表查看有效与已失效链接，并主动使单条链接失效。
- 本阶段交付Markdown结构稿，覆盖页面空间、菜单层级、展开区与滚动范围。
- 当前AI对话的链接分享仍为占位；笔记公开快照原型已有源码，归属管理及失效控制待实现；本稿中的页面和操作均为目标设计。
- 原内容删除的后续规则由正式PRD评审阶段收敛，本阶段骨架聚焦主动失效。
- 自动测试保持暂停；本阶段仅在保存后核对文件存在性。

## 概念与规则

### 结构判断

| 决策 | 判断依据 |
| --- | --- |
| 设置内两层内容 | 概览承接跨业务识别，分类名单承接单条操作。返回概览保留设置归属。 |
| 概览使用两个同级卡片 | 当前业务类型固定为AI对话和笔记，两卡对应有效数量与最近分享。 |
| 桌面表格、窄屏纵向信息行 | 两种尺寸保留标题、链接、时间、状态和更多入口；窄屏保持纵向阅读。 |
| 桌面/窄屏Web复用当前设置外壳 | 既有Web设置使用桌面侧栏与窄屏横向栏目；原生设置使用分类列表及返回栏。 |
| 单条菜单与行内展开 | 复制、打开、查看原内容及失效集中于当前行；详细信息和失败恢复紧邻操作对象。 |
| 完整标题持续可读 | 行菜单及链接信息展示创建分享时完整标题，原内容无法打开时仍可识别记录。 |
| 单一纵向内容区 | 表格、状态反馈和展开内容共同滚动，长地址换行，减少嵌套滚动。 |

页面沿用当前设置的纸面背景、文本、边框、悬停、焦点和危险操作语义样式。参考截图中的黑色画布、网站、表单与发布人列保留在原参考图中。
本阶段未增加批量、到期时间、链接搜索、密码或访客权限；设置原有搜索继续承担栏目导航。

## 页面模块结构

| 编号 | 模块 | 空间关系与主要内容 | 滚动与层级 |
| --- | --- | --- | --- |
| M1 | 设置外壳 | 桌面左侧原设置导航；窄屏Web顶部原搜索与横向栏目；原生设置分类页中的“外部链接”。 | 复用原设置导航的滚动行为；链接记录使用一个纵向内容区。 |
| M2 | 页面头部 | 概览展示“外部链接”与说明；分类列表展示“返回外部链接”及当前分类名。 | 沿设置内容区正常排列；返回入口位于列表和反馈上方。 |
| M3 | 两类概览 | AI对话、笔记两个同级卡片；类别、有效数量、最近分享标题与余量、右向箭头。 | 桌面同一行等宽，窄屏上下排列；整个卡片为进入分类的入口。 |
| M4 | 状态与刷新 | 当前分类标题下方左侧为“有效 / 已失效”，右侧为“刷新”。 | 与当前列表处于同一纵向内容区，切换状态只替换下方记录。 |
| M5 | 分类记录 | 桌面表格；窄屏纵向信息行。标题与链接占主要宽度，时间、状态及更多靠后排列。 | 表头、记录、行内反馈随内容区滚动；记录区不增加独立滚动条。 |
| M6 | 行更多菜单 | 锚定当前行右侧“⋯”；顶部展示完整标题，下方为对应状态的操作。 | 覆盖本行附近空间，自动向可见区域展开；点击外部或按Esc收起，焦点回到当前行。 |
| M7 | 行内展开区 | 承接链接信息、复制失败后的完整地址和单条操作反馈。 | 插入当前记录下方，推动后续记录下移；完整标题与地址换行，沿同一个内容区滚动。 |
| M8 | 整区反馈 | 承接首次加载、空列表、首次读取失败；刷新失败提示位于状态切换下方。 | 反馈占用原列表位置，设置导航、返回与状态切换继续可见。 |

### 呈现与布局规则

- 页面复用当前设置的内容宽度、留白、字体和深浅主题。卡片使用轻边框、简洁留白；表格使用细分隔线。
- 标题、数量与当前状态使用主文本层级；说明、日期与缩略地址使用次文本层级；边框、悬停、选中与焦点沿用设置语义样式。“使链接失效”沿用既有危险操作语义，保留完整文字。
- “有效”和“已失效”均显示文字；正在提交与结果待确认显示独立反馈，状态识别同时依靠文字和操作可用性。
- 桌面表格将更多按钮保留在最右侧。可用宽度不足时沿现有窄屏边界转为纵向信息行，记录内容保持纵向阅读。
- 有效记录中的地址缩略展示，复制使用完整地址；原地址在链接信息或手动复制区中完整换行。行菜单中的完整标题允许换行，已失效链接信息持续展示创建分享时的完整标题。
- 行菜单和行内展开区承接单条操作。本页的使链接失效、手动复制与查看链接信息均直接使用当前页面空间。
- 窄屏Web保留原设置栏目横向滚动；外部链接内容区使用单一纵向滚动。原生端按“设置分类 → 外部链接概览 → 分类列表”逐层进入。
- 当前设计全部属于待实现页面；图中数量、标题、地址及时间均为布局示例。

### 行内操作反馈与恢复位置

```text
当前记录：标题 / 链接 / 发布时间 / 最后确认状态 / ⋯
┌─────────────────────────────────────────────────┐
│ 复制失败：                                      │
│ 复制失败，请手动复制。                   [收起]  │
│ [可选中的完整地址，长地址在本区域内换行]         │
├─────────────────────────────────────────────────┤
│ 失效提交中：                                    │
│ 正在使链接失效…                                 │
│ 本条重复提交入口锁定；其余记录保持原有布局        │
├─────────────────────────────────────────────────┤
│ 失效明确失败：                                  │
│ 操作失败，请重试。                  [重试]      │
├─────────────────────────────────────────────────┤
│ 结果待确认：                                    │
│ 此链接的操作结果待确认。            [刷新状态]  │
│ 本条“使链接失效”“打开公开页面”暂不可用          │
└─────────────────────────────────────────────────┘
```

上述状态按当前结果展示对应一项，位置固定为该记录下方。点击使链接失效后收起菜单，行内反馈占用当前记录的展开区。复制失败展开区获得键盘焦点，读屏提示复制结果，收起后焦点回到原复制入口。

服务端确认成功后，该记录移出有效视图，显示“链接已失效”轻提示，并更新概览有效数量。最后一条有效记录移出时，原列表位置切换为有效空状态；“已失效”入口继续可见。结果待确认期间保留该记录与最后确认状态，新增反馈行明确本次操作的进度。

概览读取失败时，在两个卡片下方显示失败反馈与重试；卡片数量保留上次已确认值并标注更新失败，首次失败使用占位符。加载与首次失败状态使用独立提示，空状态仅在已确认记录数量为0时展示。窄屏沿同一空间关系将反馈文案与操作换行。

## Key Constraints
- 不依赖 `claude_agent/` 应用层（单向依赖：应用层 → kit 层）
- SDK 配置通过 `backend/.env` 中的直接 `ANTHROPIC_*` 变量解析；Mem0 仍优先读取 `INK_AGENT_MEM0_*`，旧 `PAWKEYLAND_MEM0_*` 仅作迁移兼容
- `AGENT_CWD` 控制工作区根目录，默认 `ink-agent-workspaces`
- `.editor/` 虚拟索引：Python `_pre_tool_use_hook` 拦截 Read 工具，从内存 `editor_state` 生成临时文件并重定向（CLI ≥2.1 `updatedInput` 格式）
- Pawkeyland 专属 MCP（necklace/mem0/animation）在 Ink & Memory 中不可用，不影响核心 Runner
- Runner SDK 失败路径先用 `logger.exception` 写后台堆栈，再通过 `on_error` 返回增强后的异常上下文

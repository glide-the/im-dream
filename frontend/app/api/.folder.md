Cookie presence always selects Browser mode; invalid/duplicate handles cannot use accompanying Bearer. Browser mutations require exact Origin and CSRF. Native Bearer requests have no ambient cookie; Python verifies Admin signature, scopes and principal. URLs carrying token/access_token are rejected. Upstream cookies and renewal credentials never reach Browser. SSE is forwarded without parsing or buffering; caller abort reaches upstream.

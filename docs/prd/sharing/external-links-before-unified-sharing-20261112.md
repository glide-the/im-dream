# 外部链接管理

## 背景与问题

用户将AI对话或笔记分享给应用外的人后，需要集中查看仍在公开的链接，并在需要时停止外部访问。
设置页面增加“外部链接”，承接这两类分享的查看、复制和失效操作。

用户提供的两张截图分别展示分类概览与分类列表。设计采用“分类概览 → 链接列表 → 行操作”的层级，并沿用Kastention现有设置外壳、纸面背景和深浅主题。

### 当前能力与本次设计

| 业务 | 当前能力 | 本设计范围与接入依赖 |
| --- | --- | --- |
| AI对话 | 已有图片生成、预览和下载；链接入口为占位项。 | 分类入口与管理规则纳入本设计；公开链接创建为接入依赖，具体分享方式另行设计。 |
| 笔记 | 已有正文快照链接与只读页面原型，分享快照独立保存。 | 登记分享归属、展示链接名单、主动失效；原内容删除后继续保留快照与管理记录。 |
| 设置 | 已有常规、订阅、工作台、记忆回应、AI模型、关于。 | 在现有设置导航中增加“外部链接”。 |

本文件定义目标产品行为，外部链接管理当前待实现。AI对话链接创建与阅读为后续接入依赖，本次管理设计仅定义其管理要求。
笔记当前分享规则见[笔记分享产品需求](../notes/sharing.md)，独立快照沿用原内容修改或删除后保留的规则。

## 目标与边界

1. 用户在设置中看到自己创建的AI对话与笔记外部链接。
2. 用户按类别查看有效链接和已失效记录，复制有效链接、打开公开页面或回到原内容。
3. 用户可对单条有效链接执行“使链接失效”，外部访问随服务端确认结果关闭。
4. 原内容删除后，分享快照及链接记录保留；用户仍可识别旧链接并主动使其失效。
5. 桌面和窄屏使用同一分类、字段、状态与操作规则。

本次范围为单条链接管理。批量操作、定时到期、密码、指定访客、访问统计和搜索引擎发布策略由后续需求定义。
原内容删除流程沿原业务处理；自动关闭关联链接的流程退出本次范围。
本设计的失效操作管理公开访问；已由访问者保存的图片、文字或文件保留在其设备中。

### 方案判断

| 方案 | 处理结果 |
| --- | --- |
| 仅在各业务的分享弹层管理 | 用户需要逐份找到原内容，跨AI对话与笔记查看的步骤较多。 |
| 设置中展示一个混合长列表 | 两类内容共用行结构，用户需要持续辨认业务类型。 |
| 设置中先展示两类概览，再进入分类列表 | 复用截图层级，分类数量与当前业务相符；选用此方案。 |
| 原内容删除时自动关闭全部关联链接 | 扩展原业务删除流程及分享规则，退出本次范围。 |
| 独立快照保留，由所有者管理单条链接 | 延续现有快照行为，覆盖用户要求的主动失效；选用此规则。 |

概览只展示“AI对话”和“笔记”。截图中的网站、公共表单、示例人物、示例日期和示例链接作为参考图片内容保留。

## 概念与规则

### 业务对象

| 对象 | 定义 |
| --- | --- |
| 外部链接 | 用户明确创建、供持有地址的人阅读一份分享内容的地址。 |
| 分享内容 | 创建链接时确定的独立快照；原内容后续编辑或删除均保留该份分享内容。AI对话的内容选择规则由其分享设计定义。 |
| 内容类型 | 固定为“AI对话”与“笔记”，用于概览、分类标题和链接归属。 |
| 原内容 | 用户日常使用的那一份AI对话或笔记；分享操作与失效操作均保留原内容。 |
| 链接所有者 | 创建该链接的用户。管理页面和管理操作按当前登录用户的归属提供。 |
| 有效链接 | 服务端当前允许通过该地址读取分享内容的链接。 |
| 已失效链接 | 服务端已关闭该地址的公开读取；原地址持续保持失效。 |
| 原内容已删除 | 原AI对话或笔记已确认删除；该提示与链接有效状态分别展示。 |

### 入口与导航

- 桌面沿现有“设置”侧边导航增加“外部链接”，与“AI模型”“记忆回应”等栏目同层。
- 窄屏Web保留设置顶部搜索与横向分类导航，增加“外部链接”栏目；原生端沿现有“更多 → 设置”进入分类页，增加“外部链接”条目。
- 设置搜索收录“外部链接、分享、公开链接、AI对话、笔记”等名称。
- 点击分类概览进入该类别列表；列表顶部返回“外部链接”概览。
- 返回概览后保留已确认的分类数量；重新进入列表时读取当前状态。
- 建议页面地址为`/story-workspace/settings/external-links`，当前未实现。现有设置入口为`/story-workspace/settings`。

### 分类概览

| 区域 | 展示与操作 |
| --- | --- |
| 标题 | “外部链接”。 |
| 说明 | “管理已分享的AI对话和笔记”。 |
| AI对话分组 | 名称“AI对话”、有效链接数量、最近创建的有效分享标题及剩余数量、进入箭头。 |
| 笔记分组 | 名称“笔记”、有效链接数量、最近创建的有效分享标题及剩余数量、进入箭头。 |

数量按有效链接条数统计，同一原内容创建的多条有效链接分别计数。
每组的标题预览使用最近创建的有效链接；其余有效链接用“+N”展示余量。
没有有效链接时分别显示“暂无有效的AI对话链接”“暂无有效的笔记链接”，分类入口仍可进入已失效记录。
数量读取失败时显示失败反馈和“重试”，保留原已确认数量并标注“更新失败”；首次读取失败时以占位符展示数量。

### 分类链接列表

列表顶部包含返回、当前分类名称与“有效 / 已失效”切换。默认打开“有效”。
两个状态视图均按发布时间从近到远排列；返回同一分类时保留用户选中的状态视图。

| 信息 | 展示规则 |
| --- | --- |
| 内容标题 | 使用创建分享时的标题，长标题截断；行菜单或链接信息中完整换行展示。 |
| 类型 | 由当前分类标题标明；窄屏行同时使用对应业务图标。 |
| 链接 | 有效视图展示缩略地址并提供复制和打开；点击缩略地址可在该行下方展开完整链接信息。已失效视图展示原地址及失效标记。 |
| 发布时间 | 使用用户当前时区展示该条链接的创建日期；详情可读到具体时间。 |
| 状态 | 链接业务状态为“有效”或“已失效”；正在提交和结果待确认属于本次操作反馈。 |
| 原内容提示 | 已确认删除时显示“原内容已删除”；保留分享时的完整标题和原地址，“查看原内容”不可用。 |
| 更多 | 单条链接的操作菜单。 |

本页按当前用户归属展示链接，“首次发布人”列省略，避免每行重复当前用户名称。
桌面使用平铺表格行与细分隔线；窄屏将同一条记录转为纵向信息行，完整地址可复制，页面保持单一纵向滚动。

### 单条操作

| 链接状态 | 操作 | 结果 |
| --- | --- | --- |
| 有效 | 复制链接 | 将完整公开地址写入剪贴板；复制失败时提供可选中的完整地址。 |
| 有效 | 打开公开页面 | 浏览器新标签页或原生系统浏览器打开该链接。 |
| 有效且原内容存在 | 查看原内容 | 打开对应AI对话或笔记，保留原业务的归属校验。 |
| 有效 | 使链接失效 | 直接提交本条链接的失效请求；提交期间锁定本条重复操作。 |
| 已失效且原内容存在 | 查看原内容 | 打开对应原内容。用户可沿原分享入口创建新链接。 |
| 已失效 | 查看链接信息 | 查看分享时的完整标题、原地址、发布时间、失效时间与失效原因；原内容已删除时显示对应提示。 |

“使链接失效”通过行更多菜单提供，菜单同时显示该记录标题，确保操作对象明确。
失效操作关闭公开访问并保留原内容，采用直接提交和结果反馈；本轮省略额外确认弹窗。
服务端确认后的成功反馈为“链接已失效”，该行从有效视图移出，在已失效视图保留记录，概览有效数量采用确认结果更新。提交中及结果待确认期间保留最后确认状态和数量。

### 链接生命周期

| 触发 | 链接结果 | 原内容结果 |
| --- | --- | --- |
| 用户首次或再次创建分享 | 创建新的有效链接，并写入当前用户的管理记录。 | 原内容保留。 |
| 同一次分享弹层重复复制 | 复用该弹层已创建的链接；后台已使该链接失效时提示重新分享。 | 原内容保留。 |
| 用户编辑原内容 | 既有链接继续读取创建时的快照。 | 原内容保存修改。 |
| 用户使某条链接失效 | 仅该地址进入已失效；同一原内容的其他有效链接保持当前状态。 | 原内容保留。 |
| 用户删除原内容 | 独立快照和链接记录保留，链接维持当前状态；有效链接继续供外部阅读，所有者仍可主动使其失效。 | 沿原删除流程处理；管理记录显示“原内容已删除”。 |
| 用户重新分享原内容 | 生成新的有效链接；已失效地址继续保持失效。 | 原内容保留。 |

管理页提供旧链接的状态记录，旧地址保持单向失效。重新分享使用新地址，避免先前已收回的公开地址再次开放。
“原内容已删除”仅说明原内容可用性，链接是否可访问由“有效 / 已失效”决定；管理记录持续保留分享时的完整标题和原地址。原内容读取暂时失败时显示读取反馈，等待后续确认。
公开访问在每次读取时核对服务端状态；已失效链接显示“此链接已失效或无法访问”，并隐藏分享正文及原内容信息。
失效前已经完成的访问与访问者保存的副本维持其既有结果。

### 失败、并发与恢复

| 条件 | 页面反馈 | 恢复动作 |
| --- | --- | --- |
| 列表首次读取失败 | 当前分类显示“外部链接暂时无法读取”。 | “重试”重新读取当前分类。 |
| 已有列表刷新失败 | 保留已确认记录并显示“更新失败”。 | “刷新”重新核对状态。 |
| 失效请求明确失败 | 保留该行与最后确认状态，显示“操作失败，请重试”。 | 对同一链接重试。 |
| 失效请求超时或连接中断 | 行内显示“结果待确认”，暂时禁用重复失效和打开公开页。 | “刷新状态”读取该链接的最新结果。 |
| 刷新确认仍有效 | 恢复有效状态及操作菜单。 | 用户可再次提交失效。 |
| 刷新确认已失效 | 更新失效记录与有效数量。 | 用户可进入已失效视图查看。 |
| 另一端已使链接失效 | 本次读取采用已失效结果，重复失效得到同一终态。 | 刷新当前列表和数量。 |
| 账户切换或登录失效 | 关闭行菜单，清除原账户页面记录，沿现有登录反馈恢复。 | 登录后重新读取当前账户记录。 |
| 原内容已删除 | 当前链接维持有效或已失效，显示“原内容已删除”；“查看原内容”不可用。 | 保留完整分享标题、原地址与管理操作；有效链接可主动失效。 |

页面只有在服务端确认后展示“链接已失效”。正在提交、结果待确认和刷新失败均保留明确反馈。
页面更新某条链接时，其他行继续可阅读和操作。

## 页面模块结构

| 编号 | 模块 | 空间关系与主要内容 | 滚动与层级 |
| --- | --- | --- | --- |
| M1 | 设置外壳 | 桌面左侧原设置导航；窄屏Web顶部原搜索与横向栏目；原生设置分类页中的“外部链接”。 | 复用原设置导航的滚动行为；链接记录使用一个纵向内容区。 |
| M2 | 页面头部 | 概览展示“外部链接”与说明；分类列表展示“返回外部链接”及当前分类名。 | 沿设置内容区正常排列；返回入口位于列表和反馈上方。 |
| M3 | 两类概览 | AI对话、笔记两个同级卡片；类别、有效数量、最近分享标题与余量、右向箭头。 | 桌面同一行等宽，窄屏上下排列；整个卡片为进入分类的入口。 |
| M4 | 状态与刷新 | 当前分类标题下方左侧为“有效 / 已失效”，右侧为“刷新”。 | 与当前列表处于同一纵向内容区，切换状态只替换下方记录。 |
| M5 | 分类记录 | 桌面表格；窄屏纵向信息行。标题与链接占主要宽度，时间、状态及更多靠后排列。 | 表头、记录、行内反馈随内容区滚动；记录区不增加独立滚动条。 |
| M6 | 行更多菜单 | 锚定当前行右侧“⋯”；顶部展示完整标题，下方为对应状态的操作。 | 覆盖本行附近空间，自动向可见区域展开；点击外部或按Esc收起，焦点回到当前行。 |
| M7 | 行内展开区 | 承接链接信息、复制失败后的完整地址和单条操作反馈。 | 插入当前记录下方，推动后续记录下移；完整标题与地址换行，沿同一个内容区滚动。 |
| M8 | 整区反馈 | 承接首次加载、空列表、首次读取失败；刷新失败提示位于状态切换下方。 | 反馈占用原列表位置，设置导航、返回与状态切换继续可见。 |

### 呈现与布局规则

- 页面复用当前设置的内容宽度、留白、字体和深浅主题。卡片使用轻边框、简洁留白；表格使用细分隔线。
- 标题、数量与当前状态使用主文本层级；说明、日期与缩略地址使用次文本层级；边框、悬停、选中与焦点沿用设置语义样式。“使链接失效”沿用既有危险操作语义，保留完整文字。
- “有效”和“已失效”均显示文字；正在提交与结果待确认显示独立反馈，状态识别同时依靠文字和操作可用性。
- 桌面表格将更多按钮保留在最右侧。可用宽度不足时沿现有窄屏边界转为纵向信息行，记录内容保持纵向阅读。
- 有效记录中的地址缩略展示，点击地址展开该行链接信息，复制使用完整地址；完整标题和原地址在展开区中换行，复制前即可阅读。行菜单中的完整标题允许换行，已失效链接信息持续展示创建分享时的完整标题。
- 菜单与行内展开区沿用设置现有背景、边框和层级；卡片和操作入口保留悬停及键盘焦点反馈，状态反馈配合明确文字。
- 行菜单和行内展开区承接单条操作。本页的使链接失效、手动复制与查看链接信息均直接使用当前页面空间。
- 窄屏Web保留原设置栏目横向滚动；外部链接内容区使用单一纵向滚动。原生端按“设置分类 → 外部链接概览 → 分类列表”逐层进入。
- 当前设计全部属于待实现页面；图中数量、标题、地址及时间均为布局示例。

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| EL01 | 从桌面设置或窄屏更多进入 | 可找到“外部链接”，展示AI对话和笔记两个分类。 |

| EL04 | 复制或打开有效链接 | 复制完整地址或打开对应快照；复制失败提供手动复制。 |
| EL05 | 对单条链接执行失效 | 仅处理该条记录；服务端确认后显示已失效并更新概览数量。 |
| EL06 | 访问已失效链接 | 公开页面显示失效或无法访问反馈，隐藏正文及原内容信息。 |
| EL07 | 重新分享 | 创建新有效地址，原失效地址继续保持失效。 |
| EL08 | 原内容已经删除 | 独立快照和链接记录保留，维持当前链接状态及有效数量；显示原内容已删除，完整分享标题与原地址可读，有效链接仍可主动失效。 |
| EL09 | 失效失败或结果待确认 | 保留最后确认状态与数量；明确失败可重试，结果待确认可刷新核对；确认已失效后才更新数量。 |
| EL10 | 另一端失效、账户切换 | 当前端刷新状态；用户只访问自己的管理记录，账户切换清除先前记录。 |
| EL11 | 桌面、窄屏、深浅主题 | 栏目、列表、行菜单和反馈可见，窄屏使用单一纵向滚动与完整操作入口。 |
| EL12 | 回到原AI对话或笔记 | 原内容保留，沿现有业务入口打开；已删除内容显示对应原因。 |
| EL13 | 对同一原内容的一条链接执行失效 | 原内容和同源其他链接保持当前结果；旧地址持续失效，重新分享生成新地址。 |
| EL14 | 尝试读取或操作其他用户的管理记录 | 管理页面及操作均仅返回当前用户的链接记录。 |

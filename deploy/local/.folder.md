# deploy/local/

## 架构概述
本地直跑发布脚本目录，复用 `backend/server.py` 与 `frontend/package.json` 的现有启动方式；
数据库由相邻 Admin `@ink-memory/db` supervisor 管理，Dream 只从 mode-0600 Admin env 文件读取连接串。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | 本地发布入口 | 检查本地依赖、Dream 配置和 Admin env 文件，使用 `LOCAL_ADMIN_ENV_FILE` 选择 embedded PostgreSQL 连接来源，启动/停止 backend 与 frontend 并执行验证 |

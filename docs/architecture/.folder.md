# docs/architecture — 目录合同

## 架构摘要

Ink & Memory 的项目级架构文档，覆盖 Next.js Dream Web、Python 后端、Admin/Gateway/PostgreSQL 拓扑，以及模块、API、认证、数据流、Claude Agent SDK/Runtime 与发布边界。

## 文件清单

| 文件 | 定位 | 职责 |

| `claude-agent.md` | Claude Agent 架构 | 目录分层、API、生命周期、配置（四项 JSON-safe 正整数、组合内存与 no-restart LKG refresh）、数据流、错误处理、测试和隔离 |
| `项目架构设计说明.md` | 项目架构总览 | 当前 Next.js 16 App Router、唯一 `frontend/app/_dream/**` Dream 源码、server-only MCP Apps Runtime、Python/Admin/Gateway/PostgreSQL 拓扑，以及自有 SDK/Runtime 版本矩阵、调用链、构建发布与回滚 |
| `auth.md` | 认证架构 | Google OAuth/OIDC、用户绑定、Token、安全边界和测试 |
| `auth-device.md` | Device Flow 架构 | OAuth 2.0 Device Authorization Grant 路由、状态、轮询、安全和时序 |
| `术语表.md` | 架构术语 | 项目通用术语与语义边界 |

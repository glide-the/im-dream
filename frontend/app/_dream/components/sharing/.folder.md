# 共享分享组件

| 路径 | 职责 |
| --- | --- |
| `ShareLinkOption.tsx` | 明确发布、复核当前状态和复制恢复，供AI及笔记使用。 |
| `ExternalLinksSettings.tsx / .css` | Web两类概览、响应式记录、行内操作和恢复反馈。 |
| `PublicShareContent.tsx` | 匿名正文叶子，复用NoteContent及publicView Markdown。 |

`PublicShareContent`复用UserMessagePart、AssistMessagePart和chatMessageLayout，公开AI快照沿Chat样式呈现；publicView媒体限制和只读复制保持。

`ExternalShareMenu.tsx`提供按行定位的拷贝/查看/设置浮层；`ExternalShareSettingsDialog.tsx`复用原Modal承接通用访问权限、失效与恢复。ExternalLinksSettings保留原API回调及行内复制恢复。

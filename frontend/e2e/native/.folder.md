# 原生组件等价验证

`chat-page-parity.tsx`组合生产ChatPage、原输入卡、历史及Thread协调器；公开HTTP/SSE DTO由内存fixture返回，Mac Next仅提供原Tiptap文档。用于首页顺序、搜索、选择历史、首个Thread布局和草稿/权限回调；技术页脚读取实际提交DTO的字符数并与明确命名的长稿样本比较，观测结果退出业务请求和回复生成职责。规范finish发送后fixture保持连接直到生产reader取消，用于Hermes实际流结束恢复检查。运行库、真实账户、存储及模型保持零调用。

`sketch-document-parity.tsx`验证生产根级草图浮层和iOS PNG文件句柄；原草图文档来自Mac Next，回调记录文件元数据后释放副本，模拟接受/拒绝。运行库、业务上传、账户和模型保持零调用；完整端侧业务单独验收。

`tool-confirmation-parity.tsx`直接呈现生产`ToolConfirmationDock.native`，验证普通批准/拒绝、reject-only、网络目标说明及multiSelect+必填文本。回调只记录synthetic tool ID、approved/reason/answers，未启动运行库、HTTP或模型。表单和确认输入维持原公开schema。

`composer-context-parity.tsx`使用生产`AIInputDock.native`、`DeckChatSelector.native`和原Chat DTO builder，检查启用Agent、前缀搜索、无Agent、manual/full-access、Skill草稿及Send/Stop。Deck和提交回执为显式内存fixture；编辑文档读取Mac Next。该入口不调用ensureStarted，真实账户、后端、存储上传和模型退出验证范围。

`original-ui-parity.tsx`渲染生产QuickActionStrip.native、原动作工厂和字体标签；点击后显示收到的原动作ID。通过Xcode的ENTRY_FILE构建参数单独编译，安装为隔离标识`com.inkmemory.uiparity`，显示名`Ink UI Parity`；主应用入口和用户iPhone包保持。

该入口用于字体、SVG、顶部操作菜单和历史列表回调验证，当前完整页面、业务发起/完成、Stop和恢复均退出其验收范围。历史记录使用明确命名的内存fixture，选择、删除及重试仅更新fixture状态；测试直接渲染生产组件。验证结束只清理自有隔离应用，保留用户原应用和数据。

`i18n-storage.test.mjs`检查原Web存储键与语言回退，并验证无localStorage的原生初始化。`chat-history-contract.test.mjs`调用生产HTTP及日期模块，检查默认Web请求、可选native transport、搜索/分页/取消/创建/删除参数及原分组顺序；临时编译目录`.history-contract-*`由测试创建并清理。

`composer-controls-parity.tsx`直接调用生产`AIInputDockControls.native`、`useComposerDraft`及`MarkdownInputEditor.native`，验证原富文本局部文档、Native权限、发送/Stop、拒绝恢复和附件/草图回调。局部文档通过Mac Next IPv6监听读取，地址为具名技术fixture所有；该读取退出iOS独立运行库证明范围。上传回调只写入内存文件元数据，草图回调只记录操作；后端、模型、账户和业务HTTP退出此入口。

`original-ui-parity.tsx`追加生产ThreadInputQueueCard.native与明确命名的queued条目，回调只更新fixture显示；用于实际Hermes菜单、编辑、selected及owner限制核对，未调用队列API、运行库或模型。Native hook与真实DTO的API调用合同由native-chat-session.spec.ts单独验证；该组件入口退出Side Business Modal和真实任务创建验收范围。

# Dream 工作台产品需求

## 背景与问题

Dream 工作台用于承载持续创作。用户在 Chat 中选择 Dream 类型 Deck 并提出创作目标，Dream Agent 在同一 Thread 中继续工作，工作台按 Project 和 Episode 展示人物、场景、剧本、分镜、Prompt 和审阅内容。

此前没有独立的 Dream 工作台 PRD。产品规则分散在 Dream Agent、Story Workspace、Episode 同步和 Deck 工作流文档中，导致三个边界不清：

- Deck 工作流定义与工作台页面职责混在一起；
- Agent 对话状态与工作台内容状态容易被解释为同一套状态机；
- Dream 首页、初稿、同步、Episode 阅读和失败恢复缺少统一的产品入口。

本 PRD 统一 Dream 工作台的用户目的和页面范围。现有正式设计继续负责具体时序和数据合同。

## 目标与边界

Dream 工作台帮助用户完成以下任务：

- 查看进行中的 Dream，并重新进入已有 Run；
- 在工作台和同一 Chat 之间切换，不丢失 Thread、消息或当前执行状态；
- 查看项目级人物、场景和分集规划；
- 按 Episode 查看剧本、分镜、Prompt、故事线和审阅结果；
- 修订或接受项目初稿，并继续后续创作；
- 查看内容更新、缺失、同步失败、最近正常版本和恢复入口；
- 确认当前 Run 使用的 Deck 与工作流来源。

本次范围包括：

- Dream 首页的进行中列表、我的 Dream、搜索、分页、空状态和加载失败；
- Run 重入、同一 Thread 恢复和 Dream Agent 面板；
- 初稿工作面、同步工作面和创作阶段指引；
- Project、Episode、故事线、人物、场景、剧本、分镜、Prompt 和审阅内容；
- 项目初稿的一次确认；
- 内容渐进更新、历史版本、最近正常内容和同步失败反馈；
- 桌面与窄屏页面结构。

本次不包括：

- Deck 的创建、编辑、内容版本提交和启停；
- Deck 工作流版本选择、工作流发布后台和远程 Marketplace；
- Claude Code Plugins 的选择、安装或发布；
- Claude Agent 运行环境、进程、文件准备和内部任务过程；
- 自动选择唯一下一步、固定 Skill 顺序或新的工作流状态机；
- 从剧本自动生成完整成片；
- 在 Dream 首页直接创建第二套对话或绕过 Chat 启动创作。

## 概念与规则

### Dream 工作台

Dream 工作台是创作 Run 的阅读、修订、确认和继续协作页面。它展示 Dream Agent 已生成并通过工作台检查的内容，不替代 Chat，不负责配置 Deck 或发布工作流。

### Dream 首页

- Dream 首页展示用户有权访问的进行中和初始状态 Run。
- 新创作从 Chat 开始；Dream 首页不复制目标输入、Deck 选择或发送流程。
- 打开、刷新、搜索和分页只读取数据，不启动或恢复模型执行。
- 列表读取失败与“还没有 Dream”是不同状态。

### Run 与 Thread

- Run 表示一次使用固定 Deck 和工作流来源的创作运行。
- Thread 保存用户与 Dream Agent 的同一组消息和执行状态。
- 工作台重入返回原 Thread；切换到 Chat 后继续原对话。
- 工作台页面状态不能替代 Thread 的运行、停止、失败和重连状态。
- 当前 Run 使用的 Deck 名称、工作流名称和版本在 Run 内保持不变。

### Project 与 Episode

- Project 是一次创作的稳定内容容器。
- Episode 是 Project 下的稳定分集单位。
- 人物、场景和分集规划可以跨 Episode 复用。
- 剧本、分镜、Prompt 和审阅结果按 Episode 区分。
- 页面、请求和缓存不得使用其他 Episode 的内容填补当前 Episode。

### 初稿与同步

- 初稿是默认工作面，展示人物、场景、分镜索引和可阅读正文。
- 同步展示 Episode 索引、故事线、审阅结果和辅助内容。
- “初稿 / 同步”只改变当前页面呈现，不改变 Run、Thread、工作流阶段或服务端状态。
- 从同步工作面打开正文时，返回初稿中对应 Episode 的阅读位置。

### 创作阶段指引

- 指引说明跨集准备、分集创作和尚未开放的成片制作范围。
- 指引不占用 Episode 索引，不触发 Agent，不保存为业务状态。
- 初始化后的 Skill 可以按用户需要调用和重复，页面不计算唯一下一步。

### 初次确认

项目初稿形成后，用户可以修订或接受一次项目级确认。接受后由同一 Dream Agent 在原 Thread 中继续首集创作。后续 Episode 不重复建立同类确认门槛。

### 内容更新与版本

- 人物、场景、剧本、分镜、Prompt 和审阅内容可以分别到达。
- 新内容到达时，页面保留仍然有效的选择和其他已可读模块。
- 修订或重新生成后显示当前版本，并保留先前版本及其来源。
- 最新内容无法读取时，页面显示最近一次正常内容并说明当前问题。
- 页面不把 revision、文件数量或内部路径展示为另一套创作进度。

### Dream Agent 面板

- 面板复用同一 Thread 的消息、输入、工具反馈、确认和 Stop。
- 折叠状态可以显示安全的活动摘要和未读提示。
- Agent 面板不能隐藏需要用户处理的确认或错误。
- 打开或收起面板不创建新 Thread，也不重复发送初始化消息。

## 功能描述

| 功能模块 | 功能描述 |
| --- | --- |
| Dream 首页 | 展示进行中的 Dream 和用户可重新进入的 Run。 |
| 搜索与分组 | 按目标、Deck 或 Run 标识查找并分组展示已有 Dream。 |
| Run 重入 | 打开已有创作 Run 并恢复对应工作台内容。 |
| Chat 连续协作 | 在工作台与同一 Chat 之间切换并继续原对话。 |
| Dream Agent 面板 | 展示消息、输入、工具反馈、确认和停止操作。 |
| 初稿工作面 | 展示人物、场景、分镜索引和可阅读正文。 |
| 同步工作面 | 展示 Episode 索引、故事线、审阅和辅助内容。 |
| Episode 阅读 | 展示当前 Episode 的剧本、分镜、Prompt 和审阅内容。 |
| 创作阶段指引 | 说明跨集准备、分集创作和未开放制作环节。 |
| 初次确认 | 支持修订或接受项目级初稿并继续首集创作。 |
| 内容版本 | 回看生成、修订和重新生成前后的内容及来源。 |
| 状态与恢复 | 展示加载、生成、内容缺失、同步失败、最近正常内容和恢复入口。 |
| Run 来源 | 展示当前 Run 使用的 Deck、工作流名称和版本。 |

## 页面信息架构

### Dream 首页：桌面

```text
┌ 主导航 ───────┬ Dream ──────────────────────────────────────────┐
│ Chat          │ 继续创作，或选择一个 Deck 开始新的 Dream。       │
│ Dream ●       ├ 进行中的 Dream ─────────────────────────────────┤
│ Decks         │ 项目 A · Deck 名称                         [继续] │
│ More          │ 项目 B · Deck 名称                         [继续] │
│               │                                      [查看更多] │
│               ├ 我的 Dream ──────────────── [搜索我的 Dream____] │
│               │ 进行中  2                                     │
│               │ 项目 A · 当前状态 · 最近活动时间       [打开工作台] │
│               │ 初始状态  1                                   │
│               │ 项目 C · 当前状态 · 最近活动时间       [打开工作台] │
│               │                              [上一页] 1/2 [下一页] │
└───────────────┴──────────────────────────────────────────────────┘
```

Dream 首页不提供新的目标输入。没有 Run 时显示前往 Decks 并在 Chat 中开始创作的入口；读取失败时保留重试操作。

### Dream 首页：窄屏

```text
┌ Dream ─────────────────────────────┐
│ 继续创作，或开始新的 Dream。         │
├ 进行中的 Dream ────────────────────┤
│ 项目 A · Deck 名称            [继续] │
│ 项目 B · Deck 名称            [继续] │
│ [查看更多]                          │
├ 我的 Dream ────────────────────────┤
│ [搜索我的 Dream________________]    │
│ 进行中                              │
│ 项目 A · 状态 · 时间                │
│ 初始状态                            │
│ 项目 C · 状态 · 时间                │
├ 固定底部导航 ───────────────────────┤
│ Chat      Dream      Decks      More │
└─────────────────────────────────────┘
```

页面单列纵向滚动。搜索、分组、分页和空状态保持与桌面相同的业务含义。

### 创作工作台：桌面

```text
┌ ← 返回 Dream   创作工作空间 ───────────── [Dream Agent 活动摘要] ┐
│ Deck 名称 · 工作流名称 v1.0.0    [查看短剧创作阶段指引]          │
├ 模块索引 ───────────┬ 内容阅读与编辑 ───────────┬ Dream Agent ──┤
│ 人物                │ 当前条目标题、说明与正文    │ 同一 Thread    │
│ 场景                │ 关联 Project / Episode     │ 消息与工具反馈  │
│ 分镜                │                            │ 输入 / Stop     │
│                     │ [修订初稿] [接受并继续]     │ [打开完整 Chat] │
└─────────────────────┴────────────────────────────┴───────────────┘

后续执行：
┌ Dream / 后续执行 ─ 项目名称 ───────────── [Dream Agent 消息预览] ┐
├ [故事资产] [故事线与叙事点] ────── [查看短剧创作阶段指引] ─────┤
│ 索引                  │ 选中内容正文 / Episode 聚焦页             │
└───────────────────────┴───────────────────────────────────────────┘

切换到同步：
┌ Episode 索引 ─────────┬ 当前 Episode 内容 ───────┬ 审阅与辅助内容 ┐
│ EP01                  │ 故事线 / 剧本 / 分镜      │ 审阅结果        │
│ EP02                  │ Prompt / 场景 / 镜头      │ 关联内容        │
└───────────────────────┴───────────────────────────┴────────────────┘
```

桌面端允许 Agent 面板与内容工作面并列。初稿与同步切换位于 Dream Agent 标题区域，切换后背景工作面立即更新。

### 创作工作台：窄屏

```text
┌ ← Dream    创作工作空间   [Dream Agent] │
│ Deck 名称 · 工作流名称 v1.0.0           │
├ 初稿工作面，单列纵向滚动 ────────────────┤
│ 人物 / 场景 / 分镜                       │
│ 当前条目正文                             │
│ [查看短剧创作阶段指引]                   │
│ [修订初稿] [接受并继续]                  │
└──────────────────────────────────────────┘

Dream Agent 以全宽对话框显示：
┌ Dream Agent   [打开完整 Chat] [初稿] [同步] [×] │
│ 消息、工具反馈、确认、输入与 Stop                 │
└───────────────────────────────────────────────────┘

选择“初稿”或“同步”后收起对话框并显示目标工作面。
同步工作面按 Episode 索引 → 当前内容 → 审阅与辅助内容纵向排列。
```

## 状态与失败反馈

| 场景 | 页面反馈 | 恢复方式 |
| --- | --- | --- |
| Dream 首页加载中 | 显示进行中和我的 Dream 的读取状态。 | 等待读取完成。 |
| 还没有 Dream | 说明需要从 Decks 选择 Dream Deck，并在 Chat 中开始。 | 前往 Decks 或 Chat。 |
| Dream 列表读取失败 | 显示“暂时无法加载”。 | 重新读取。 |
| Run 正在生成 | 显示 Agent 活动摘要，保留最近可读内容。 | 打开 Agent 面板查看或停止。 |
| 等待初稿 | 显示人物、场景或分镜仍在生成。 | 等待 Agent 完成本轮。 |
| 等待确认 | 显示项目初稿和一次确认操作。 | 修订或接受并继续。 |
| Episode 尚未生成 | 当前 Episode 索引或内容显示空状态。 | 返回同一 Chat 调用相应 Skill。 |
| Episode 不存在或失效 | 说明当前链接不属于该 Run。 | 返回 Episode 索引重新选择。 |
| 最新内容部分不可用 | 展示可读模块和最近正常版本，并指出缺失项。 | 重试读取或继续使用现有内容。 |
| 同步自动修正中 | Chat 显示修正原因和一次修正过程。 | 等待同一 Agent 完成修正。 |
| 自动修正后仍失败 | 保留最近正常内容并显示停止结果。 | 用户修改目标后重新发送。 |
| Thread 绑定冲突 | 保留消息与附件，显示不能安全继续的原因。 | 重新读取或返回原 Chat。 |
| Run 失败或取消 | 显示最终状态和现有可读内容。 | 返回 Dream 或同一 Chat 决定后续操作。 |

## 实现差距

- Dream 首页、Run 重入、同一 Thread、初稿/同步和 Episode 隔离已有现行页面与设计依据。
- 工作流来源字段已经进入 Run 数据，仍需确认其在所有有效工作台状态下稳定可见。
- 内容历史版本的完整保留与回看能力需要按剧本、分镜、Prompt 和审阅类型逐项核对，不能用当前 revision 文案冒充已经完成。
- 阶段指引中的 `/script-reviewer` 必须与实际安装的审阅 Skill 对齐。
- 自动修正已有一次执行边界，仍需用真实 Chat/SSE 页面验证原因、修正结果和最终停止反馈。

## 验收条件

- Dream 工作台拥有独立 PRD，不再由 Deck 工作流 PRD 代替。
- Dream 首页只负责发现和重入；新创作从 Chat 开始。
- 工作台和 Chat 使用同一 Thread，切换页面不创建新对话或启动新 turn。
- 初稿、同步和阶段指引的职责清楚，页面切换不写入业务状态。
- Project 与 Episode 内容层级清楚，当前 Episode 不显示其他 Episode 的内容。
- 项目初稿最多出现一次业务确认，后续创作不增加阶段审批。
- 内容可以渐进更新；最新内容不可用时保留其他可读模块和最近正常版本。
- 修订与重新生成不覆盖先前版本及其来源。
- Dream Agent 面板保留 Chat 的确认、Stop、失败和重连能力。
- 桌面与窄屏骨架覆盖首页、创作工作台、Agent 对话框和同步工作面。
- 页面不展示内部路径、运行环境、文件数量或程序任务过程。
- 未实现的成片制作、工作流发布后台和远程 Marketplace 没有被描述为可用功能。

以上是产品与文档验收标准。程序差距闭合并完成对应真实业务流程验证前，不得宣称 Dream 工作台已按本文完整实现。

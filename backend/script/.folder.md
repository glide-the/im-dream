# backend/script - Folder Contract

## Architecture Summary
Operational scripts for one-off or repeatable backend data maintenance tasks.
Scripts should reuse backend helper modules such as `database.py` where possible,
keep environment-specific values in CLI arguments or environment variables, and
avoid adding service runtime behavior.

## File Table

| File | Pos | Function |
|------|-----|----------|
| `import_diaries.py` | data-import utility | imports Markdown diary/note files into `user_sessions` with existing date/label/idempotency rules; Agent labels require explicit Admin OAuth before I/O and production profile ID matching before creating threads; maintenance database writes remain explicit |
| `import_claude_mcp_config.py` | one-time cutover importer | uses server-owned Admin config plus `INK_MCP_IMPORT_ACCESS_TOKEN`, derives canonical actor from `/principal`, and imports only non-secret legacy remote MCP metadata through Registry134-147 receipts；无actor参数、PostgreSQL credential或数据库fallback |
| `verify_gateway_e2e.py` | release verification | requires an explicit existing email, Admin OAuth and exact model contract; reads public `/api/me` before database/model activity and matches account ID before proceeding; emits redacted receipts; existing Gateway subject helper awaits purpose migration |

# 笔记分享

## 背景与问题

用户希望将一份笔记发送给应用外的人，在写作页面使用与聊天分享一致的弹层，选择图片或链接。
当前写作页面拥有笔记保存、历史笔记打开和正文编辑入口；聊天分享拥有长图生成、预览和下载能力。

需求来源：[Notion：笔记支持对外分享](https://app.notion.com/p/40b30b7547c380cd9930c384ab35023c#40f30b7547c380d9a571e159bfc360ef)。
正式交互：[笔记分享设计](../../design/edit-session/note-sharing.md)。

## 目标与边界

在当前笔记的工具栏增加“分享笔记”。用户打开历史笔记后，使用同一入口分享该笔记。
分享弹层提供“导出图片”和“复制链接”，沿用现有聊天分享的纸面样式和长图预览形式。

分享范围为当前笔记的正文。内嵌聊天、写作建议、批注、执行任务、账户信息和工作区信息留在原应用中。
公开阅读页面仅展示正文、笔记标题、创建日期和品牌。

本轮交付包含浏览器桌面、浏览器窄屏，以及原生写作入口的系统复制和图片分享接线。
公开地址的可达性、分享服务采用和实体设备系统分享由实际部署及设备验收确认。
协同编辑和分享期限归后续独立需求。AI对话按[统一分享规则](../sharing/external-links.md)提供文字快照。
设置中的归属查看和单条主动失效见[外部链接管理](../sharing/external-links.md)，页面与接口源码已接入。Admin后台发布与本次技术检查完成，前端服务采用和真实账户/设备验收由执行记录登记；旧文件方案保存在[历史稿](sharing-before-unified-sharing-20261112.md)。

## 概念与规则

| 对象 | 规则 |
| --- | --- |
| 当前笔记 | 用户在写作页面正在阅读、编辑的那一份笔记。 |
| 分享快照 | 用户打开分享时选定的正文；图片沿该内容生成，链接创建时核对已保存正文。 |
| 图片 | 用户点击导出后生成完整正文长图，预览区域内部滚动，下载或系统分享由用户触发。 |
| 链接 | 用户点击复制链接后保存正文快照；持有链接的人可直接阅读。 |
| 后续编辑 | 原笔记继续保存修改；已有分享快照独立保留。 |
| 原笔记删除 | 已有分享快照继续保留，有效链接继续读取快照，所有者可在设置中主动使链接失效。 |
| 空笔记 | 图片和链接操作均处于禁用状态。 |
| 取消 | 用户关闭分享弹层或取消系统分享后，继续停留在原笔记。 |

1. 打开分享弹层仅展示选项；复制链接触发对外发布。
2. 链接创建先完成当前笔记保存，再核对选定正文与已保存正文。内容变化时提示关闭并重新打开分享。
3. 分享内容保留正文顺序、换行、中文和表情符号；正文中的标记按原文字展示。
4. 链接创建成功后展示可选中的完整链接；系统复制失败时提示手动复制。
5. 同一次弹层重复复制复用已创建链接，并核对当前状态。已失效时提示再次分享，原地址继续失效。
6. 图片生成、下载或链接创建失败时给出反馈，并保留重试入口。
7. 原生系统分享取消后保留图片预览，用户可再次分享。
8. 切换笔记、账户或离开原生写作页面后关闭本次分享，后续结果按原操作归属处理。
9. 分享弹层支持键盘关闭、焦点约束和关闭后焦点恢复；窄屏保留可见操作入口。

## 页面骨架

### 桌面

```text
应用侧栏 | 当前笔记写作页面
         | 左侧工具栏：日历 / 保存 / 分享笔记 / 原有其他操作
         | 当前笔记正文（原滚动范围）
         |
         |   分享笔记弹层 ────────────────── 关闭
         |   笔记标题
         |   [复制链接]
         |   快照公开阅读范围说明
         |   [已创建链接，支持选中复制]
         |   [导出图片]
         |   失败反馈
         |
         |   图片预览 ───────────────────── 关闭
         |   ┌──────────────────────────┐
         |   │完整正文长图，内部纵向滚动    │
         |   └──────────────────────────┘
         |   [下载图片] [返回选项]
```

### 公开阅读

```text
浏览器页面，正文区域纵向滚动
品牌
笔记标题
创建日期
正文段落，按原顺序和换行展示

```

公开页面直接阅读。链接缺失或已失效时显示统一无法访问页面；服务暂时不可用时显示稍后重试反馈。

## 验收条件

| 项目 | 预期 |
| --- | --- |
| 选项 | 打开当前笔记分享后同时看到图片和链接入口。 |
| 图片 | 完整正文可预览、下载，长内容允许分图保存，私有聊天及写作建议退出图片内容。 |
| 链接 | 登录用户可发布自己笔记的快照，应用外访问者直接阅读。 |
| 更新 | 分享后编辑原笔记，原链接展示先前快照；创建期间正文冲突给出重新打开提示。 |
| 失败 | 保存、链接创建、生成图片、系统分享、系统复制失败均有可操作的恢复入口。 |
| 原生 | 图片经系统分享面板交付，取消后仍可重试；链接经系统剪贴板复制。 |
| 展示 | 中文、英文、深浅主题与窄屏操作可见，正文按文字显示。 |

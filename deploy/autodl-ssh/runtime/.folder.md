# deploy/autodl-ssh/runtime — Folder Contract

## Architecture Summary

Direct-host runtime entry scripts for the already published Dream/Admin release.
They bind persistent server-owned data roots and supervise only their named
processes; build, migration, and deployment ownership stay in the parent folder.

## File Table

| File | Pos | Function |
|---|---|---|
| `init-dream-data.sh` | persistent-data initializer | Creates and validates Dream agentdata, actor-scoped Notion runtime, artifact, upload, plugin, and log roots with private ownership/modes and symlink rejection. |
| `start-dream.sh` | Dream process supervisor | Starts the published frontend/backend pair with explicit persistent Agent and Notion runtime roots. |
| `start-ink-memory.sh` | release restart entry | Restores the already published Admin and Dream processes without building, migrating, or replacing unrelated processes. |

# docs — 文档目录

## 目录职责

保存当前业务设计、系统架构、部署操作和开发规则。业务设计按模块组织；任务、执行、评审和测试
证据由 Git、PR、CI 或外部任务系统保存，不在仓库内建立历史流水目录。

## 当前目录

| 目录/文件 | 职责 |
|---|---|
| `README.md` | 文档总入口 |
| `design/` | 当前业务需求、实现结果、边界与代码所有权 |
| `architecture/` | 当前系统拓扑、数据所有权、安全和 Schema 协议 |
| `deploy/` | 本地、Docker、Remote SSH 与云部署操作 |
| `rules/` | 复用、配置和文档同步规则 |

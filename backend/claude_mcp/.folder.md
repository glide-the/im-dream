# backend/claude_mcp — Folder Contract

## Architecture Summary

Owns the `claude-mcp` business domain for Resources discovery and official Claude Code MCP OAuth argv operations. Authentication runs before any thread in a server-owned, platform-user-scoped config and secure-storage identity. Every Agent turn returns opaque `mcpServers` definitions for direct public SDK injection; Linux additionally projects file-backed `mcpOAuth`, while macOS keeps secrets inside Claude Code's user Keychain and passes only the secure-store selector to Agent. No database schema, whole-home copy, Keychain payload access, shell command, or private SDK control subtype belongs here.

| `service.py` | operation orchestration | Own user-scoped in-memory OAuth lifecycle, idempotency, concurrency, and verification. |

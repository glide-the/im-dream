## 架构摘要

保存从设计合同拆出的技术工作项索引。每份索引描述模块边界、依赖、验收、真实缺口和回滚，可直接帮助实现定位范围。

## 维护规则

- 新增、删除或重命名索引时同步本文件。
- 工作项只能引用已接受的 `docs/design/` 合同；确有架构缺口时记录问题、影响范围和安全默认值。
- 每项至少给出目标、必要技术依赖、写入边界、验收、验证方法与回滚。
- 实现是否可开始由技术依赖和安全边界决定。
- 实际失败必须保留原命令、退出码和原因，不能用文档状态掩盖。

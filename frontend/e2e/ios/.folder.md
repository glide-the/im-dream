# iOS页面验证

2026-11-03：APP-01/02/03/05验收已恢复，APP-04持续暂停。`AppExperienceUITests.swift`对显式安装的普通账户报告详情执行只读手势和诊断覆盖检查；主Agent运行真实账户步骤，结果归私有xcresult。启动测量10项合同已通过，当前Simulator阶段数据由总控执行记录登记。

| 文件 | 职责 |
| --- | --- |
| `DeckScrollUITests.swift` | 对显式指定的已安装应用执行原预览页只读滑动，以及已有维护表单/内容历史/插件栏目的原生导航；无编辑、消息、模型或业务写入 |
| `AppExperienceUITests.swift` | 对已打开的原回顾详情验证拖动吸附及开发者覆盖、返回；写作页验证浮动按钮触摸拖动和位置恢复，不重置App或提交业务 |
| `prepare-ui-runner.rb` | 使用现有CocoaPods的xcodeproj创建指定临时目录中的独立XCTest UI runner；可选择同目录Swift测试源，默认DeckScroll，生产Xcode工程保持，无依赖安装 |
| `tasks/` | 仅记录XCUITest E2E目标、交互断言、运行状态及脱敏证据索引；[任务索引](tasks/README.md) |

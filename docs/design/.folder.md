# docs/design — 当前业务设计

## 目录职责

按业务模块保存当前需求、已实现结果、边界和代码所有权。执行过程、评审记录、测试证据和任务流水
不进入本目录。

## 模块目录

| 目录 | 业务职责 |
|---|---|
| `account-auth/` | 账号、OAuth 与会话 |
| `writing-memory/` | 写作、时间线、Reflections 与 Memory |
| `chat-agent/` | Chat Thread 与 Claude Agent 交互 |
| `deck/` | Deck 管理、版本和启动 |
| `deck-register/` | 明确延期的市场分发边界 |
| `dream/` | DreamAgent、Run 和产物同步 |
| `story-workspace/` | 创作项目、Episode 和审阅 |
| `resources-plugins/` | 资源连接器与插件 |
| `workspace-storage/` | 工作区文件与对象存储 |
| `subscription-models/` | 订阅、额度、模型和 Gateway |
| `ui/` | 路由、布局、主题和交互基线 |

# Ink & Memory 定时任务页面结构草图

## 1. 结构提炼

页面沿用参考图的核心工作方式：任务创建结果嵌在 Chat 的 assistant turn 中，任务标记卡是打开详情的稳定入口；桌面端在右侧并排打开任务详情，窄屏端切换到全高详情页。详情正文按“任务说明 → 当前状态 → 间隔编辑表单 → 运行历史”排列，底部操作栏始终可见。实际执行记录通过自身的精确 `target_thread_id` 进入对应会话；跳过记录没有会话入口。

### 桌面滚动边界

- **外层 V0**：浏览器视口固定，不产生页面级纵向或横向滚动；A0 与 B0 都被限制在可视高度内。
- **左侧内层 L1**：仅 A2 Chat 消息流滚动；A1 和 A4 固定。打开或关闭 B0 时保留 A2 的阅读位置，关闭详情后焦点回到 A3。
- **右侧内层 R1**：仅 B8 详情正文滚动，滚动内容从 B2 到 B5；B1 和 B7 固定。B5 不再创建第二层滚动容器，长历史通过 R1 滚动并用“继续加载”扩展。
- **会话切换**：B6 进入 C1 前记录 R1 位置；从执行会话返回时恢复该位置。skipped 范围没有 B6。

### 窄屏滚动边界

- **外层 M0 / M2**：Chat 与详情都是全高视口，外层不滚动；详情覆盖 Chat，避免两栏被压缩。
- **Chat 内层 M1**：仅 A2 滚动，A1 与 A4 固定。
- **详情内层 M3**：B2、B4、B3、B5 共用一个连续纵向滚动区；B1 与 B7 固定。表单和历史均不嵌套独立滚动条。
- **横向范围**：长标题单行省略，prompt 可换行，表单值和历史摘要在容器内换行或截断；所有视口均禁止页面级横向滚动。

## 4. 模块索引

| 编号 | 模块 | 结构职责 | 主要内容或动作 |
| --- | --- | --- | --- |
| V0 | 桌面外层视口 | 限定双栏高度与外层滚动 | 外层不滚动，容纳 A0 与 B0 |
| A0 | Chat 主区 | 保留创建任务的对话上下文 | A1、A2、A4 |
| A1 | Chat 顶栏 | 标识当前 Thread | 标题、分享、更多/返回 |
| A2 | Chat 消息流 | 承载自然语言创建过程 | 用户消息、assistant 正文、Tool 过程、A3 |
| A3 | Chat 定时任务标记卡 | 持久化展示创建成功结果 | 标题、计划摘要、应用状态；整卡打开 task ID |
| A4 | Chat 输入区 | 继续普通交互会话 | 输入、附件、模型、发送 |
| B0 | 任务详情侧栏 | 桌面查看和编辑当前任务 | B1、B8、B7 |
| B1 | 详情顶栏 | 标识并关闭/返回当前详情 | 任务标题、更多、关闭/返回 |
| B2 | 任务说明卡 | 说明任务做什么及来源 | 完整 prompt、来源 Chat |
| B3 | 间隔编辑表单 | 编辑 desired 任务配置 | 运行于、重复、每隔 N 分钟、时区、通知、字段错误 |
| B4 | 应用状态 | 呈现 desired/effective 结果 | 已保存计划、生效计划、下次运行、异常与重试 |
| B5 | 运行历史 | 按到期时间倒序展示 trigger | 执行状态、时间、结果、skipped 范围、继续加载 |
| B6 | 会话入口 | 进入实际执行记录 | 使用该行精确 `target_thread_id`；skipped 不展示 |
| B7 | 底部操作区 | 提交或撤销编辑 | 取消、保存；保存期间防重复提交 |
| B8 | 详情正文 | 组成详情的单一连续内容流 | B2、B4、B3、B5 |
| C1 | 执行会话 | 处理结果或待确认工具 | 对应 TaskSession / Thread / Turn，支持返回详情 |
| M0 | 窄屏 Chat 视口 | 单栏呈现 Chat | 外层固定，A2 内滚动 |
| M2 | 窄屏详情页/抽屉 | 覆盖 Chat 呈现完整详情 | 外层固定，M3 内滚动 |

## 5. 关键显示规则

1. A3 仅在真实创建结果含 task ID 时出现；创建失败或正文只提到“已创建”时不生成标记卡。
2. B3 选择“间隔”时显示正整数 `interval_minutes` 和分钟单位；10 分钟可以作为快捷选择，但不是隐含默认值。
3. B4 只有 fresh effective 的 revision 与当前规则全部适用值匹配 desired 时才显示“已应用”；否则展示“正在应用”或“仍按上一版计划运行”。
4. B5 的实际执行行可以显示 B6；skipped 范围只显示起止时间和次数，不伪造会话入口。
5. “需要操作”与“状态待确认”必须使用文字表达；B6 直接进入对应执行会话处理，不在详情里增加重复确认弹窗。

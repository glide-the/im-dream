# 回归分析：分析内容

## 背景与问题

当前总分析只将日记会话传入任务。Notion 已有授权、资源挂载、本地索引和正文读取，但没有接入回归分析；各栏目另有 Analyze，入口分散。Deck 选择组件的组标题是 Deck，选项是 Agent，不存在“点击组标题执行整个 Deck”的合同。

本地 Notion 快照是资源索引，不包含正文。开启后应复用索引限定范围，在提交时通过现有 `get_page_markdown` 读取正文，并冻结为本任务输入；不能声称直接从本地全文快照分析。

## 目标与边界

总分析按钮旁提供“分析内容”展开面板，包含 Notion 整体开关和按 Deck 分组的 Agent 选择。关闭各栏目独立 Analyze，保留栏目配置、进度、错误、结果和历史。

选择 Agent 作为分析视角，服务端使用该 Agent 的 `system_prompt`；仍执行回归分析三栏目工作流、默认模型和原有工具权限。Deck 的 Chat 插件和 Dream 写作执行并不属于此选择。面板明确显示“分析 Agent”，不称为切换完整 Chat Runtime。无选择保持原有默认路径。

不增加逐资源管理器、全文同步系统、全局偏好、配置版本系统、模型选择或确认弹窗。已有当日报告时保留日记范围选择弹窗；它决定本次日记范围，不重复确认 Notion 或 Agent。创建结果未确认或来源校验失败时直接恢复或调整后重试，不增加再次确认。

## 概念与规则

| 对象 | 本次规则 |
| --- | --- |
| 默认 | Notion 关闭，Agent 未选择；原日记全范围 |
| 面板选择 | desired 为下一次提交选项，只影响下一次提交，使用 AnalysisView 页面内存；收起重开保留，组件卸载或刷新重置；未确认提交例外按下方存储规则恢复 |
| 执行输入 | effective 为 Admin 已提交任务中的输入；服务端在创建任务事务前读取正文，在事务内保存输入和 Agent 指令；任务启动后固定 |
| Notion 范围 | 当前账户活动连接器、已授权且已挂载的当前快照全部非归档页面；按规范化 page_id 去重，不按日历今天筛选 |
| 日记范围 | 首次分析沿用原全范围；再次分析使用弹窗选中 session_ids；选择为空且 Notion 有正文时允许仅 Notion 分析 |
| 正文版本 | snapshot_version 记录索引版本；正文是提交时的读取结果，记录读取时间和摘要；不把它称为 Notion 历史正文版本 |
| 空正文 | 跳过已成功读取但为空的页面，保留空正文数；日记与 Notion 均无正文时任务记录 FAILED，不启动模型，页面提示选择有正文的来源；不保存空报告 |
| 读取失败 | 开启 Notion 时任何选定页面读取失败均阻止本次创建，不静默减少来源；关闭开关可继续日记分析 |
| 快照变化 | 预览版本与提交版本不同，或提交期间授权、挂载/快照改变时拒绝创建并提示重新加载 |
| 引用 | 日记只写 related_session_ids；Notion 使用独立 related_notion_page_ids，经校验后将标题和安全 URL 写入 evidence；索引版本、读取时间及摘要保存在报告来源元数据 |
| 并发 | 立即锁定提交，复用已有任务恢复；配置变化不修改进行中任务；过期候选响应不覆盖当前页面 |
| 长来源准备 | 当前登录会话仍有效时，沿普通续期完成同一本次提交，保留原内容选择；续期失败或来源变化明确反馈，不能缩减范围或另建已提交任务 |
| 存储 | default 为关闭 Notion 和未选 Agent；desired 保留在页面内存，effective 保存在任务；不增加全局配置或额外 revision；仅未确认创建结果的提交保存窄范围 request_key 与原始选项（无正文或凭证），成功或明确失败后清除；任务状态及 revision 沿用 Admin 合同 |

### 页面骨架

桌面：外层页面垂直滚动，面板自身超过可用高度时滚动，Agent 弹层沿用现有固定定位选择器。

```text
┌ 回归分析 ──────────────────────────────────────┐
│ 天数 / 日记 / 字数                               │
│ [历史回顾 → 时间轴] / 最新三份报告 → 阅读页                         │
│        [生成分析]  [分析内容 ▾]                  │
│                     ┌ 分析内容 ─────────────┐   │
│                     │ [ ] 将 Notion 加入分析 │   │
│                     │ 已挂载资源范围 / 状态   │   │
│                     │ 分析 Agent [默认 ▾]    │   │
│                     │   Deck 组 → Agent 选项 │   │
│                     └───────────────────────┘   │
│ 任务进度 / 失败反馈                              │
│ 回响 ⚙       性格特质 ⚙       行为模式 ⚙         │
│ 栏目配置弹窗、栏目进度和错误；无独立 Analyze      │
│ 栏目结果 / 历史报告                              │
└ 页面滚动 ──────────────────────────────────────┘
```

窄屏：两个主入口允许换行，展开面板在内容宽度内，栏目纵向排列；报告、已有日记范围选择和配置弹窗沿用现有响应式布局。

```text
┌ 回归分析 ───────────────┐
│ 统计 / 历史             │
│ [生成分析] [分析内容 ▾] │
│ ┌ 分析内容 ──────────┐ │
│ │ [ ] Notion         │ │
│ │ 范围、状态、重试   │ │
│ │ 分析 Agent [默认 ▾]│ │
│ │ 分组列表可滚动     │ │
│ └────────────────────┘ │
│ 进度 / 失败反馈         │
│ 回响 ⚙                 │
│ 性格特质 ⚙             │
│ 行为模式 ⚙             │
│ 报告内容（页面滚动）    │
└────────────────────────┘
```

### 状态与反馈

CREATED 表示已保存但尚未启动。进入页面只显示“有一项分析尚未开始”及“继续未开始的分析”，不自动调用模型、不锁定新生成。继续采用原任务输入；主生成采用当前选项。已启动任务仍自动订阅原任务并阻止重复生成。

未登录允许查看已有展示，但提交提示登录。未连接或授权失效分别显示连接或重新授权提示；无快照提示完成已有资源同步，空索引显示没有挂载页面，读取失败显示重试。展开不执行同步、工作区扫描或正文读取。Deck 加载失败显示重试，默认分析仍可用；已选 Agent 失效须由服务端拒绝，不能退回默认。 已选 Agent 从候选中消失时显示不可用名称及重选提示；Notion 候选版本变化时保留原选择并提示重新开启，不静默换用新范围。

执行失败保留错误；部分成功保留成功栏目并显示失败栏目。断流按已有任务恢复，不能因查询失败清除活动任务后另建任务。创建响应丢失时显示恢复提示，并使用原 request_key 和选项查询原回执；明确尚未创建的失败允许调整选择。保存失败保留当前结果并提供重试保存。服务端任务报告持久化是历史来源，页面不创建第二份全分析报告。

### Analyze Chat 预览标签（已实现）

Analyze 栏目执行所需的完整冻结输入继续由任务和 Chat 持久化边界保存，不删除、截断或改写。Chat 前端对能够精确识别栏目的服务器生成 user message 不再渲染原始 Markdown 气泡，只在原消息位置上方显示一个标签按钮：`回顾分析 · 重复回响`、`回顾分析 · 性格特质` 或 `回顾分析 · 行为模式`。

点击标签离开 Chat，进入现有回顾分析页，打开包含该栏目的最新已保存报告，并定位、聚焦 `ReflectionBlogPage` 已有的 `echoes`、`traits` 或 `patterns` 栏目按钮。Chat 不增加来源详情、展开、原文查看、加载、失败、重试、确认弹窗或第二个操作。

识别以服务器固定指令 `Complete this Reflections analysis in this turn.` 的最后一次出现为锚，只检查锚点之后的第一个 Markdown 一级标题是否完整等于三个默认工作流标题之一；不扫描锚点之前的 Notion/日记正文，也不按 XML、正文语义或大小猜测。锚点或首个标题不符合规则时保持普通消息渲染。现有消息没有 `task_id/report_id`，所以跳转语义是最新匹配报告，不猜测旧 Thread 对应的精确报告。

本规则只移除匹配消息的 `ChatMarkdown` 和超长 DOM，不减少历史消息的数据库读取、响应字节数或 JSON 解析。完整网络载荷仍是后续可测量风险，不在本轮通过新增接口解决。

桌面骨架：标签在原 user message 的右对齐位置，assistant final 保持原样；不显示空气泡或分析输入卡。

```text
┌ Chat 历史 ───────────┬ 当前会话 ────────────────────────────┐
│ <sessions_context>…  │                         [回顾分析 · 行为模式]
│ 普通对话             │                         （无原始 Analyze 气泡）
│                      │ 分析结果 final…                         │
└──────────────────────┴─────────────────────────────────────────┘

点击 → 现有回顾报告页 → [重复回响] [性格折射] [行为轨迹]
                                                    ↑ 对应栏目
```

375px 窄屏骨架：沿用单列消息滚动，标签空间不足时整体换行；跳转后目标栏目按钮进入视口并获得焦点。

```text
┌ 当前会话 ─────────────────┐
│       [回顾分析 · 行为模式]│
│       （无原始 Analyze 气泡）│
│ 分析结果 final…            │
└────────────────────────────┘

点击 → 回顾报告页的对应栏目按钮
```

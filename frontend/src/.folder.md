# frontend/src - Folder Contract

## Architecture Summary
React 19 app source for the Ink & Memory frontend.
Owns the app root, global styles, i18n setup, and first-level feature folders.
Routes view state through `App.tsx` while feature folders own focused UI behavior.
`App.tsx` keeps the chat workspace mounted after its first visit so chat-local state survives app-level view switches.

## File Table

| File | Pos | Function |
|---|---|---|
| `App.tsx` | `frontend app-root node` | Render the authenticated app shell, global views, mobile/desktop navigation, current view state, and preserved chat workspace mount. |
| `App.css` | `app-style sheet` | Provide app-level layout and theme styling. |
| `api/` | `frontend-api client dir` | Backend REST/SSE client helpers, including Claude Agent and Memory workspace initialization calls. |
| `constants/` | `frontend-constants dir` | Centralized frontend constants for storage keys and Edit Session sync timing values. |
| `engine/` | `editor-engine dir` | EditorEngine state/command model and editor widget data contracts. |
| `hooks/` | `frontend-hooks dir` | Session lifecycle, editing, comments, voice input, inspiration, copy/debounce, file upload, and Edit Session event subscription hooks. |
| `i18n.ts` | `i18n-config node` | Configure frontend translation resources and language defaults. |
| `index.css` | `global-style sheet` | Provide global CSS variables/base styles. |
| `lib/` | `frontend-lib utility dir` | Shared API base/runtime config, chat protocol, transport, and file proxy helpers. |
| `styles/tokens.css` | `frontend-theme-token sheet` | Provide semantic app theme tokens for shared UI styling. |
| `main.tsx` | `react-entrypoint node` | Mount the React application into the browser document. |

# 笔记分享组件

| 文件 | 职责 |
| --- | --- |
| `noteShare.ts` | 有序TextCell投影、公开DTO及正文SHA-256。 |
| `NoteContent.tsx` | 公开页面与PNG共用的文字呈现，保留换行。 |
| `exportNoteImage.tsx` | 离屏正文渲染、复用原分片捕获并释放临时DOM。 |
| `NoteShareDialog.tsx` | 冻结正文、保存/发布、复制恢复、图片预览和平台交付的操作状态。 |

## 统一分享改造

NoteShareDialog以ShareLinkOption接入统一发布与逐次状态检查；图片沿原捕获，NoteContent保留文字呈现。

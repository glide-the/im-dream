# backend/services/memory

| 文件 | 职责 |
| --- | --- |
| documents.py | 整理成功栏目、保留证据/推断/置信度，固定L3标签、版本及引文校验。 |
| policy.json | Admin单一发布源的逐字副本；四主题十六标签、复合表达/反馈规则，不是自由可执行prompt。 |
| files.py | 私有根、普通文件/非符号链接、临时文件/fsync/rename/摘要校验；丢失时恢复已存字节。 |
| worker.py | after-report discover/claim/stage/publish，canonical恢复与L3独立重试；无额外模型调用。 |
| behavior.py | fresh owner设置/immutable snapshot、当前消息与Thread边界、固定允许动作；不写事实或配置。 |
| __init__.py | 包入口。 |

由server管理Worker生命周期；Admin唯一管理memory_artifact与memory_behavior_settings。缺少精确capability时本域关闭，不绕过正常生产路径。

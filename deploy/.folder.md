# deploy/

## 架构概述
平台化发布脚本入口，按 local、docker、remote-ssh、google-cloud 分目录组织；根目录保留旧 Cloud Run 脚本兼容路径。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| README.md | 脚本入口说明 | 三类平台脚本入口、旧 Cloud Run 脚本兼容映射、通用参数约定 |
| local/ | 本地发布脚本 | 本地直跑检查、构建、启动、验证、停止和清理入口 |
| docker/ | Docker 发布脚本 | Docker Compose 检查、构建、启动、验证、停止和清理入口 |
| remote-ssh/ | Remote SSH 发布脚本 | 通过 SSH/rsync 同步仓库到已安装 Docker 的远程服务器，并在远端执行 docker-compose 构建、启动、验证、回滚和清理 |
| google-cloud/ | Google Cloud 发布脚本 | Cloud Run 主发布入口，默认使用固定公开域名 `ink-backend.suoxya.com` / `ink-frontend.suoxya.com`，承载完整构建、推送、部署、CORS 回写和验证流程 |
| setup-storage.sh | 兼容：存储初始化 | 委托 `google-cloud/setup-storage.sh`，保留旧调用路径 |
| setup-env.sh | 兼容：环境变量初始化 | 读 `backend/.env`，指定 key 写入 Secret Manager，其余配置汇总；输出根目录 `.cloud-env` |
| deploy.sh | 兼容：Cloud Run 部署 | 委托 `google-cloud/deploy.sh deploy`，保留旧调用路径 |
| sync-data.sh | 兼容：云数据同步 | 委托 `google-cloud/sync-data.sh`，保留旧调用路径 |

# docs/user/

## 职责

本目录保存面向ink-dream普通使用者的对外正文。每份文档只维护一个主题，使用ink-dream作为叙述主体。个人信息、服务费用和人工智能内容分别说明；发布条件、源码依据、审核操作和验证记录由内部上架资料维护。

## 文件清单

| 文件 | 定位 | 职责 |
| --- | --- | --- |
| [README.md](README.md) | 使用说明入口 | 按使用者的问题选择对应文档。 |
| [privacy-policy.md](privacy-policy.md) | 隐私政策 | 个人信息的收集、使用、共享、权限、保存和使用者权利。 |
| [subscription-and-usage.md](subscription-and-usage.md) | 订阅与用量说明 | 服务价格、周期、额度、取消和费用问题。 |
| [ai-usage.md](ai-usage.md) | 人工智能使用说明 | 提交内容、生成结果、使用边界和问题反馈。 |

Markdown文件为正文来源。网站静态版本位于`frontend/public/`，正文保持一致。当前版本为未生效草案；正式公布前的核定事项由[内部上架手册](../deploy/ios-app-store-release.md)维护。

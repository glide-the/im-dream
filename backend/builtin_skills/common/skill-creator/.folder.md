# backend/builtin_skills/common/skill-creator — Folder Contract

## Architecture Summary

Production built-in Skill authoring package. Workspace initialization links this
common source read-only into every full thread workspace under the canonical
lowercase ID `skill-creator`, then exposes the same source through
`.claude/skills/skill-creator` discovery.

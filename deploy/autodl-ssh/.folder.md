# deploy/autodl-ssh

## 定位

该目录是 Dream frontend/backend 在 AutoDL/SeetaCloud SSH 主机上的直接发布平台，与 `deploy/remote-ssh` 的 Docker、nginx 和 TUN 组合路径分离。

## 合同

- Vite Preview 监听 `127.0.0.1:6006` 并同源代理到 `127.0.0.1:8765` FastAPI；Admin 监听 `127.0.0.1:6008`，公网只映射前端与 Admin。
- Vite host policy 默认使用 Dream 公网 origin 的精确主机；显式 `AUTODL_VITE_ALLOWED_HOSTS=*` 才投影为 allow-all，用于动态 AutoDL 服务地址。
- 发布安装固定 Node/Python 依赖、构建版本化 frontend/backend release、SDK 0.2.144、由通用 Runtime 流程从授权 2.1.88 源码构建并在 Linux x64 Docker 中资格化的 local-core Runtime、官方 CLI 回滚件和 `ntn` 0.15.1；不使用 Docker 或 nginx。Linux local-core 的 `vendor/seccomp/<arch>/apply-seccomp` 是 Runtime 构建资产，不是 AutoDL 专用分支，并由制品摘要绑定。
- Dream 从 Admin 生成的安全 env 读取 PostgreSQL 身份，只消费 Admin-owned schema，不执行 migration 或 runtime DDL。
- Claude 插件的不可变 artifacts 位于数据盘的持久 runtime root；发布可幂等补充，但不得随版本化 release 删除，验收必须校验默认 Deck 插件。
- `AGENT_CWD`、actor-scoped `INK_NOTION_RUNTIME_ROOT`、`ARTIFACT_WORKSPACE_ROOT`、本地文件、服务 home 与 Claude plugin runtime 全部位于 `AUTODL_DATA_ROOT`；`init-dream-data.sh` 拒绝符号链接并幂等校正 owner/group/mode，Notion root 固定为 `0700`。
- Admin 与 embedded PostgreSQL 的 home 固定为 `/root/ink-autodl/data`，数据库目录为其下的 `postgres`；不得放回 Dream 数据根或 `/var/lib`。
- AutoDL env 投影不得写入 Agent 并发或内存预算覆盖；resource admission 使用应用默认预算并从宿主机与 cgroup 指标自动建立运行时快照。
- AutoDL env 投影必须覆盖来源值并固定 `INK_AGENT_SANDBOX_ENABLED=false`；Workspace Mode、Thread cwd/context/files、hooks 与工具确认保持启用，但 approved Bash 直接以 Dream `root` 身份运行，不获得 bubblewrap 文件系统/网络隔离。
- Dream 源码同步排除仓库根目录的虚拟环境、构建输出、artifact 与本地验证缓存；Runtime 只同步只读 verifier 合同和已经生产资格化的 Linux x64 package，AutoDL 不读取外部恢复源码，也不重新生成资格回执。
- npm 私有访问通过可选 `AUTODL_NPM_TOKEN` 生成临时 mode-0600 npmrc；安装完成立即删除，不写 runtime env 或日志。
- `screen` 只负责 SSH 断开后的进程存活；Dream 的 Vite Preview、FastAPI/Claude 及监督进程以 `root` 运行，确保 `/root` 下 workspace 安全协议可逐级固定目录描述符；Admin/PostgreSQL 仍使用独立非 root 用户。
- `runtime/start-ink-memory.sh` 仅恢复已经发布的 Admin → Dream 进程，不执行 GPU 探测、构建、migration、restore 或未知进程替换。
- `rollback` 只切换 Dream application release，不修改数据库、workspace 或 Admin。

## 入口

- `prepare-env.sh`：将 Dream 与 Admin 安全配置投影为 gitignored `.env`，固定全部 Dream 持久资源根、强制写入 AutoDL 的 disabled Bash sandbox capability，并允许显式投影 Vite `*` host policy。
- `platform.env`：从 `platform.env.example` 复制的、gitignored 的 SSH、端口与公网映射配置；`prepare-env.sh` 和 `deploy.sh` 自动读取。
- `deploy.sh`：`check|plan|sync|build|deploy|start|stop|status|logs|verify|rollback`。
- `runtime/start-dream.sh`：screen 内同时监督 Vite Preview 与 uvicorn 的前台入口，并从显式 agentdata root 绑定 Agent/Notion runtime 路径。
- `runtime/init-dream-data.sh`：部署与独立启动共用的持久目录初始化器，创建私有 Notion user-credential root。
- `runtime/start-ink-memory.sh`：由 Dream `sync/deploy` 安装到 `/root/ink-autodl/start-ink-memory.sh` 的独立幂等启动脚本。
- `test-topology.sh`：provider-free 校验 env 投影、目录幂等性、owner/mode 与 symlink fail-closed。
- `README.md`：面向 AutoDL 使用者的应用介绍、AutoDL 注入的 6006/6008 公网映射安全查询、启动步骤、状态检查和日志入口。

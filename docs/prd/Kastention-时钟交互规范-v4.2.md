# Kastention 时间化思维时钟 · v4.2 动效修订

**原型**：`Kastention-一体化时间时钟-v4.2-离散跳针与发丝.html`  
**设计依据**：原始 `startup.svg` / `startup-dark.svg` 与《Ink & Memory 应用界面设计规范 v3.0》。  
**修订范围**：仅时间推进、表情模式切换及发丝动画；原脸型、双眼、蓝色头发主造型和十二时位交互不做视觉重绘。

## 1. 时间推进的基本规则

| 指针 | 触发条件 | 每次位移 | 行为 |
|---|---|---|---|
| 秒针 | 当前秒数变化 | 顺时针 **6°** | 每秒一次离散跳格 |
| 分针 | 当前分钟变化 | 顺时针 **6°** | 每分钟一次离散跳格，其余时间静止 |
| 时针 | 当前小时变化 | 顺时针 **30°** | 每小时一次离散跳格，其余时间静止 |

例如，**11:59:59 → 12:00:00**：三根指针同时触发一次跳格，秒针与分针从 354° 越过正上方至 0°，时针从 330° 至 360°（显示等价于 0°）。指针只经过一个时位的角度，不以多圈旋转表现时间切换。

这是一种**离散、机械节律的时间表达**。时间刻度的粒度不是现实机械时钟的齿轮级模拟：这是按产品要求明确设定的小时、分钟、秒三级跳变。

## 2. 单次跳格时间轴

每个指针使用同一组归一化阶段，持续时间略有区别：

| 阶段比例 | 视觉动作 | 位移占当前格角度的比例 |
|---|---|---|
| 0–30% | 停留 | 0 |
| 30–51% | 缓慢起动 | 0 → 7.5% |
| 51–69% | 快速跃迁 | 7.5% → 106.5% |
| 69–81% | 轻微回弹 | 106.5% → 98.5% |
| 81–100% | 归位停止 | 98.5% → 100% |

- 秒针：240 ms
- 分针：300 ms
- 时针：355 ms

动画由 `animateTransform` 执行，变换围绕原始指针中心 `(625, 650)`。采用同角度的无回放规范：每次最多推进一格，模式切换不会触发旋转。

## 3. 头发：三种状态通用的逐秒摆动

原始头发的三个 `<path>` 保留各自基准路径。每一秒钟从上一秒进入下一秒时，调用三组事先声明的 SVG `animate`，对三次贝塞尔曲线的控制点作有限幅度偏移，再恢复原路径。

- 触发：每个正常连续整秒一次，**时钟、开心、悲伤三种模式均生效**。
- 时长：520 ms；预摆、上抬、回落、余摆、复位。
- 改变：只改变 `d` 中与头发有关的三次贝塞尔控制点；不改脸部轮廓与眼睛。
- 每秒触发时无需计算贝塞尔点坐标，`values` 已预先声明在 SVG 中。
- 从后台切回前台时直接同步真实时间，不把遗漏的多次头发摆动补播。

## 4. 模式切换

点击整个脸部（刻度不受影响），循环：

`时钟 → 开心 → 悲伤 → 时钟`

- 时钟：显示三根指针；原来的表情元素弱化。
- 开心：隐藏三根指针；嘴部使用原 SVG 开心贝塞尔路径。
- 悲伤：隐藏三根指针；仅把嘴部曲线变为向下的贝塞尔形状。
- 切换时不改变时间，不旋转指针，也不改变任一刻度的含义。
- 嘴部从开心至悲伤的路径过渡约 290 ms；其它部分不变。
- 处于开心/悲伤状态时，三个指针在视觉上隐藏，但内部每个时间边界仍自动更新，使返回时钟模式后能直接显示当前时间。

## 5. 运行开销与适用边界

时钟仅维护一个与实际整秒对齐的 `setTimeout`。每秒进行一次时刻比较、一次数字读数更新，并按条件调用浏览器原生动画：

- 普通整秒：一次秒针动画，三次头发路径动画。
- 分钟边界：秒针与分针各一次，三次头发路径动画。
- 小时边界：时针、分针、秒针各一次，三次头发路径动画。
- 无 `requestAnimationFrame` 动画循环，无每帧几何运算、弹簧数值积分或贝塞尔采样。
- 系统启用“减少动态效果”时，指针直接定位，头发与嘴部形变不播放。
- 页面在后台时暂停计时回调；重新显示后与设备本地时钟对齐。

说明：SVG `d` 形变需要浏览器进行路径重算，因此比纯 `transform` 的渲染代价更高。本设计把每秒形变限制在三个较小路径、520ms 内，减少额外脚本计算；在低端设备上仍建议实机检查 CPU 与渲染帧率。

## 6. 验收记录（Chromium 浏览器原型）

- 桌面宽度 1190px、移动宽度 390px 和 320px 均无横向溢出。
- 3 点概念刻度选中后只切换说明文字，不带动指针旋转。
- 点击脸部循环切换三种模式；无状态切换转圈动画。
- **12:58:58 → 12:58:59**：仅秒针动画。
- **12:58:59 → 12:59:00**：秒针、分针动画。
- **12:59:59 → 13:00:00**：秒针、分针、时针动画。
- 原生 SVG 头发贝塞尔路径已在动画过程中发生可测量的几何形变，播放结束后恢复基准形状。
- Web Chromium 的上述行为已测试；Safari、Android WebView、React Native 原生版本及真机性能仍待项目环境验收。

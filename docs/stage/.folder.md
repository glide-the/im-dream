## Maintenance Rules

- 依赖变化时同时更新 Mermaid、阶段表、验收和回滚。
- 只在当前候选上存在命令、退出码、关键输出和可回读证据时声明技术完成。
- 旧版本或旧 lock 的结果必须标明历史适用范围。
- 真正的安全或运行条件缺失时 fail closed，并保留普通业务路径。

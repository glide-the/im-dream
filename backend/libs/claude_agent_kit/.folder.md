# backend/libs/claude_agent_kit — Folder Contract

## Architecture Summary
Claude Agent Kit 层，**直接复制自 Pawkeyland `libs/claude_agent_kit/`** 原结构。  
保留 `server/`、`messages/` 子目录和所有文件，仅做最小路径适配。  
被上层 `backend/claude_agent/` 应用层消费。

## Migration Source
Pawkeyland `libs/claude_agent_kit/` — 直接复制原结构。

**最小适配（不改变业务逻辑）**：
- `_PROJECT_ROOT`：`parents[3]` → `parents[4]`（`backend/` 增加了一层）
- workspace 默认目录名：`claude-agent-workspaces` → `ink-agent-workspaces`
- `server/__init__.py`：MCP server factory import 加 try/except 保护（mcp 包未安装时降级）
- `libs/volcresource/cfg.py`：stub 实现（返回空配置），让 sdk_env 降级到直接读 `ANTHROPIC_*` 变量
- `infrastructure/`、`prompts/policy_loader.py`：stub，necklace/mem0 工具不可用时静默失败

## Key Constraints
- 不依赖 `claude_agent/` 应用层（单向依赖：应用层 → kit 层）
- SDK 配置通过 `.env` 中的 `ANTHROPIC_*` 变量（volcresource stub 降级处理）
- `AGENT_CWD` 控制工作区根目录，默认 `ink-agent-workspaces`
- Pawkeyland 专属 MCP（necklace/mem0/animation）在 Ink & Memory 中不可用，不影响核心 Runner

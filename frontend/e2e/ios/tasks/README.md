## 每项任务记录

任务按`<业务目标>-<日期>.md`命名，正文包含：

1. 任务目标、范围、允许的操作和业务写入。
2. App ID、版本/构建号、提交、目标平台/系统，以及设备身份的受限回执位置。
3. 实际Swift文件、测试类、方法和runner工程；缺失或私有生成物按实际位置标注。
4. 测试前页面、会话、设备、签名和信任条件；真实业务与fixture分别说明。
5. 步骤、目标元素、预期状态、成功及失败断言。
6. 实际命令、退出码、方法是否执行、结果、xcresult/截图位置，以及未执行范围。
7. 失败原因、后续依赖和本轮生成物清理范围。

## 状态规则

| 状态 | 判定条件 |
| --- | --- |
| 文档准备 | 已定义目标、步骤和验收；尚无本轮运行回执 |
| 前置失败 | 设备、工程、签名或runner失败，测试方法未执行 |
| 断言失败 | 方法已执行，预期元素、动作或结果未满足 |
| 通过 | 目标设备上选定方法的预期断言全部通过，证据可定位 |
| 用户手工确认 | 用户提供的实际操作结果，单列来源和范围 |

每轮保留独立结果，重试沿新运行号保存。命令退出0、页面效果、后台业务和商店发布按实际证据分别登记。Simulator结果注明Simulator；真机结果注明设备与安装版本。

本目录仅保存任务Markdown及目录合同；AppleScript、桌面镜像操作、ZIP、安装包、xcresult及截图退出该任务目录。账号、Cookie、Bearer、授权code/state、PKCE及正文均排除Git任务记录。旧内容的原文、摘要与私有恢复包见[历史快照](../../../../docs/exec/history/ios-debug-tasks-before-xcuitest-20261102.md)。

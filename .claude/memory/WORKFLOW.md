# Memory Workspace Workflow

## 决策树：记忆工作流程

当你收到用户消息时，按以下顺序执行记忆工作流：

```
┌─────────────────────────────────────────┐
│           收到用户消息                    │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│  Step 1: 记忆检索 (Memory Query)          │
│  读取 memory/MEMORY_QUERY_PROMPT.md      │
│  → 从对话历史和存储中检索相关记忆           │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│  Step 2: 记忆蒸馏 (Memory Distillation)   │
│  读取 memory/MEMORY_Distiller_PROMPT.md  │
│  → 从当前对话中提取关键信息               │
│  → 输出：事件摘要、情感基调、关键实体      │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│  Step 3: 记忆输出 (Memory Answer)         │
│  读取 memory/MEMORY_ANSWER_PROMPT.md     │
│  → 基于检索到的记忆生成回应              │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│  Step 4: 记忆更新 (Memory Update)         │
│  读取 memory/DEFAULT_UPDATE_MEMORY_PROMPT.md │
│  → 决定是否更新长期记忆存储               │
│  → 支持：添加 / 更新 / 删除 / 无变化      │
└─────────────────────────────────────────┘
```

## 记忆类型说明

| 类型 | 存储位置 | 更新频率 | 说明 |
|------|----------|----------|------|
| **短期记忆** | 当前对话上下文窗口 | 实时 | 最近 10 轮对话的即时上下文 |
| **长期记忆** | `memory/long_term_memory.md` | 每轮对话后 | 历史对话的摘要和关键信息 |
| **程序性记忆** | `memory/procedural/` 目录 | 业务规则触发时 | 结构化的业务规则、用户偏好、事件记录 |

## 文件结构

```
memory/
├── WORKFLOW.md                    ← 本文件：工作流程定义
├── MEMORY_QUERY_PROMPT.md         ← 记忆检索提示词
├── MEMORY_Distiller_PROMPT.md     ← 记忆蒸馏提示词
├── MEMORY_ANSWER_PROMPT.md        ← 基于记忆的回答提示词
├── DEFAULT_UPDATE_MEMORY_PROMPT.md ← 记忆更新规则
├── long_term_memory.md            ← 长期记忆存储（运行时生成）
└── procedural/                    ← 程序性记忆目录（运行时生成）
    ├── user_preferences.json      ← 用户偏好
    ├── important_events.json      ← 重要事件
    └── timeline.json              ← 时间线记录
```

## 何时读取记忆

- **每轮对话开始**：执行 Step 1 记忆检索
- **需要个性化回应时**：读取用户偏好和历史偏好
- **用户提及过去事件时**：检索相关程序性记忆

## 何时写入记忆

- **对话结束或重要信息出现时**：执行 Step 4 记忆更新
- **用户明确告知偏好时**：立即写入程序性记忆
- **发生重要事件时**：写入事件记录

## 约束

- 不要在每轮对话都完整执行所有步骤 — 仅在必要时执行
- 程序性记忆文件为 JSON 格式，遵循预定义 schema
- 长期记忆以 Markdown 格式存储，便于人工阅读
- 删除记忆前必须有充分理由

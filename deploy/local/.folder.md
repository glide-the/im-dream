# deploy/local/

## 架构概述
本地直跑发布脚本目录，复用 `backend/server.py` 与根 Next.js 项目 `frontend/package.json` 的 pnpm 启动方式；
数据库由相邻 Admin `@ink-memory/db` supervisor 管理，Dream 只调用 Admin auth/data API。

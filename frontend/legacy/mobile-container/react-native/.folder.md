# mobile/react-native

RN拥有启动、失败恢复、一级导航和More入口。`InkBusinessSurface`复用iOS原WKWebView控制器，持有同一Cookie容器、桥和业务页面。原生`EmbeddedDreamBackend`持有解释器、Node与HTTP；RN管理器合并启动请求。Android原生接线独立实施。

| 文件 | 职责 |
| --- | --- |
| `package.json`、`pnpm-lock.yaml`、`.npmrc` | 锁定RN 0.81.5、React 19.1和构建工具；独立依赖目录 |
| `index.js`、`babel.config.cjs`、`metro.config.cjs`、`react-native.config.js`、`tsconfig.json` | 注册InkMemory、构建本地bundle并定位既有iOS工程 |
| `src/App.tsx` | RN启动/失败页、恢复层、Chat/Decks/More、键盘与主题 |
| `src/runtime/BackendRuntimeManager.ts` | 共享启动promise与公开就绪事实 |
| `src/web/BusinessWebSurface.tsx` | 绑定原生持久业务视图，传递路径与公开状态 |

业务接口、消息、Cookie、CSRF与权限继续由原Web页面及后端拥有。RN Root重挂载与页面导航不停止后端。发布包从bundle运行，运行时无需Metro。

# docs/design/deck — Folder Contract

## Architecture Summary

Deck product requirements, current interaction contracts, capability boundaries, and implemented
behavior. The Deck route projects at most fourteen enabled icons while the
launcher separates user Available Decks from registered System Decks; both open the same read-only
preview page before typed Chat/Dream trial or user maintenance. The
Settings / Work category owns full Deck/resource/plugin management and related Chat cleanup. The original create-then-full-maintenance-popup remains active;
all effective form changes advance one durable aggregate draft, explicit commits create immutable
Deck vN snapshots, runtime binding history remains secondary, and Workflow is excluded.

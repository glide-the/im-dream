# backend/routers — Folder Contract

## Architecture Summary
FastAPI router modules for authenticated REST/SSE API boundaries.
Routers validate Admin request actors and delegate migrated Chat ownership/persistence to typed Admin consumers; remaining domains still use their existing database/service modules until migrated.
Business logic stays in focused backend modules rather than route handlers when reusable.

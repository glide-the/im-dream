# 原生品牌图片

| 文件 | 职责 |
| --- | --- |
| `app-icon-reference.png` | 用户第一张160×134图标参考；高清图标位于iOS AppIcon资源集 |
| `startup.png` | 用户第二张1254×1254原图，保留来源参考 |
| `startup-artwork.json` | 角色轮廓、五官与蓝白帽子的七条矢量路径；静态SVG与统一时钟生成资产共用，脸部及画布透明 |
| `startup.svg` | 同一路径生成的独立透明SVG，线稿使用currentColor |

`node frontend/ios/scripts/sync-startup-artwork.mjs --write`生成独立SVG及iOS `StartupArtwork.imageset/`内的深浅色SVG；`--check`验证路径一致性。系统启动页和iOS诊断按钮共用该资源集，RN准备页与屏保沿统一入口使用同源路径和预声明关键帧。iOS线稿色读取`inkColors.ts`现有文字色，主背景由原宿主提供。PNG参考图保持原始字节。图片内容作为视觉素材。

`kastention-clock-v4.2.json`从用户提供的v4.2 HTML与原七条SVG路径生成，包含十二时位及离散跳针／发丝关键帧。生成器复用现有字体工具fontTools 4.60.1；原SVG、PNG及系统静态图标来源保持。

# 原生合同校验

`check-bridge-contract.mjs`校验已有协议及平台常量；`check-web-assets.mjs`仅校验显式提供的历史网页资源制品。RN主发布链使用Metro bundle、Next构建与Xcode/Gradle，旧网页制品校验退出发布前置步骤。

`check-original-ui-contract.mjs`比对原Web图标与已迁移Native图标的几何、原CSS与Native颜色值。该检查只证明已列明的视觉资源合同，整页视觉与真实业务分别验收。

`prepare-deck-icons.mjs --write`从原`deckVisuals.ts`及锁定安装包提取12个固定SVG路径和5个CSS token名，写入`shared/deck-icons.json`；默认执行逐字数据校验，`check-original-ui-contract.mjs`复用该校验。第三方包与Web图标源码保持。生成数据保留包版本、原文件归属、Font Awesome署名与CC BY 4.0链接。

原Deck预览使用的`FaPlay`投影为独立`actions.play`，归属`DeckManagerPanels.tsx`；`DeckPlayIcon`直接渲染同一几何。配置图标的12个键和未知键回退保持；操作图标单独命名，Native Try now使用原SVG和颜色，Unicode emoji退出该入口。

图标检查同时读取createIcon声明和函数式IconStop的SVG、填充及子节点几何，原Stop保持实心圆角方块，原ArrowUp保持线段与折线。新增原生组件仅迁移实际消费的图标。

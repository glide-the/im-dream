# backend/claude_agent — Folder Contract

## Architecture Summary
Claude Agent 应用层，迁移自 Pawkeyland `application/claude_agent/`。  
提供流式 AI 写作助手的业务逻辑（会话管理、上下文组装、SSE 事件），  
依赖 `backend/libs/claude_agent_kit/` 提供 SDK 封装和类型。  
与现有 PolyCLI agent 会话完全隔离。

## Migration Source
Pawkeyland `application/claude_agent/`（已移除 pet/persona/mem0/necklace 专属逻辑）。  
Kit 层（types/runner/workspace）已移至 `backend/libs/claude_agent_kit/`。

## Two-Layer Architecture
```
backend/libs/claude_agent_kit/   ← Kit 层：SDK 封装、类型、工作区
backend/claude_agent/            ← 应用层：业务逻辑、会话编排（本目录）
```

## Persistence Contract (aligned with better-chatbot)
`_persist_turn` 在成功的 agent turn 后保存两条 `chat_message` 记录：
- **user**：原始文本 + `parts_json`（含附件等 AI-SDK parts）
- **assistant**：`parts_json` 包含所有 `reasoning` + `tool-invocation` + `text` parts，`metadata` 含 usage/model/toolCount

`tool_use` 事件（非流式 AssistantMessage 路径）在 `emitted_tool_input_ids` 去重后同步创建 `inv_part` 并注册到 `tool_inv_by_id`，`tool_result` 到来时 in-place 更新 state 和 output。

每次成功 turn 后，`_persist_turn` 还会将 `result.session_id`（Claude SDK 分配的 session ID）和 `_AGENT_RUNTIME_CONTRACT_VERSION` 写回 `chat_thread.claude_session_id` / `agent_contract_version`，下一轮 `assemble_context` 据此决定是否 resume。

## Key Constraints
- 不导入 PolyCLI / polyagent / polycli 模块
- 不定义 `@session_def` — 路由在 `server.py` 注册
- Kit 层导入：`from libs.claude_agent_kit import ...`
- `session_id = user_id`（无 persona 维度；可扩展为 `user_id__tag`）

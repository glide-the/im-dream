# Dream auth routes

| File | Pos | Function |
| --- | --- | --- |
| `start/route.ts` | Login entry | Admin code/PKCE redirect with restricted relative return. |
| `callback/route.ts` | Exact registered callback | Original state/issuer/PKCE transaction to opaque cookie; unknown exchange preserves recovery. |
| `session/route.ts` | Browser state | Public current-user fields and handle-bound CSRF, no OAuth token. |
| `logout/route.ts` | Logout | Exact origin/CSRF then Admin revoke; clear cookies on success. |
| `device/route.ts` | Device entry | Capability-checked redirect to Admin device review/approve/deny UI with optional user_code. |
| `me/route.ts` | Profile alias | Shared authenticated BFF proxy to existing Python/Admin public profile. |

All routes delegate to [the same private owner](../api/_auth/handlers.ts). No route owns a password hash, signs JWTs, reads PG, enables deferred ASR or changes Agent/SSE/lease behavior. Configuration must register the actual callback URI and exact Dream/Admin origins. Candidate routes are not a claim of frontend/Runtime/full-domain migration or deployment.

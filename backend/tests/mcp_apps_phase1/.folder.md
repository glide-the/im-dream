# MCP Apps Phase 1 backend tests

Provider-free tests for the Node-only connection projection. Tests use injected
repositories/loaders and never create schema, contact providers, or decrypt real
credentials. DTO fixtures use the official demo identity but do not claim to
exercise the missing offline official artifact.

| File | Function |
|---|---|
| `test_connection_view.py` | Proves pre-decryption actor/enabled/config+credential+policy revision/expiry/catalog checks, authoritative expired-OAuth refresh revision, and redaction. |
| `test_result_identity_projection.py` | Proves exact managed-registration and workspace ownership, complete success-result preservation, live/persisted/public transport, error-result ordinary fallback, and projection-only fail-closed rejection. |

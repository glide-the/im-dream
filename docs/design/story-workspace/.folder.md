# docs/design/story-workspace — 目录合同

## 架构摘要

Story Workspace 当前产品设计集，定义 Dream/Chat 重入、Project/Episode 工作台、Artifact 读取、Skill 同步和 Thread 绑定冲突恢复。

## 文件清单

| 文件 | 定位 | 职责 |
|---|---|---|
| `README.md` | 业务设计索引 | 汇总当前模块、跨系统合同与权威规则 |
| `artifact-reading-and-degradation.md` | Artifact 读取设计 | 定义文件投影、revision、缺失和降级显示 |
| `dream-workspace-and-reentry.md` | Dream 重入合同 | 定义 Run 发现、同一 Thread 恢复、当前 Agent 与输入状态 |
| `product-scope-and-navigation.md` | 产品范围 | 定义角色、信息架构、路由和响应式外壳 |
| `project-and-episode-workbench.md` | 创作工作台 | 定义 Project、Episode、故事线、场景和镜头阅读编辑 |
| `settings.md` | 设置设计 | 定义 Story Workspace 设置入口与无障碍 |
| `skill-commands-and-workbench-sync.md` | Skill 与同步 | 定义 Slash 建议、自由调用和成功 Hook 自动同步 |
| `thread-binding-conflict-recovery.md` | Thread 冲突交互 | 区分 launch provenance 与当前 Agent，定义真实冲突错误契约、保留和恢复 |

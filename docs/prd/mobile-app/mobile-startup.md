# 移动端异步启动与开发者页 PRD

本次任务的产品设计集中在本文。页面骨架见[启动页](#启动页)和[开发者页](#开发者页)；操作时序、状态和生命周期见[独立交互设计](../../design/multi-platform/mobile-startup-interaction.md)。

## 背景与问题

用户希望Python异步启动，前端在准备期间可见，并能查看最简运行状态。当前后台启动路径直接复用；首次登录与业务操作继续等待原依赖。

## 目标与边界

新增状态展示和入口已接入源码：复用现有异步启动、原准备页面和同一个只读开发者页。原登录、权限、输入、任务和恢复规则保持。技术回归和模拟器专项回执归[专项评审](../../exec/mobile-startup-design-review-20261101.md#模拟器验证2026-11-01)。此前模拟器验证复用原Native/运行资源；新增原始错误日志已通过技术与模拟器验证，回执归专项评审。构建24已覆盖安装至原iPhone并普通启动，物理页面与完整业务验收待执行。

性能专项、分段监控、重启、停止、清理、终端和自动修复退出范围。普通Web沿原页面，桌面骨架作为宽屏布局参照。

## 概念与规则

1. 打开应用先显示原框架和准备反馈；后台启动完成后检查原会话，再显示原登录或业务导航。开发者入口在准备、未登录及错误视图均可达。
2. 登录后沿“更多 → 设置 → 关于 → 开发者控制页”进入同一页。返回保留原页面实例、输入和已有任务；会话失效与进程重开沿原恢复规则。
3. 页面显示原启动调用保存的启动中、就绪或失败、总耗时、更新时间和启动错误码。原会话读取结果单独展示；公网连接显示“未单独观测”。总耗时在启动返回后显示，准备中显示尚未完成。
4. 错误日志显示本次应用中启动、登录会话、配置读取及Agent目录各来源最近一次错误的时间、来源和原文。原始错误信息、错误码、路径和堆栈直接展示，复制保留相同原文。读取恢复后保留最近错误，当前运行状态单独显示；进程重开清空本次记录。
5. 刷新只重读已有状态；复制诊断摘要在原位置显示结果。离页释放观察，后台暂停，前台重读。记录范围为原调用返回的错误，页面仅读取本次记录。
6. 启动失败沿原边界提示重开应用；原登录、配置与历史失败继续各自读取重试。准备期间业务操作按原条件等待，自动业务重发为零。
7. iOS应用图标使用用户第一张参考图的高清方形稿，保留黑色笑脸与浅米色纸张。第二张蓝色角色重绘为透明矢量，只保留轮廓、五官和蓝白帽子，脸部与外围透出当前主背景。线稿随深浅色主题显示，准备期间轻微呼吸；准备完成或失败后随准备视图移除。应用就绪即继续会话与登录流程，动画无最短播放时长。
8. 品牌区由角色和现有手写字体的Ink & Memory组成，位于页面中部偏上；准备状态与开发者入口位于底部安全区，保留独立触控范围。窄屏和横屏缩小角色，角色、名称与底部反馈保持间距。呼吸动画在后台、开发者页打开及系统开启减少动态效果时暂停。图标与系统启动资源本次接入iOS，Android系统资源及设备显示继续单独交付。

## 页面设计

### 启动页

准备页采用当前应用主背景，品牌区显示透明矢量角色与手写字标，底部独立显示“正在准备”或会话检查反馈及开发者入口。系统启动阶段静态显示相同矢量角色，进入准备页后接续呼吸。启动失败时显示原恢复说明；登录、会话读取重试沿原条件展示。

```text
窄屏启动页（当前主背景贯穿全页）
┌─────────────────────────────────────┐
│                                     │
│        透明线稿与蓝白色块             │
│          Ink & Memory               │

│          [开发者控制页]              │

失败后沿原错误、重试或重开说明，无新增确认弹窗。

桌面宽屏参照（移动准备视图的宽屏布局）
┌──────────────────────────────────────────┐
│                                          │
```

### 开发者页

两个入口进入同一页：准备/未登录/错误视图的“开发者控制页”，以及“更多 → 设置 → 关于 → 开发者控制页”。返回时保留原页面实例，显示其当前结果。

状态区展示已有启动结果、总耗时、更新时间、本地就绪、原会话读取结果和启动错误码；公网连接显示未单独观测。缺少信息显示未观测。操作区固定，状态内容独立纵向滚动。启动状态下方直接显示错误日志，原文可选择复制；日志与其他状态共用纵向滚动区。刷新与复制结果在原位置提示。

## 验收

核对准备期间页面可操作、原就绪和认证条件、失败反馈、重复启动、前后台及进程重开恢复，以及开发者页刷新/复制的只读行为。方法及证据要求归[专项评审](../../exec/mobile-startup-design-review-20261101.md#验收计划)。本轮文档检查与程序、真实设备验收分别报告。

账号入口失败时，用户关闭原登录窗口后可在现有开发者控制页查看最近一次登录、注册或Google错误及时间。取消授权继续原返回行为。刷新与复制读取当前记录，错误恢复后保留最近记录至进程退出；页面入口、骨架和启动状态保持。

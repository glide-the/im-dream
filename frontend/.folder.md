# frontend/

## 架构概述
React 19 + Vite + TypeScript SPA，部署路径 `/ink-and-memory/`，容器化方案为多阶段 Dockerfile（Node 构建 → nginx 服务）。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| Dockerfile | 容器构建 | 多阶段构建：Node 22 编译 → nginx 1.27 服务静态文件 |
| nginx.conf.template | 反向代理模板 | 服务 `/ink-and-memory/` 静态文件；`${BACKEND_URL}` 在容器启动时由 envsubst 替换（本地=内部服务名，Cloud Run=HTTPS URL） |
| .dockerignore | 构建优化 | 排除 node_modules、dist、.env 等 |
| package.json | 依赖管理 | npm 依赖声明，`npm run build` 输出到 `dist/` |
| vite.config.ts | 构建配置 | base `/ink-and-memory/`，dev proxy 到 localhost:8765 |
| src/ | 应用源码 | React 组件、路由、API 调用 |
| public/ | 公共资源 | 无需编译的静态资源 |

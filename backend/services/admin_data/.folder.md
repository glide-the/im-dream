# Admin authentication/data consumers

## 架构概述

统一消费Admin OAuth和领域数据协议，无PG/SQL/fallback。现Product客户端绑定HS256与Product专属过滤，不能复用为全域transport；保留其业务DTO，接入时迁移authority。

| File | Pos | Function |
| --- | --- | --- |
| `__init__.py` | 包公开边界 | 导出配置、安全错误与OAuth verifier |
| `config.py` | server-owned配置 | 固定Admin origin/issuer/resource/service secret和timeout/JWKS/响应大小 |
| `models.py` | wire DTO | strict Pydantic principal/capabilities/browser-session/receipt，canonical ID保持string |
| `client.py` | Internal DTO consumer | 独立service ID/credential与用户Bearer；注册领域DTO、capability匹配、无自动重试、未知提交/receipt恢复 |
| `errors.py` | 错误边界 | 不保存HTTP request/token/body/上游message，区分未知提交；仅DECK_VERSION_CONFLICT保留strict两项revision详情 |
| `jwt_verifier.py` | Resource Server | PyJWT ES256/at+jwt/时间/issuer/audience/scope；有界JWKS缓存刷新；不猜canonical用户ID |
| `resource_models.py` | Resource policy DTO | strict desired/state union，精确安全整数/组合字节，RootModel 保持原 wire JSON |
| `resource_data.py` | Resource domain adapter | Admin 实际双向 contract hash；composition root 后台 reader/observer；unknown 原 request_id 回执恢复 |
| `chat_models.py` | Chat strict DTO | 14个Thread/message输入输出，JSON/角色/decimal/null/微秒ISO原样，复用纯final-history validator |
| `chat_data.py` | Chat typed consumer | 14个实际双向hash候选、显式actor token和原request_id；生产Chat CRUD/history/ownership已接入，后台persist/title/session委托待接 |
| `profile_data.py` | Current-user typed consumer | 第17个实际合同候选；空input，闭集profile，保留原Dream公开字段与微秒时间 |
| `http_transport.py` | Shared HTTP parser | 显式URL/header/DTO，有界响应与no retry；prepared request禁止继承client cookie/auth/header |
| `delegation.py` | Purpose Runtime consumer | server create按实际三identity及0033 unified schema与四special-route method/path/hash广告；public renew/revoke/receipt只持idg，immutable entity/scope/maximum |
| `delegation_keeper.py` | Server grant lifecycle | 到期前后台renew，unknown保留原ID先receipt，absent不重发，最大寿命和purpose保持；尚未接入Agent lifecycle |
| `retired_auth.py` | Retired issuer response | 只读公开Admin origin/issuer/resource；旧签发/refresh路径410，无密码/code/cookie解析或HTTP/DB动作；配置非法503 |
| `request_auth.py` | Request identity owner | 生产共享依赖验证JWT/principal精确subject/client/scope，immutable显式actor与profile ID匹配；composition root关闭时释放自有连接 |
| `workflow_data.py` | Workflow typed read/snapshot | 唯一thread input与实际十字段strict DTO；exact identity/unified schema与operation hash；公开Chat转不可变actor/thread snapshot，不复制Admin图/hash/SQL规则 |

资源操作 input/output 版本均为1；pins来自Admin实际 [operation artifact](../../../docs/architecture/admin-auth-data-interaction.md)。缺广告/hash不匹配/网络或响应错误 fail closed；provider保留LKG。observer未知写尚无committed回执时阻止后续snapshot写入，不能认为absent意味着失败。历史 `resource_postgres_sink` 名称继续作为内部标识，已无SQL；不借文档清理更改Agent接口。

Runtime四special route在`auth.delegations`单独广告，不走generic data operation dispatch；缺schema/任一路径、method、version/hash不匹配时create fail closed。当前create digest按Admin实际非空text IDs生成，不额外增加160字符业务限制。public Runtime config仅含Admin origin与transport边界，无service/DB/Gateway秘密。Keeper源码技术验证不代表CLI/Editor/后台持久化已接入。

公开Chat Workflow context在已有Deck/Voice绑定后、message预留/SSE前通过明确OAuth读取；read failure拒绝，null不会触发旧PG mapper。Service只接收与actor/thread匹配的immutable snapshot；内部confirmation/launch仍保留原guard/mapper，未据此声明全Workflow/Runtime迁移。

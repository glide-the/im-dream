# frontend/src/engine — Folder Contract

## Architecture Summary
EditorEngine owns the in-memory and serialized Writing document state, including distinct Text, Widget, and WritingSuggestion Cells plus the Session-owned Writing Thread reference.
Widget data models live beside the engine so UI hooks/components consume one shared editor state contract.

## File Table

| File | Pos | Function |
|---|---|---|
| `EditorEngine.ts` | `editor-engine node` | Maintain EditorState, distinct persistent WritingSuggestion Cells, one Session Thread reference, text/widget/comment commands, prose-only weight accounting, reload interruption recovery, and stale-response-safe suggestion mutations; ordinary edits never call a model. |
| `ChatWidget.ts` | `chat-widget model node` | Define chat widget data shape consumed by editor widgets and chat UI. |
| `__tests__/` | engine behavior tests | Lock production EditorEngine state and network boundaries. |

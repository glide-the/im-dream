## Architecture Summary

Deck 工作流插件定义 Dream 类型 Deck 的版本化业务工作流及其与 Dream Agent、Dream 工作台的连接；Dream 工作台产品规则由 `docs/prd/dream-workspace/` 独立负责。Claude Code Plugins 服务创建或编辑思维模式时的插件清单选择。两类插件各有独立 PRD 和交互设计。
历史工作流集成、安装管理和远程来源同步不构成新的用户插件分类。
远程 Marketplace 发布平台尚未设计。当前重复界面和技术文案仍是待处理的实现差距。

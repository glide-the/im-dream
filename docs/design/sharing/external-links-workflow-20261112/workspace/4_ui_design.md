# 第四阶段：外部链接管理呈现规范

## 背景与问题

参考概览图提供“分类、数量、最近分享、进入箭头”，列表图提供“返回、平铺记录、细分隔线、行更多”。本阶段将这些结构融入现有设置样式。
产品规则与完整骨架见[正式PRD](../../../../prd/sharing/external-links.md)，业务时序与状态图见[正式交互稿](../../external-links.md)。

## 目标与边界

沿用[第二阶段结构](2_structure_sketch.md)与[第三阶段层级](3_hierarchy_logic.md)，交付文字视觉规范。本轮仅完成管理设计；页面、接口、归属及状态目录、Schema与迁移均待实现，AI对话链接创建为后续依赖。
自动测试与测试代理保持暂停，本阶段仅做手工阅读和文件存在性核对。

## 概念与规则

### 视觉层级

| 对象 | 呈现规范 |
| --- | --- |
| 页面基底 | 复用设置纸面背景、内容宽度、留白与深浅主题语义；颜色取既有背景、文本、边框和交互语义。 |
| 标题与说明 | 页面标题沿用设置标题样式；类别标题及数量使用主文本，说明、日期和地址使用次文本，保留现有字体。 |
| 分类卡片M3 | 桌面两列等宽，窄屏单列；同级类别、数量和最近标题对齐，轻边框、常态留白，整卡提供悬停及焦点反馈。 |
| 分类列表M4/M5 | 状态切换与刷新居于记录上方；桌面平铺表格，窄屏纵向信息行，记录之间使用细分隔线。 |
| 行更多M6 | 沿用设置菜单背景、边框和层级；完整标题换行，操作按阅读顺序排列，“使链接失效”使用既有危险操作语义及完整文字。 |
| 行内展开M7 | 占用当前行下方全宽，使用现有次级区域语义；完整标题和地址换行，后续记录随内容下移。 |
| 状态与反馈M7/M8 | “有效”“已失效”保留文字；提交中、失败和结果待确认使用独立反馈行，重试及刷新紧邻文案。颜色配合文字表达结果。 |

### 操作与阅读

- 有效链接的缩略地址可点击展开当前行的链接信息，完整标题和完整地址在复制前即可阅读；复制使用完整地址。行菜单保留复制、打开、查看原内容和单条失效。
- 更多菜单贴近当前行，随可见边界调整方向；关闭后焦点回到触发入口。行内信息、手动复制和操作反馈共用一个展开区，按当前动作展示。
- 原内容确认删除后保留分享标题、地址与链接状态，显示“原内容已删除”，原内容入口不可用；有效链接继续提供主动失效。
- 内容区使用单一纵向滚动；窄屏Web设置导航沿原横向滚动，菜单及恢复入口保持可见。完整地址换行，信息区随页面滚动。
- 服务端确认失效后更新记录与数量，显示既有轻提示；提交中及结果待确认保留最后确认状态和数量，反馈采用原设置的过渡与焦点样式。

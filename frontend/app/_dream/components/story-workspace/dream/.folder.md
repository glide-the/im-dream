# Dream components

## Architecture Summary

Dream 侧组件消费既有 Run、Agent、Thread 与思维模式数据。局部交互不拥有业务持久化，Deck 保留为实现名称。

## File Table

| File | Pos | Function |
| --- | --- | --- |
| `StoryWorkspaceDreamDeckMetadata.tsx` | 思维模式信息入口 | 显示既有 Dream Run 及 Deck 信息，产品名称复用 i18n。 |
| `StoryWorkspaceDreamDeckMetadata.css` | 信息弹层样式 | 保持入口与弹层的既有布局。 |
| `StoryWorkspaceDreamAgentDialog.tsx` | Agent 弹窗 | 承载 Dream Agent 的既有对话界面。 |
| `StoryWorkspaceDreamAgentPanel.tsx` | Agent 面板 | 组合 Dream Agent 的既有面板内容。 |
| `StoryWorkspaceDreamAgentRail.tsx` | Agent 栏 | 组合 Agent 入口与思维模式信息入口。 |
| `StoryWorkspaceDreamThreadChat.tsx` | Dream Thread 对话 | 消费既有共享 Thread 对话与运行事实。 |
| `storyWorkspaceDreamAgentFocus.ts` | 聚焦辅助 | 管理 Dream Agent 入口的既有聚焦逻辑。 |
| `__tests__/` | 技术合同 | 保存 Dream Thread 与工作区文件的现有验证。 |

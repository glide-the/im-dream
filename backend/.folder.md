## 架构概述
FastAPI + uvicorn Python 服务，端口 8765，提供 REST/SSE/WebSocket API。运行时仅通过 Admin 的鉴权与 DTO 业务接口访问持久化；共享文件系统继续由 Dream 操作。SQLite、旧 PostgreSQL importer 和 SQL receipt probes 只存在于明确命名的测试 fixture/harness。

# frontend/src/utils — Folder Contract

## Architecture Summary

Small frontend utilities for storage, normalization, device behavior, errors, timezone, and theme state.
Utilities remain UI-agnostic and expose reusable deterministic seams where practical.

## File Table

| File | Pos | Function |
|---|---|---|
| `calendarStorage.ts` | `calendar storage utility` | Persist calendar UI state. |
| `debugLogger.ts` | `debug logging utility` | Gate frontend diagnostic logging. |
| `errorMessage.ts` | `error presentation utility` | Normalize unknown errors into safe messages. |
| `mobileDetect.ts` | `device utility` | Detect mobile browser behavior used by responsive UI. |
| `textNormalize.ts` | `text utility` | Normalize user-facing text. |
| `theme.ts` | `theme state utility` | Own persisted/system theme resolution and notify Story Workspace/Settings controls. |
| `timezone.ts` | `timezone utility` | Resolve and format application timezone values. |
| `voiceStorage.ts` | `voice storage utility` | Persist voice-related UI preferences. |

# frontend/src/components/chat - Folder Contract

## Architecture Summary
Chat workspace UI components for input, messages, tool output, modal/toast feedback, and the composed chat view.
`ChatView.tsx` owns thread/file sidebar/search-dialog state, app-owned history/connector entry rendering, the single pill-style `QuickActionStrip` beneath the composer, and the shell-level error boundary / recovery entry; it delegates message streaming to `ChatPanel.tsx`. Workspace Mode gates file sidebar visibility and workspace file sync entry points.
The landing shell is viewport-contained and width-aligned to the Chat composer/tab bar: ChatView owns the outer flex/min-height chain, while history and the `资源连接器` (`ResourceConnectorTabPanel`) own their internal scroll regions.
Settings navigation is not owned by this folder; app-level top/mobile navigation owns that route entry. The Chat `WorkspaceTabBar` (聊天历史/资源连接器 pill switch) is the primary connector discovery entry, and connector configuration belongs to Settings' `ConnectorNotionDetailPage`.

## 6. 模块间关系链（权威叙事）

```
Deck 插件（制品，profile 声明 surfaces[]）
  → Dream 页选 Deck 点 Chat → 创建 thread（锁 deck_id）
  → 首个 agent turn：pack_workspace_plugins()
      → 物理映射 .dream 静态启动层（仅声明 dream surface 时）+ 写 launch-manifest / pack-receipt
  → GET plugin-load-receipt 透出 surfaces → useWorkspaceSurfaces
  → preflight / 创建 workflow run → Chat Agent 获得受控运行上下文
  → Chat Agent 按插件步骤写人物、场景、分镜 canonical 文件
      → 同步原子更新 .dream/runtime run.json 与 stages/*.json
      → 后端安全读取文件 → REST/SSE 驱动对应页面
  → 用户在 Dream 页面修改内容 → 一次“确认并继续”
      → 隐藏 Chat 确认消息注入原 thread → 同一 Chat Agent 写入修改并继续
  → StoryWorkspaceSurfaceLinkButton → 独立执行页持续显示 Agent 工作空间更新
```

既有 guidance 端点与侧边栏是已实现代码事实，但不属于上述 Dream 单次确认主链。

The new `/auth/session` DTO exposes decimal-string user ID, existing profile fields and `csrf_token`. It never exposes access/refresh tokens. Existing Python `/api/me` public projection remains separately owned by its router. Missing credentials return401; origin/CSRF403; invalid/unavailable Admin configuration/DTO503. Callback unknown exchange retains the original cookie for same-transaction recovery; failed revoke retains the same handle. Generic API and Claude SSE use the same credential owner/stream transport. Browser state, explicit MCP Apps adapters and long-turn/tool wiring remain active implementation work, so these route candidates do not prove complete migration or deployment.

Next may construct a Route Handler request URL from its internal listener or tunnel transport origin. The boundary therefore accepts the exact configured public origin, an exact `Host` equal to that public origin's host, or an HTTP loopback URL when the server explicitly configures proxy mode with `INK_DREAM_BFF_INTERNAL_ORIGIN`. In that configured proxy mode, `X-Forwarded-Proto` and `X-Forwarded-Host` may recover the public origin even when the tunnel rewrites the request URL and `Host`; the two headers must form the exact configured public origin, and comma-separated or mismatched values remain denied. Callback path is compared after mapping to the public origin, while registered callback URI, mutation `Origin`, CSRF, cookies and configured public origin remain independently enforced.

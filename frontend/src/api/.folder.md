# frontend/src/api — Folder Contract

## Architecture Summary
Frontend API client helpers for backend REST/SSE calls.
Keeps endpoint construction and protocol details out of feature components.

## File Table

| File | Pos | Function |
|---|---|---|
| `gatewayModelsApi.ts` | gateway-model-catalog transport node | Validate Admin Gateway model catalog/default alias and resolve an effective selection from an explicit saved preference or Admin's callable default. |
| `productApi.ts` | product-subscription transport node | Validate and transport the same-origin Dream Product BFF subscription, plan, usage, model, command, and payment contracts; mirror Admin's unavailable-plan state matrix without deriving subscription facts in the browser. |
| `resourceConnectorApi.ts` | `resource-connector api client node` | Provide connector CRUD, auth polling, resource discovery, resource selection, sync helpers, backend/local response normalization, normalized UI fallback connector shaping, and same-platform local replacement for the single-account rule. |
| `voiceApi.ts` | voice-api client node | Provide session/deck/voice API helpers, lightweight Deck metadata input, default-Deck reconciliation, server policy facts for system-default display, Claude Agent SSE helpers, Reflections analysis, and report storage; active Deck clients expose no marketplace transport. |
| `chatHistoryApi.ts` | Chat history transport | Share typed production create/list/delete calls between Chat and Deck Work; list supports actor-scoped `deck_id` filtering. |
| `claudePluginAdminApi.ts` | ClaudePlugin administration transport | Expose shared installation facts, server-owned management permission, real install operations, uninstall, Deck refs, and plugin load receipts; no Marketplace catalog transport exists. |
| `deckPluginApi.ts` | Deck runtime-version transport | Expose Agent type, exact binding/options/history DTOs, CAS saves, and validation; aggregate Deck versions remain separate. |
| `deckVersionApi.ts` | Deck content-version transport | Expose capability-backed draft state, no-write preview, explicit commit, immutable history, and structured CAS errors. |
| `storyWorkspaceApi.ts` | Story Workspace API client | Strictly parse Dream launch/files/re-entry contracts, including lifecycle-consistent initial/in-progress outcomes and canonical `run.href`. |
| `__tests__/` | API contract tests | Focused strict DTO and client projection tests; see `__tests__/.folder.md`. |

# Android host

## Current RN build

2026-10-27: native project lives at `frontend/android/`; Gradle consumes `../index.native.js` through the pinned RN plugin, and `MainActivity` uses ReactActivity. `MainApplication` owns the RN Host; `InkRuntimePackage` reports the unqualified embedded backend explicitly. Old WebView Activity and static resource build definitions are archived under `frontend/legacy/android-webview/`. Below is the retained original runtime/platform inventory; Android backend execution and build acceptance remain pending.

## Responsibility

- `app/` owns the Kotlin host, exact-origin WebView bridge, Android document/share/browser adapters, and the private `:dream_runtime` service boundary.
- `app/build.gradle.kts` bundles `frontend/index.native.js` through the RN Gradle plugin and has no HTML resource preBuild task.
- `scripts/check-toolchain.sh` reports the local JDK, Android SDK, and Gradle prerequisites without installing or changing them.
- `gradle/wrapper/gradle-wrapper.properties` pins the intended Gradle distribution. The wrapper JAR is generated during the later dependency-initialization task.

## Runtime boundary

- The application process owns Android UI and WebView.
- `DreamRuntimeService` runs in the non-exported `:dream_runtime` process and exposes only the AIDL methods in this folder.
- The current capability snapshot reports embedded Python, Claude CLI, and local Dream transport as `unavailable`.
- The document and share adapter is implemented behind `NATIVE_FILES_CONTRACT_UNQUALIFIED`; multi-file import rolls back every copy from a failed batch. Android build and device checks must qualify it before the bridge exposes it.
- External browser handoff requires a user gesture and an exact host in `mobile_allowed_external_hosts`. The list is empty until release configuration is approved.
- Runtime calls fail with `CAPABILITY_UNAVAILABLE`. The host contains no simulated response and no remote Dream fallback.

## File inventory

- `settings.gradle.kts`: plugin and dependency repositories.
- `build.gradle.kts`: Android Gradle Plugin pin.
- `gradle.properties`: deterministic Gradle defaults.
- `app/build.gradle.kts`: Android target, RN/Hermes dependencies and shared native bundle generation.
- `app/src/main/AndroidManifest.xml`: application, launcher activity, provider, permissions, and private runtime service.
- `app/src/main/aidl/`: Binder protocol between the UI and runtime processes.
- `app/src/main/java/com/inkmemory/mobile/`: host, bridge, runtime, and Android resource adapters.
- `app/src/test/`: bridge parser and generation-isolation tests.

# deploy/autodl-ssh/runtime — Folder Contract

## Architecture Summary

Direct-host runtime scripts for the current AutoDL release shape. The supervisor
starts standalone Next.js and FastAPI while retaining persistent-root and
process-ownership safety.

## File Table

| File | Pos | Function |
|---|---|---|
| `init-dream-data.sh` | persistent-data initializer | Creates and validates Dream agentdata, actor-scoped Notion runtime, artifact, upload, plugin, and log roots with private ownership/modes and symlink rejection. |
| `start-dream.sh` | Dream supervisor | Starts standalone Next.js with the server-only MCP Apps environment and private FastAPI; fails if AutoDL sandbox ownership changes. |
| `start-ink-memory.sh` | release restart entry | Starts Admin first, then only a current standalone Next/FastAPI Dream release, while refusing unknown port owners. |

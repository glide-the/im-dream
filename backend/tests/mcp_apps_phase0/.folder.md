# backend/tests/mcp_apps_phase0

## Purpose

Provider-free Phase 0 contracts for standard MCP transport locality, fresh-session state portability, existing Chat JSON persistence, and secret rejection. Tests invoke production Chat save/list functions through a fake connection and never create schema or business rows.

## Files

| File | Role |
|---|---|
| `projection.py` | Test-only safe Apps result projection into the existing Chat JSON shape. |
| `test_protocol_locality.py` | stdio, Streamable HTTP, SSE, and fresh-session checks. |
| `test_chat_apps_projection.py` | Existing save/list/public-route round-trip, complete result preservation, and secret/schema boundary checks. |

## Rollback

Delete this directory; no persistent database cleanup is required.

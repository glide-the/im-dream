# backend/notion — Folder Contract

## Architecture Summary
Notion resource connector backend package.
Owns authentication CLI wrappers, read-only discovery operations, SQLite-backed connector and snapshot persistence, canonical snapshot materialization, and workspace-local `.notion/` attach helpers.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | public-api node | Re-export Notion connector facade, auth helpers, persistence helpers, and canonical snapshot materializers for router/service callers. |
| `auth.py` | auth node | `ntn login --no-browser`, `ntn login poll`, and `ntn auth status` wrappers plus `NOTION_HOME` env resolution. |
| `errors.py` | error node | Shared Notion connector exception hierarchy. |
| `factory.py` | facade node | User-scoped `NotionConnectorFacade` orchestration for auth, discovery, selection, sync, and workspace materialization. |
| `operations.py` | operations node | Read-only `ntn api` discovery/query/page read helpers and normalized discovery payloads. |
| `store.py` | store node | SQLite persistence for connectors, resources, resource pages, snapshot history, and thread attachments. |
| `sync.py` | sync node | Canonical snapshot assembly and workspace-local `.notion/` file materialization. |

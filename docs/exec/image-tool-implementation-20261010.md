## 已落实代码与设计修订

- 图片工具复用原 Runner MCP stdio 与 turn-local broker，生成调用 Admin `/v1/images/generations`，编辑提交实际图片字节到 `/v1/images/edits`。主对话继续原 Messages/Gateway 路径，不添加 Responses 内置图片工具。
- 参考图限同 Thread 工作区；上传附件同时提供视觉图片块与规范 URI。Host 使用当前授权、公开目录选图模型、检查结果并发布新文件。原图不覆盖，Provider 凭证/base64 不进入浏览器或历史。
- 原工具过程补齐生成/编辑双语名称；图片复用原 Markdown、查看器、下载与文件权限。Service 只展示本轮登记 Tool 与 Host 发布记录匹配的图片，沿原消息保存，支持重开继续编辑。
- 修正最终图片被拆成两个文本 part 导致 `history_final_text` 缺失的问题，改为原文本结束前补齐。限定图片补齐不改变普通多段文本 turn 的最终全文，新增公开 Service 兼容回归。
- 收紧停止后的完成回执：已经发布文件但尚未收到CLI完成回执时，Host关闭后不再把迟到回执提升为聊天图片；保留原文件，不伪造图片完成。补充停止时机回归。
- 多参考图改为读取时累计容量，首次超限即终止，不把整组文件先装入内存。容量配置不变，补充超限后不再读取后续文件/调用Images的回归。
- 参考图描述符读取匹配Host绑定时的Thread根目录设备/inode；运行中根目录被换成另一目录或符号链接时拒绝读取及Images派发。原文件模块可选参数默认不设置，其他文件调用保持。
- Admin 修正主对话用户图片及 Read 图片结果转换，保留顺序、call_id 和视觉内容；小 JSON 工具结果仍为原文字。补齐安全错误类导入并修正测试联合类型缩窄，重新验证。
- 现行 PRD 去除未实现的选图专用确认承诺；正式稿明确图片实际显示时机，图片读取恢复保留原保存状态。保留 3 份实施前完整稿，目录和 README 同步。

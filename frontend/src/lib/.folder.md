# frontend/src/lib - Folder Contract

## Architecture Summary
Shared frontend utility and transport modules for runtime API base config, chat request types, Claude Agent streaming, and file proxy URL construction.
Feature components consume this folder for protocol contracts and API-adjacent helpers rather than duplicating request shapes.

## File Table

| File | Pos | Function |
|---|---|---|
| `apiBase.ts` | `frontend API base-url utility node` | Lazily resolve REST/SSE and WebSocket base URLs from runtime config, Vite env, or root same-origin fallback. |
| `chat-schema.ts` | `chat-schema type node` | Define frontend chat request plus validated Deck/Agent/Dream, assistant turn/final/duration, and read-only history projection metadata types. |
| `claude-agent-sse-utils.ts` | `claude-agent reconnect SSE utility node` | Parse replay frames, retain the server turn ID on assistant messages, and idempotently merge allowlisted Dream auto-repair boundaries. |
| `claude-agent-transport.ts` | `transport adapter` | Adapt SSE to AI SDK, including server-owned assistant `turnId`; persisted user boundaries and typed errors retain existing reconnect/safe-text behavior. |
| `system-config-events.ts` | `system-config-events utility node` | Broadcast same-tab Settings changes, including IM full-access approval mode and Workspace Mode, to chat/file components without page refresh. |
| `toFileProxyUrl.ts` | `file-proxy-url utility node` | Convert stored file keys into frontend-accessible proxy URLs. |

# docs/prd/mobile-app

## Architecture Summary

本目录负责iOS与Android移动应用的导航、登录、使用旅程、启动反馈、桌面参照、窄屏页面骨架及验收。Chat、Deck、写作、回顾与设置的领域规则沿既有业务PRD。架构、实例生命周期及正式业务交互图归[跨平台设计目录](../../design/multi-platform/README.md)。

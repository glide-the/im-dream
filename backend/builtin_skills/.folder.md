# backend/builtin_skills — Folder Contract

## Architecture Summary

Server-owned Agent Skills included by the backend-only Docker build. Source
ownership is split between always-selected `common/` and connector-selected
platform namespaces; directory packages are linked read-only while `.skill`
archives are unpacked inside the current thread.

## File Table

| Path | Pos | Function |
|---|---|---|
| `common/` | common-skill-namespace | Platform-independent packages selected for every full workspace; currently owns `skill-creator`. |
| `notion/` | platform-skill-namespace | Notion directory packages plus archive-backed `notion-diary-sync`; selected only for the current actor/thread's effective Notion Runtime projection. |

# frontend/src/hooks — Folder Contract

## Architecture Summary
React hooks that coordinate editor lifecycle, text editing, comments, voice input, explicit Writing suggestions, and session event subscriptions.
Hooks own side effects and protocol subscriptions while components keep rendering concerns.

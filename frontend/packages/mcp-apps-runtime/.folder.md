# @ink-dream/mcp-apps-runtime

## Architecture

Process-scoped, server-only Node MCP Runtime. The package owns Python connection
projection access, upstream MCP Clients, connection/catalog reuse, standard
Streamable HTTP sessions, per-request authorization, server-owned low-risk calls,
versioned plugin lifecycle, bounded resource/network policy, redacted diagnostics,
and teardown. It never imports the root Web package, React, or DOM.
Production composition fails closed unless the Node plugin manifest, maximum
resource bytes, catalog pages, upstream timeout, per-scope concurrency, and network hosts are
provided through `INK_MCP_APPS_PLUGIN_MANIFEST_JSON`,
`INK_MCP_APPS_MAX_RESOURCE_BYTES`, `INK_MCP_APPS_MAX_CATALOG_PAGES`,
`INK_MCP_APPS_UPSTREAM_TIMEOUT_MS`,
`INK_MCP_APPS_MAX_CONCURRENCY_PER_SCOPE`, and
`INK_MCP_APPS_NETWORK_HOST_ALLOWLIST`. Python reads the current versioned
positive-list policy from `INK_MCP_APPS_POLICY_JSON` on each connection view;
the view also requires the actor's current App-settings revision and intersects
its desired choices before Node can open or reuse an upstream connection.

## Files

| File | Function |
|---|---|
| `package.json` | Private workspace package identity, exports, and exact direct dependency contract. |
| `plugin/manifest.example.json` | Secret-free disabled scaffold for the deployed Browser/Node entry identity, protocol/SDK ranges, and four feature flags; copy its JSON into the server-owned manifest configuration with an advanced revision/lifecycle. |
| `tsconfig.json` | Strict no-emit server package TypeScript boundary. |
| `tsconfig.integration.json` | No-emit canonical root route/Host/package graph check with the workspace link represented explicitly. |
| `src/index.ts` | Explicit `server-only` request/teardown entry, safe manifest read and public-request-origin parser used by root Route Handlers. |
| `src/contracts.ts` | Strict policy/view, App-settings, route-context, catalog, low-risk call, lease, safe-error, and canonical irreversible connection-profile identity contracts. |
| `src/config-provider.ts` | Service-authenticated Python single-Server projection client plus credential-free public connection-settings read for status composition. |
| `src/plugin-manifest.ts` | Versioned Browser/Node entry, protocol/SDK range, `resourceReads`/`lowRiskToolCalls`/`uiMessage`/`windowIm` feature, and lifecycle compatibility contract. |
| `src/runtime-policy.ts` | Environment-configured resource bytes, catalog pages, upstream timeout, per-scope concurrency, and network host positive list. |
| `src/diagnostics.ts` | Closed-schema hashed diagnostics that cannot carry URL/header/credential/body/HTML content. |
| `src/sdk-connector.ts` | Standard MCP SDK upstream Client adapter with no-redirect fetch, bounded catalog pagination/resource reads, and governed tool calls. |
| `src/persistent-connector-manager.ts` | Actor/workspace/Server/Browser/plugin key, reference, every-request revalidation, expiry timer, concurrency, invalidation, and teardown owner. |
| `src/http-adapter.ts` | Standard Web Streamable HTTP session, view-bound session expiry, policy enforcement, plugin reconciliation, and proxy adapter. |
| `src/runtime.ts` | Process-global configured composition root, production-off preview gate, and same-origin validation against the public request Host when framework internals canonicalize the URL host. |
| `src/*.test.ts` | Provider-free manager, HTTP authorization, lifecycle, isolation, limit, timeout, and redaction contracts. |

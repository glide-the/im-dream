# MCP Apps user-guide images

## Purpose

Sanitized screenshots of the real production Settings and MCP App Host
components used by the English and Chinese READMEs. The source browser journeys
use provider-free example data and contain no real account, credential, or Chat
content.

## Files

| File | User-visible step |
|---|---|
| `01-add-mcp-connection.png` | Add a managed MCP endpoint from Resource Links. |
| `02-configure-mcp-app.png` | Enable the App and choose connection-level interaction permissions. |
| `03-use-mcp-app-in-chat.png` | Keep the interactive App visible while the completed tool detail is collapsed. |

## Source and refresh

- The first two images come from the production Settings components exercised
  by `frontend/e2e/claude-mcp-resources.spec.ts` with
  `INK_CAPTURE_MCP_APPS_GUIDE=1`.
- The Chat image comes from the production `ToolMessagePart` →
  `McpAppHostPanel` tree exercised by
  `frontend/e2e/mcp-apps/phase-1/official-phase1-3.spec.ts` with the same capture
  flag and the reviewed unmodified official AppServer artifacts.
- Refresh images only when the related user-visible flow changes, and verify
  every capture for real account identifiers, credentials, and unrelated Chat
  content before committing it.

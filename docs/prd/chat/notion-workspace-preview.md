# Chat 中的 Notion 工作空间预览

> 2026-11-18 最新要求：Notion正文由react-notion-x展示；文件、页面引用等扩展标签需要正确呈现；界面按Kastention UI规范v3.1对齐。用户已确认执行Next.js集成方案A。[调研结果](../../design/workspace/notion-workspace-preview-react-notion-x-research.md)记录数据合同和推荐方案；正文展示切换为react-notion-x；完整历史基线由正式设计目录保留，实施状态见执行记录。

## 背景与问题

用户在对话中让 Agent 阅读已连接的 Notion 页面，希望直接阅读页面内容，并按需检查与保存该次读取的 JSON。[问题原文](https://app.notion.com/p/40b30b7547c380cd9930c384ab35023c#41b30b7547c3803a9079e5c84adc127d)指定 `.notion/pages/` 的 Read 触发、摘要卡片、展开、占满对话窗口、下载和 JSON 元信息。三张参考图分别呈现摘要、完整阅读和右侧详情。

调整前，Read 已完成页面授权和按需读取，Chat 将结果展示为通用终端文本。页面正文、JSON 转义和元信息混排，阅读入口缺失。本轮网页呈现已接入摘要与完整阅读，技术回执见执行记录。

## 目标与边界

本次交付网页 Chat 的桌面和窄屏阅读。预览对象为 Agent 已经读取的单个 Notion 页面；内容对应该次读取结果。完整阅读在当前对话区域展开。读取结果和 JSON 下载均沿现有对话访问范围。

本次范围包括摘要、完整正文、JSON 详情、JSON 下载、空正文及读取失败反馈。页面编辑、Notion 工作空间目录管理、重新授权、新增页面请求、自动刷新正文、数据库视图和原生客户端扩展留在各自业务范围。正文由react-notion-x呈现文件、页面引用、提示、折叠、分栏、表格和普通Markdown内容。附件签名刷新沿后续独立合同。

历史对话沿现有受限过程读取：首次返回最终文字后，原历史过程读取模块加载工具结果，结果到达后显示页面摘要。已加载摘要保留在过程折叠区域外。读取失败沿“查看过程”的原重试入口恢复，预览组件不增加读取请求。

## 概念与规则

| 对象 | 规则 |
| --- | --- |
| 工作空间页面 | 当前 Thread 中 `.notion/pages/<页面标识>.json` 对应的已挂载页面；Read hook 可将实际读取重定向至私有临时文件 |
| 预览 | 当前 Read 已返回的页面正文；页面后续修改留待下一次 Agent 读取。同页多次读取分别保留对应卡片 |
| 摘要 | 小文档图标、页面标题和最多两行摘要；标题右侧提供下载与展开图标 |
| 完整阅读 | 顶部固定标题、JSON详情、下载和关闭；正文单独纵向滚动 |
| JSON 详情 | 展示该次读取返回的 JSON，包含正文和来源元信息；桌面置于右侧，窄屏切换至独立阅读栏目 |
| 下载 | 保存该次读取返回的 JSON；文件名使用页面标识，直接执行 |
| 访问范围 | 复用已登录用户的 Thread 消息权限和原 Notion Read 授权；预览仅消费现有结果 |

一般文件、目录列表、Bash 输出、页面标识冲突和不完整 JSON 沿原工具展示。读取中的目标页面保留原工具进度和确认反馈；明确的 Notion 读取错误显示中文恢复指引。恢复授权或挂载范围后，用户在原对话中请 Agent 重新读取。展示组件不执行工具重试。

## 页面与交互

桌面骨架：

```text
Chat消息区（原纵向滚动）
[文档] 页面标题                     [下载] [展开]
       正文摘要，最多两行
       与标题文字对齐
       （条目宽度上限36rem，无外框及阴影）
助手原回复与输入栏

展开覆盖当前对话区域，外围导航与原消息位置保留：
┌页面标题────[JSON详情] [下载JSON] [关闭]┐
│ 正文独立纵滚           │ JSON独立纵滚 │
│ 长代码／表格局部横滚   │ 默认关闭     │
└──────────────────────────────────────┘
```

窄屏骨架：

```text
[文档] 页面标题…    [下载] [展开]
       摘要最多两行
       标题省略，操作可达
展开，占满当前对话区域：
┌页面标题──────[关闭]───┐
│ [正文／JSON详情] [下载]│
├───────────────────────┤
│ 当前栏目独立纵向滚动  │
│ 长代码／表格局部横滚  │
└───────────────────────┘
```

完整阅读复用原弹层的 Escape 关闭、焦点约束和焦点恢复。关闭返回原消息位置。切换 Thread 或卸载消息会关闭预览。页面主题和语言沿当前应用设置。

## 状态与恢复

| 状态 | 条件 | 用户反馈 | 恢复操作 |
| --- | --- | --- | --- |
| 读取中 | 目标页面 Read 尚未返回 | 原工具进度及确认入口 | 等待或沿原确认入口操作 |
| 内容展示 | 完整结果包含页面标识及正文 | 摘要及完整阅读入口 | 展开、查看JSON或下载 |
| 空正文 | 成功返回空白正文 | 此页面暂无正文 | 查看JSON |
| 权限或范围问题 | 原读取返回授权、权限或挂载错误 | 对应恢复指引 | 在设置恢复连接或范围后请Agent重新读取 |
| 读取失败 | 原读取明确失败 | 读取失败，提示重新读取 | 在原对话继续操作 |
| 内容不完整 | 部分Read或结果无法解析 | 原工具结果展示 | 请Agent完整读取页面 |
| 正文加载 | 阅读组件尚未就绪 | 正在显示页面 | 保留JSON与关闭入口 |
| 预览失败 | 组件或内容转换异常 | 局部失败反馈 | 重试、查看JSON或关闭 |
| 图片失败 | 已保存图片加载失败 | 图片失败反馈 | 重试原地址或打开原图 |
| 下载失败 | 浏览器创建下载失败 | 保留正文及下载重试入口 | 再次下载 |

## Notion内容展示与UI规范

摘要采用无外框、无阴影的紧凑条目，标题与两行摘要分层。下载与展开图标常显在标题右侧；长标题单行省略，完整名称用于辅助功能。正常、空内容和失败反馈沿同一骨架。

文件显示名称和说明，页面引用显示标题并保留原链接；空块呈现留白，换行保持原位置。提示、折叠、分栏与表格使用对应内容结构；窄屏分栏纵向排列。正文隐藏原始标签及资源签名参数，代码示例中的标签保持字面文本。JSON详情及下载继续保留原始读取结果。

视觉按[UI规范v3.1](../Kastention-App-UI-Guidelines-v3.1.pdf)的轻纸面、文字层级、局部强调和原有字体规则实现；标题、操作固定，正文独立滚动，文件/引用换行，代码及表格局部横滚。组件加载失败保留JSON查看入口，提供重试和关闭入口。

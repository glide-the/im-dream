# deploy/autodl-ssh

## 定位

该目录是 Dream backend 在 AutoDL/SeetaCloud SSH 主机上的直接发布平台，与 `deploy/remote-ssh` 的 Docker、nginx、frontend 和 TUN 组合路径分离。

## 合同

- Dream 仅监听 `127.0.0.1:6006`，Admin 监听 `127.0.0.1:6008`；公网 HTTPS origin 由 SeetaCloud 映射并通过环境变量注入。
- 发布只安装固定 Node/Python 依赖、版本化 backend release、SDK 0.2.144、Runtime 0.1.1 和官方 CLI 回滚件；不发布 frontend、Docker 或 nginx。
- Dream 从 Admin 生成的安全 env 读取 PostgreSQL 身份，只消费 Admin-owned schema，不执行 migration 或 runtime DDL。
- npm 私有访问通过可选 `AUTODL_NPM_TOKEN` 生成临时 mode-0600 npmrc；安装完成立即删除，不写 runtime env 或日志。
- `screen` 只负责 SSH 断开后的进程存活；实际 FastAPI/Claude 进程以专用非 root 用户运行。
- `rollback` 只切换 Dream application release，不修改数据库、workspace 或 Admin。

## 入口

- `prepare-env.sh`：将 Dream 与 Admin 安全配置投影为 gitignored `.env`。
- `platform.env`：从 `platform.env.example` 复制的、gitignored 的 SSH 与公网映射配置；`deploy.sh` 自动读取。
- `deploy.sh`：`check|plan|sync|build|deploy|start|stop|status|logs|verify|rollback`。
- `runtime/start-dream.sh`：screen 内的前台 uvicorn 入口。

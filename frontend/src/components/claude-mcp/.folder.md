# frontend/src/components/claude-mcp — Folder Contract

## Architecture Summary

Owns the Settings Resources presentation for the `claude-mcp` business domain. Components consume only the typed Claude MCP API, retain redirect URLs in transient component state, recover live operations from backend IDs, and render prompt-free public-SDK tool inventory without executing tools. They never persist OAuth credentials, parse `/mcp` TUI output, or emulate CLI state locally.

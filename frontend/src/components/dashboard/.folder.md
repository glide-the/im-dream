# frontend/src/components/dashboard - Folder Contract

## Architecture Summary
Dashboard components for chat-adjacent navigation, file access, quick actions, model settings, and legacy sidebar surfaces.
These components should reuse existing chat icons, design tokens, and parent-owned callbacks instead of owning route state.
Vertical navigation currently exposes files, chat history, and user avatar controls; Settings is owned by top/mobile app navigation.

## File Table

| File | Pos | Function |
|---|---|---|
| `FileSidebar.tsx` | `file-sidebar component node` | Render file workspace sidebar UI and file list/actions for a session. |
| `ModelConfigSection.tsx` | `settings-model-config component node` | Render Settings page AI model/theme/system-prompt/workspace-mode controls and API interactions. |
| `QuickActionCard.tsx` | `quick-action-card component node` | Render reusable prompt shortcut cards for chat quick actions. |

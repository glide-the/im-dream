## 桌面主结构

```text
┌──────────────────── A1 Chat 顶部 ────────────────────────────────────────┐
│ Agent / Deck             新建 [铃铛：已选中] 任务与进度 更多             │
├───────────────────────────┬────────────── 右侧 20rem ────────────────────┤
│ A2 主消息／原 landing     │ B1 活动                   搜索 刷新 关闭    │
│ 原消息滚动区              ├─────────────────────────────────────────────┤
│                           │ C/D 共享唯一列表滚动区                      │
│                           │ C1 优先级                                 … │
│                           │ C2 任务标题…／定时任务 ·今日 ·运行中       │
│                           │ C2 Dream 标题…／Dream ·进行中 ·时间        │
│                           │ C2 Chat 标题…／Chat ·更新时间             │
│                           │ C3 来源状态反馈（需要时）                   │
│                           │ D1 今天／昨天／最近七天／三十天／更早       │
├───────────────────────────┤ D2 历史分页加载／失败重试／全部已显示       │
│ A3 原输入与发送／停止     │                                             │
└───────────────────────────┴─────────────────────────────────────────────┘
```

20rem 沿用现有 FileSidebar 宽度，不增加同时可见的旧 16rem 历史列。标题 B1 固定，C1 随整个列表滚动；C2 用标题与来源状态两层信息，标题省略而完整名称仍可访问。三来源行示例不代表固定数量或固定三段；实际列表仍按 Stage 1 排序。A2 的原消息滚动不属于活动列表，二者互不重置。


## 菜单与来源失败结构

```text
┌────────── C/D 列表 ────────────┐    ┌──────── E1 显示 ───────┐
│ C1 优先级                    … │───→│ 优先级部分          ✓ │
│ C2 三来源活动行                │    │ 定时任务            ✓ │
│ D1 日期历史                    │    │ Chat                ✓ │
│ D2 历史分页                    │    │ Dream               ✓ │
└────────────────────────────────┘    └───────────────────────┘
```

菜单是独立浮层，不占列表高度、不被列表 overflow 裁剪，并根据可用视口向上或向下显示。勾选即时更新 C2；关闭优先级部分后 C1/E1 保留，D1/D2 接续。选项不添加管理操作。菜单可连续勾选，外部点击或 Escape 关闭并将焦点返回 C1 省略号。

```text
┌──────────── C1 优先级 ───────────────────┐
│ C2 今日任务…／定时任务 ·今日 ·运行中    │
│ C2 Chat 对话…／Chat ·更新时间          │
│ C3 Dream 暂时无法加载    [重新加载]     │
│ D1 今天／昨天…                          │
│ D2 加载历史失败         [重试]         │
└─────────────────────────────────────────┘
已有 Dream 行时保留行，C3 改为“Dream 更新失败 [重新加载]”。
全部分类关闭：C3“选择要显示的活动类型”，保留 D1/D2。
选中来源均读取成功且为空：C3“暂无需要关注的活动”，保留 D1/D2。
```

C3 来源失败不能变成整体空状态，重试只读取失败来源。D2 分页错误保留历史，不能标记为全部已显示。刷新保留成功数据，但旧运行标签不能当作当前运行观察；具体语义沿用 Stage 1。

## 390px 窄屏结构

```text
┌────── 390px Chat A1（打开前）───────────┐
│ 新建 [铃铛：活动视图] 原操作／更多     │
│ A2 当前 Chat                           │
│ A3 原输入区                            │
└────────────────────────────────────────┘
                       ↓ 打开
┌────── 390px 全宽覆盖抽屉 ──────────────┐
│ B1 活动             搜索 刷新 关闭    │ ← 固定
├────────────────────────────────────────┤
│ ↓ C/D 唯一列表滚动区                  │
│ C1 优先级                           … │
│ C2 任务标题…                         │
│    定时任务 ·今日 ·运行中            │
│ C2 Dream 标题…                       │
│    Dream ·生成中／进行中 ·时间       │
│ C2 Chat 标题…                        │
│    Chat ·更新时间                   │
│ C3 单来源失败与重新加载（需要时）     │
│ D1 日期历史                          │
│ D2 底部分页反馈                      │
│ 既有安全区留白                       │
└────────────────────────────────────────┘
背景 A2/A3 保留原位置，打开时不接受点击或焦点。
```

沿用 `useMobile`，小于 768px 的视口进入窄屏，既有移动设备判定保留。抽屉覆盖全宽并适配可用视口高度，Chat 不在旁边压缩。菜单不超出抽屉，搜索 F1 覆盖于抽屉上方且适配窄屏。打开焦点进入 B1；关闭回到 A1，动态更新不抢焦点、不滚回列表顶部。桌面为普通侧栏，窄屏为管理焦点的对话框。

## 弹窗与侧栏关系

| 起点与动作 | 目标结构 | 关闭或返回 |
| --- | --- | --- |
| A1 打开活动 | B1/C/D；收起 F2/F3 | 再点铃铛或 B1 关闭，回到原 Chat；不自动恢复上一个侧栏。 |
| B1 搜索 | F1 聚焦搜索输入 | 原搜索关闭行为返回 B1 搜索按钮，活动保留。 |
| C2 定时任务 | F2 接管右侧栏 | 活动收起；详情依原合同导航。 |
| C2 Chat／D1 历史 | `handleSelectThread` | 活动收起，目标 Chat 接管。 |
| C2 Dream | `openDreamRun(run.href)` | 原导航与修饰键行为；目标页面接管。 |
| 原入口打开 F3 | 原右侧栏 | 活动收起；目标原侧栏接管焦点。 |
| E1 打开后 Escape | 菜单关闭 | 返回 C1 省略号，不同时关闭活动。 |

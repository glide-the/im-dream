# docs/architecture — 目录合同

## 架构摘要

Ink & Memory 的项目级架构文档，覆盖 Next.js Dream Web、Python 后端、Admin/Gateway/PostgreSQL 拓扑，以及模块、API、认证、数据流、Claude Agent SDK/Runtime 与发布边界。

Registry130-133 已将 Dream launch 的 enabled Deck/Workspace/Voice scope、current/frozen binding、lock、Runtime metadata、source、Preflight、Run、dispatch 与失败持久化迁入 Admin。Chat、Reflections、launch、confirmation 与 Guidance 均在进入 ThreadFactory 前构造绑定 actor/Thread/Run 的 Admin owner；`ClaudeAgentService` 不含 SQL、database import 或生产回退。Dream 保留请求编排、共享 artifact/CLI 校验、Runtime、SSE 与文件系统。

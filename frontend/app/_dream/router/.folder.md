# frontend/app/_dream/router — Folder Contract

## Architecture Summary

Pure Story Workspace path/context seams live beside the React router adapter.
Authenticated navigation stays inside the shared Story Workspace layout and canonical Chat bridge.

## File Table

| File | Pos | Function |
|---|---|---|
| `story-workspace.tsx` | `Story Workspace router adapter` | Resolve browser location and the optional stable Episode query, render the shared sidebar layout, and connect route surfaces to canonical Chat/Dream handoffs. |
| `storyWorkspacePath.ts` | `pure route seam` | Match canonical paths, build index-first Execution URLs, exact opaque Episode selections or allowlisted one-shot Reflections section links, and reject unsupported historical prefixes. |
| `storyWorkspaceChatBridge.ts` | `Chat handoff bridge` | Carry an exact bound Thread into canonical Story Workspace Chat. |
| `storyWorkspaceDreamContext.ts` | `Dream context seam` | Project the fixed Dream workspace context consumed by router surfaces. |
| `__tests__/` | `router seam tests` | Lock pure path, Chat bridge, and Dream context contracts. |

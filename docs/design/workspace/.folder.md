# Workspace — Design Documents

Design documents for the workspace file management subsystem, ported from
[`claude-agent-next-kit`](https://github.com/glide-the/claude-agent-next-kit/tree/feat/claude-agent-kit).

> policy that explicitly allows built-in file tools under the current workspace
> `files/` directory, low-risk query tools, `Skill`, and `switch_editor` in
> auto mode; high-risk tools use the frontend confirmation side-channel.
> `Content-Disposition` handling for non-Latin workspace filenames.
> Code Bash sandbox settings written into `{workspace}/.claude/settings.json`.
> nested sandbox detection for Claude Code Bash sandbox.
> `denyWrite` protects `.claude` internals without blocking `.claude/skills/`.
> `workspace-skills-flow.md` document importing real `.claude/skills/`
> writes into `workspace/skills/` before rebuilding discovery symlinks.
> network mode omits `sandbox.network` instead of writing `allowedDomains:["*"]`.
> downloads through the existing authenticated file download endpoint.

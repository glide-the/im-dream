# frontend/

## 架构概述
React 19 + Vite + TypeScript SPA，部署路径 `/ink-and-memory/`，容器启动时生成 runtime-config 以支持跨域后端请求。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| Dockerfile | 容器构建 | 多阶段构建：Node 22 编译 → nginx 1.27 服务静态文件；npm registry 通过 build arg 配置，默认使用国内镜像 |
| nginx.conf.template | 静态服务/兼容代理模板 | 服务 `/ink-and-memory/` 静态文件；对 SPA HTML 与 `runtime-config.js` 禁用缓存；保留 `${BACKEND_URL}` 反向代理作为同源 fallback |
| docker-entrypoint.sh | 容器入口 | 渲染 nginx fallback 配置和 `/ink-and-memory/runtime-config.js`，注入 `API_BASE_URL` / `WS_BASE_URL` |
| .dockerignore | 构建优化 | 排除 node_modules、dist、.env 等 |
| package.json | 依赖管理 | npm 依赖声明，`npm run build` 输出到 `dist/` |
| vite.config.ts | 构建配置 | base `/ink-and-memory/`，dev proxy 到 localhost:8765 |
| src/ | 应用源码 | React 组件、路由、API 调用 |
| public/ | 公共资源 | 字体/图片，以及 runtime-config 模板与默认配置 |

# frontend/mobile

## Architecture Summary

This folder compiles the HTML, styles, and bootstrap entry for both native hosts. It imports the canonical `DreamRoot` and mounts it after the existing Python/auth/transport checks succeed. One local timer bounds the initial check; failure displays one message and a retry action.

## File Table

| File | Position | Function |
| --- | --- | --- |
| `index.html` | packaged document entry | Provide the fixed root consumed by the native local-origin handler. |
| `entry.tsx` | mobile bootstrap | Read app/startup facts, install the local transport after readiness, and mount `DreamRoot`. |
| `mobile-shell.css` | startup surface style | Render safe-area-aware loading and blocked states before the product root qualifies. |

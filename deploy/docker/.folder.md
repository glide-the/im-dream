# deploy/docker/

## 架构概述
Docker 发布脚本目录，复用根目录 `docker-compose.yml` 与前后端 Dockerfile；frontend image 运行 standalone Next.js，历史 Nginx 模板不在默认运行路径。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | Docker 发布入口 | 检查 Docker/Compose、本地配置和 `deploy/clash/config.yaml`，构建 standalone Next.js 与 FastAPI image，启动、验证、停止和清理 Compose 服务；当前仍检查不被默认 image 消费的 `frontend/nginx.conf.template`，这是待清理的兼容前置而非 Runtime owner |

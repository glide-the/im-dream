# 主对话图片能力与Image模型选择

## 背景与问题

用户选择AI模型来理解和回复对话；选择Image模型来决定明确要求image_gen时使用的图片服务。共享Gateway不能使两种用途自动等同。当前模型的图片勾选只对应独立图片工具，主对话尚没有完整内置图片调用支持，不能向用户展示已经具备这项能力。

本专项关联[现有聊天图片PRD](image-generation.md)、[草图输入](sketch-input.md)、[正式设计](../../design/claude-agent/image-model-call-division.md)与[本轮执行记录](../../exec/image-model-call-division-20261010.md)。旧稿原文继续保留，不用本稿覆盖历史证据。

## 目标与边界

设置页在现有AI模型选择下方增加Image模型选择。两种选择有清楚的用途和独立保存反馈。普通图片生成与编辑只能使用当前AI模型已支持且可调用的内置能力；用户明确要求image_gen时使用Image模型。系统不替用户切换模型、改变调用方式或同时生成两次。

本轮最小交付包括设置、目录、独立图片工具选择、用途规则及未支持能力的明确反馈。主对话内置图片成功路径仍须完成Gateway结果转换、CLI/SDK兼容、文件历史和计费后才开放；当前不宣称已经实现该成功路径。上传、绘制草图、文件查看、下载与原会话保存继续复用。没有新的创作页面、确认弹窗、后台任务或数据库。

## 概念与规则

| 用户控制 | 用途与范围 |
|---|---|
| AI模型 | 主对话的理解与回复；模型列表分别标记真正支持的主对话图片生成和编辑。独立图片工具能力不能用作这些标记。 |
| Image模型 | 仅供明确要求image_gen的生成和编辑。候选为Admin发布给独立图片接口的模型，展示各自生成/编辑能力和不可用原因。 |
| 上传图片与绘制草图 | 当前消息素材；添加时没有推理或图片调用，也不选择调用方式。 |
| 图片查看与下载 | 读取已经完成的图片；重新加载不重新生成。 |

AI沿用平台默认值，用户已保存选择优先。Image初始显示“未选择”，用户选择后自动保存；没有单图模型自动选择、平台AI默认代用或服务器模型环境变量回退。用户保存的选择失效时保留其名称，提示重新选择；不自动选一个替代项。保存只影响此后的调用，正在执行的操作维持既有选择与原停止语义。

普通需求例如“画一幅山水画”“把这张图片的背景改为夜景”，使用AI模型对应的内置能力。明确需求例如“请使用image_gen生成山水画”，才使用独立工具。“image_gen是什么”“这段代码提到image_gen”属于讨论，不能因此调用。素材上传本身也不能触发生成。意图由主对话结合上下文理解；名称匹配不能替代意图理解。模型行为尚需真实验收，不能把提示词检查当成语义验收。

## 设置与完整流程

用户从现有设置栏目打开模型区域。AI列表显示主对话模型名称、可用状态及真实图片标记；Image列表紧随其后，说明“仅用于明确要求image_gen工具的图片生成和编辑”。生成与编辑是独立标记，支持其中一项的模型也可以展示。

选择可调用模型后自动保存，服务器回读确认后分别反馈已保存。明确拒绝时保留上次确认选项，按原因重新选择。网络中断、成功响应无法解析或回读值不一致时，提示“保存结果未确认”，暂时禁用两项选择；用户点击“重新加载设置”核对实际保存值后继续，不能声称一定未写入或自动重发。目录加载失败保留最近成功目录但禁用保存，提供重新加载；配置读取失败也禁用保存，不能将未知配置展示为未选择。模型停用、配置未就绪、权限或额度问题分别提供重新选择、联系管理员或查看订阅的操作。

用户回到主对话描述需求，可使用上传图片、草图或当前会话图片作素材。图片操作完成后在现有回复中查看新图，打开查看器下载，继续修改或重开原会话。编辑保留原图。原生成状态、工具授权、停止、断线恢复与消息保存继续复用。

## 不支持与恢复

当前AI模型不支持或执行链路尚未支持图片生成/编辑时，回复明确说明该操作不能完成。用户可以进入设置自行选择具有相应可调用标记的AI模型后重新发送；若目录中没有此能力，反馈直接说明当前没有可选模型。用户也可以自行选择Image模型并在新需求中明确要求image_gen。系统不自动执行恢复动作。

Image未选择、失效或不能执行当前编辑/生成时，工具反馈要求进入设置选择支持本次操作的可用Image模型；重新发送才产生新调用。生成失败、结果解析失败、文件保存失败、消息保存失败与图片访问失败分别反馈。访问失败使用原重新加载入口；断线使用原会话恢复，不自动重做图片。停止保留已完成结果。

标记可换行，单选框可用键盘操作，保存结果用aria-live反馈，不依赖颜色表达能力或不可用状态。

## 验收

两项选择分别保存、刷新恢复并只影响对应用途。AI标记不借用独立Images能力；上传/草图不触发生成；名称讨论不触发image_gen；明确image_gen只调用所选Image模型，不同时调用内置能力。图片完成、原图保留、查看下载、保存重开和失败恢复一致，真实调用身份可追溯。

[正式设计验收矩阵](../../design/claude-agent/image-model-call-division.md#验收矩阵与发布边界)区分已经实现、隔离技术验证与未实现/未验收。主对话内置成功路径缺失时不能宣称专项完整完成。

## 管理员连接配置补充（2026-10-10）

管理员在原Provider设置中为通用OpenAI连接选择上游实际支持的Chat或Responses接口；旧连接默认Chat。该选择只影响主对话通信，独立图片工具继续使用Images接口。选择Responses不自动发布图片生成或编辑能力。切换须通过已有模型的连接验证；尚无验证模型时先登记模型再激活或切换。保存失败保留原配置；版本冲突保留草稿，重新加载后核对再保存。托管产品仍由其既有连接流程管理。

该前提的源码已实施，专项成功图片流程仍未完成；具体协议、并发与验收状态见[正式设计](../../design/claude-agent/image-model-call-division.md)和[执行记录](../../exec/image-model-call-division-20261010.md)。

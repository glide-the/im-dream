# docs/prd/deck

## Architecture Summary

本目录按思维模式业务归属保存产品规则与页面骨架。Deck 是现有代码与接口中的承载形式。
正式交互图由关联的 `docs/design/deck/` 或 `docs/design/deck-plugin/` 设计稿负责。

## File Table

| File | Pos | Function |
| --- | --- | --- |
| `thinking-modes.md` | 现行思维模式 PRD | 定义产品名称、概念、中文用语范围、桌面与窄屏骨架、状态及验收。 |
| `deck-workflow-plugin.md` | Deck 工作流插件 PRD | Dream Story Workflow 用途、设置目录及 Deck 维护桌面/窄屏骨架、工作流版本和连接边界。 |

结构要点：

- `A1` 与现有 `PlanButton` 同属顶部右侧浮动操作区；它只负责入口，不在按钮下方展开大型弹层。
- `B1` 是对话 `<main>` 的兄弟节点，沿用 `FileSidebar` 的宽度归零、左边框与过渡方式。
- `B2` 固定在面板顶部；`C1` 至 `D3` 位于独立滚动内容区。
- 文件侧栏与子智能体侧栏互斥，避免聊天正文被两层右栏同时挤压。

## 4. 窄屏抽屉结构

```text
┌──────────────────────────────────────────────┐
│ ChatViewContent                              │
│                                              │
│  对话内容（被半透明遮罩覆盖）                │
│  ┌──────────────┬─────────────────────────┐  │
│  │              │ B1 右侧覆盖式抽屉      │  │
│  │   遮罩区     │ ┌─────────────────────┐ │  │
│  │   点击关闭   │ │ B2 ◎ 子智能体   [×]│ │  │
│  │              │ ├─────────────────────┤ │  │
│  │              │ │ C1 已开启           │ │  │
│  │              │ │ C2 / C3            │ │  │
│  │              │ │                     │ │  │
│  │              │ │ D1 完成 · N         │ │  │
│  │              │ │ D2 可滚动任务列表   │ │  │
│  │              │ │ D3 加载更多         │ │  │
│  │              │ └─────────────────────┘ │  │
│  └──────────────┴─────────────────────────┘  │
└──────────────────────────────────────────────┘
```

- 抽屉宽度为 `min(22rem, 100vw)`；极窄屏可占满视口。
- 打开后焦点进入 `B2`，关闭或按 `Escape` 后返回 `A1`。
- 面板滚动不带动聊天主区，减少动效设置下取消非必要位移动画。

## 5. 模块索引

| 编号 | 模块名称 | 父级/位置 | 核心内容 | 显示条件与结构关系 |
| --- | --- | --- | --- | --- |
| A1 | 子智能体入口按钮 | 聊天主区顶部右侧操作栏 | 子智能体 SVG、展开态、运行/未读点 | 当前线程至少存在 1 条真实任务记录时显示；控制 B1 |
| A2 | 最近代理与汇总 | A1 内部扩展区 | 最多 4 个代理头像、运行数、完成数 | 宽度足够时显示；窄屏隐藏文字但保留 tooltip/aria-label |
| B1 | 右侧详情面板容器 | `ChatViewContent` 根级、`main` 右侧 | 受控 `<aside>`、边框、宽度动画、滚动容器 | A1 打开后显示；与 `FileSidebar` 互斥 |
| B2 | 面板标题栏 | B1 顶部 | 图标、“子智能体”、关闭按钮 | 面板打开时常驻，不随内容滚动 |
| C1 | 已开启分组标题 | B1 内容区第一组 | “已开启”与 active 数量 | 有历史任务时显示 |
| C2 | 已开启任务列表 | C1 下方 | 头像、任务名、状态、摘要、已运行时长 | `pending/running` 数量大于 0 时显示，按开始时间倒序 |
| C3 | 已开启空状态 | C1 下方 | “没有已开启的子智能体” | 有历史记录且 active 数量为 0 时替代 C2 |
| D1 | 完成分组标题 | C2 或 C3 下方 | “完成 · N” | 有历史任务时显示，N 使用服务端完整计数 |
| D2 | 已完成任务列表 | D1 下方 | 头像、单行标题、两行摘要、右对齐耗时 | completed 数量大于 0 时显示，按完成时间倒序 |
| D3 | 加载更多 | D2 末尾 | 次级按钮或局部加载骨架 | `nextCursor` 存在时显示；分页失败不替换 D2 |
| E1 | 初次加载骨架 | B2 下方内容槽 | 3–5 条头像/标题/摘要骨架 | 无可用快照且正在首次水合时，替换 C1–D3 |
| E2 | 全局空状态 | B2 下方内容槽 | 机器人图形、无任务文案 | REST 成功且线程任务总数为 0 时，替换 C1–D3 |
| E3 | 错误/离线状态 | B2 下方或正常列表上方 | 错误说明、过期提示、重试按钮 | 无缓存时替换列表；有缓存时作为列表上方非阻塞提示 |

## 6. 结构状态切换

```text
A1 点击
   │
   ├─ 当前关闭 ──> 打开 B1 ──> 关闭 FileSidebar
   │
   └─ 当前打开 ──> 关闭 B1 ──> 焦点返回 A1

B1 内容槽
   │
   ├─ 首次水合中且无快照 ──> E1
   ├─ 水合成功且 total = 0 ─> E2
   ├─ 有数据且 active > 0 ──> C1 + C2 + D1 + D2 (+ D3)
   ├─ 有数据且 active = 0 ──> C1 + C3 + D1 + D2 (+ D3)
   └─ 请求失败 ─────────────> E3（有旧快照时与正常列表并存）
```

此结构确保入口元信息、运行任务、完成数量、摘要与耗时均有明确承载位置，同时保持现有 React 聊天页面的主从关系：聊天是主内容，子智能体信息是受控的会话级辅助侧栏。

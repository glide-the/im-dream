# frontend/

## 架构概述
React 19 + Vite + TypeScript SPA，部署在前端 origin 根路径 `/`，容器启动时生成 runtime-config 以支持跨域后端请求。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| Dockerfile | 容器构建 | 多阶段构建：Node 22 编译 → nginx 1.27 根路径服务静态文件；npm registry 与 `VITE_PUBLIC_SITE_URL` 通过 build arg 配置 |
| nginx.conf.template | 静态服务/兼容代理模板 | 从 `/` 服务静态 SPA；对 SPA HTML 与 `runtime-config.js` 禁用缓存；保留 `${BACKEND_URL}` 反向代理作为同源 fallback；根级 SEO 文件代理到后端生成器；Docker Compose 中通过 `127.0.0.11` resolver 解析 `ink-backend` |
| docker-entrypoint.sh | 容器入口 | 渲染 nginx fallback 配置和 `/runtime-config.js`，注入 `API_BASE_URL` / `WS_BASE_URL` |
| .dockerignore | 构建优化 | 排除 node_modules、dist、.env 等 |
| package.json | 依赖管理 | npm 依赖声明，`npm run build` 输出到 `dist/` |
| vite.config.ts | 构建配置 | base `/`，dev proxy `/api` / `/polycli` 到 localhost:8765，并在 HTML 构建期替换 SEO public URL / image placeholders |
| index.html | HTML 入口 | SPA HTML shell；包含 Codex SEO metadata、Open Graph/Twitter tags、JSON-LD WebApplication schema 和非 JS crawlable product overview |
| src/ | 应用源码 | React 组件、路由、API 调用 |
| public/ | 公共资源 | 字体/图片，以及 runtime-config 模板与默认配置 |

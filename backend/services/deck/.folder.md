## Architecture Summary

Deck-domain application services. This folder resolves server-owned Deck
plugin policy, runtime locks/context, default provisioning, and Story Workflow
operations without accepting filesystem paths or installation identities from
the browser.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | package init | Mark the Deck service package. |
| `admin_gateway.py` | Deck Plugin admin adapter | Call Admin plan/apply with the current OAuth actor; verify only server-published local artifact directory, manifest and digest; never open PostgreSQL or retry an unknown write. |
| `agent_type.py` | Deck Agent type policy | Purely derive `chat` / `dream` from the Admin-supplied published manifest; list/detail projection stays in Admin. |
| `agent_type_runtime.py` | Agent-type local verifier | Derive Registry129 immutable evidence from Admin's closed candidate using the configured shared artifact store, manifest parser and current Claude CLI; no paths or persistence cross the API. |
| `builtin_plugin.py` | built-in plugin source | Resolve and hash the repository-owned Dream Story plugin for Admin-planned local evidence; persistence belongs to Admin. |
| `chat_context.py` | Admin Deck context policy | Validate one Registry105 DTO snapshot, apply enabled/ready and selected-Voice rules, and expose prompt provenance without database access. |
| `defaults.py` | Deck-default local verifier | Verify Admin's configured six-field candidate against shared artifact bytes and the current Claude CLI, then return the four-field evidence used by Admin-owned Deck transactions. |
| `sharing.py` | Deck sharing policy | Derive publication eligibility and reject system-default publishing, self-collection, and collection of unpublished Decks. |
| `story_workflow_application.py` | Story Artifact application service | Authorize remaining Run-scoped Dream file/Artifact/index operations and expose body-free Episode/selected artifacts. Preflight, public Run read/create/retry/cancel, Guidance and confirmation persistence use Admin DTOs; confirmation keeps the local shared-filesystem projection, while Artifact SQL callers remain tracked. |

# Folder Plan: docs/exec/mcp-apps

## Purpose

保存 MCP Apps Phase 0—3 的当前候选技术验收和各阶段细化证据。这里的 `Go` 只表示 provider-free 技术链路完成；真实外部 Server、真实账号和生产发布仍由独立验收负责。

## Files

| Path | Role |
|---|---|
| `current-candidate-validation.md` | 当前 pnpm、官方制品、Backend/Node/Browser、构建与发布边界的统一回执。 |
| `phase-0/` | P0-01—P0-08 当前证据与唯一 decision。 |
| `phase-1/` | N1/C1/S1/M1/H1 当前证据、历史对照与 Phase 1 decision。 |

## Boundary

证据不得包含 credential、真实 Server URL、账号正文、完整对话或生产数据库写入。测试只清理自己创建的端口、进程和临时产物。

# 第三阶段：外部链接管理层级逻辑

## 背景与问题

用户要求在设置中管理已生成的AI对话与笔记链接，并可主动使链接失效。参考概览图提供“类别 → 数量 → 最近分享 → 进入箭头”，参考列表图提供“返回 → 平铺记录 → 行更多”的层级。

本阶段综合[初稿](1_prd_draft.md)、[第二阶段结构](2_structure_sketch.md)与两张原始截图，将页面空间及操作归属映射为父子关系。[现行PRD](../../../../prd/sharing/external-links.md)持有产品规则和完整桌面/窄屏骨架，[正式交互稿](../../external-links.md)持有正常业务、异常恢复和状态转换。

## 目标与边界

- 设置中的“外部链接”与原设置栏目同层；AI对话与笔记为两个同级分类。
- 概览承接类别选择与有效数量，分类列表承接单条管理，行菜单和行内展开承接操作与恢复。
- 仅设计单条主动失效。独立快照和管理记录在原内容删除后保留，原内容可用性单独提示。
- 管理页面与失效控制待实现。AI链接创建为后续接入依赖；本阶段保留分类设计，具体AI分享协议留待对应设计。
- 自动测试保持暂停；本阶段仅核对保存文件存在性，图示语法和功能验收留待后续。

## 概念与规则

### 范围收敛记录

| 输入或方案 | 判断与选定结果 |
| --- | --- |
| 用户“实效”操作 | 按主动使链接失效定义；对象为用户选定的单条链接。 |
| 设置内两类概览与分类名单 | 对应参考图和当前AI对话、笔记范围；选用既有第二阶段结构。 |
| 初稿新增“删除原内容自动关闭全部链接” | 涉及原业务删除流程及已有快照行为变更，退出本次范围；该扩展保留在初稿过程证据中。 |
| 独立快照及管理记录持续保留 | 原内容删除后显示“原内容已删除”，完整分享标题与原地址持续可读，有效链接继续供外部阅读并可主动失效；选用。 |
| 单条状态 | 链接状态仅为有效、已失效；提交中、明确失败和结果待确认只描述本次操作。 |
| 数量 | 按已确认有效链接条数统计；原内容删除、提交中和结果待确认均保留最后确认数量。 |
| 旧地址与重新分享 | 已失效为单向终态，原业务重新分享创建新链接；原内容及同源其他链接保持当前结果。 |

原内容已删除提示适用于有效和已失效两种记录。原内容暂时无法读取时展示恢复反馈，确认删除后才展示删除提示。用户只能查看和操作自己的管理记录。

### 功能区域编号

| 编号 | 区域 | 上级与意图 |
| --- | --- | --- |
| M1 | 设置外壳 | 根区域；拥有栏目导航与外部链接内容区。 |
| M1.1 | 原设置导航 | 属于M1；负责栏目进入，保留桌面、窄屏Web及原生导航关系。 |
| M1.2 | 外部链接内容区 | 属于M1；概览和分类列表择一展示，拥有单一纵向滚动。 |
| M2 | 页面头部 | 属于当前视图；概览展示用途，列表展示类别及返回入口。 |
| M3 | 两类概览 | 属于概览视图；分类选择。 |
| M3.1、M3.2 | AI对话卡片、笔记卡片 | 属于M3；各自展示有效数量、最近有效分享与进入箭头。 |
| M4 | 状态与刷新 | 属于分类列表；选择有效/已失效及刷新当前结果。 |
| M5 | 分类记录 | 属于分类列表；按发布时间从近到远展示当前类别和状态的记录。 |
| M5.R | 单条记录 | 属于M5，可重复；链接标题、地址、时间、状态和原内容提示共同定位操作对象。 |
| M6 | 行更多菜单 | 属于当前M5.R；靠近该行展开，展示完整标题与可用操作。 |
| M7 | 行内展开区 | 属于当前M5.R；链接信息、手动复制或操作反馈占用原行下方空间。 |
| M8 | 整区反馈 | 属于当前视图；占位、空状态、首次读取失败及已有数据刷新失败。 |

M2与M8在概览和列表中按当前视图复用。M6覆盖当前行附近空间，M7随原行展开并推动后续记录；两者均保留在分类列表层级。

## 页面层级结构图：逻辑树

```text
Root 设置
└── M1 设置外壳
    ├── M1.1 原设置导航
    │   └── 外部链接入口：进入管理概览
    └── M1.2 外部链接内容区：当前账户、单一纵向滚动
        ├── 概览视图
        │   ├── M2 页面头部：用途说明
        │   ├── M3 分类选择
        │   │   ├── M3.1 AI对话：有效条数、最近标题、进入箭头
        │   │   └── M3.2 笔记：有效条数、最近标题、进入箭头
        │   └── M8 概览反馈：加载、读取失败、重试
        └── 分类列表视图：AI对话或笔记择一
            ├── M2 页面头部：分类名称、返回概览
            ├── M4 视图选择与刷新
            │   ├── 有效：默认视图，展示仍开放的链接
            │   ├── 已失效：展示旧链接记录
            │   └── 刷新：核对当前状态及数量
            ├── M8 列表反馈
            │   ├── 首次加载、空列表、首次读取失败
            │   └── 已有数据刷新失败：保留记录与最后确认数量
            └── M5 当前分类记录
                └── M5.R 单条记录，可重复
                    ├── 识别信息：分享时标题、地址、时间、链接状态
                    ├── 原内容提示：确认删除后显示原内容已删除
                    ├── M6 行更多菜单：完整标题、当前可用操作
                    │   ├── 有效：复制链接、打开公开页面、使链接失效
                    │   ├── 已失效：查看链接信息
                    │   └── 查看原内容：按原内容可用性提供
                    └── M7 行内展开区：按当前动作择一展示
                        ├── 链接信息：完整标题、旧地址及时间/原因
                        ├── 手动复制：可选中完整地址
                        └── 单条反馈：提交中、明确失败、结果待确认
                            └── 恢复：重试或刷新状态
```

### 页面与操作关系

| 用户操作 | 层级变化或反馈归属 | 状态与数量规则 |
| --- | --- | --- |
| 进入外部链接 | M1.1 → 概览M2/M3/M8 | 按当前账户读取已确认结果。 |
| 选择AI对话或笔记 | M3卡片 → 分类列表 | 首次默认有效，分类内保留已选状态视图。 |
| 点击更多 | 当前M5.R展开M6 | 保持分类、状态视图和滚动位置。 |
| 复制失败或查看链接信息 | 当前M5.R展开M7 | 完整标题、地址持续可读，数量保持。 |
| 使链接失效 | 收起M6，M7显示提交中 | 仅锁定本条重复失效，其他记录可继续操作。 |
| 请求结果待确认 | M7提供刷新状态 | 保留最后确认链接状态和有效数量，本条失效及打开暂不可用。 |
| 确认已失效 | 当前有效行移出，轻提示反馈 | 采用已确认数量；最后一条移出时显示有效空状态。 |
| 原内容已删除 | M5.R及M7展示原内容提示 | 保留链接当前状态、完整标题、旧地址和主动失效能力。 |
| 重新分享 | 返回仍存在的原内容，沿原分享入口创建 | 新链接进入有效记录，旧失效链接持续保持终态。 |

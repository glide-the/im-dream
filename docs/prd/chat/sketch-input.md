# Chat 图片与草图输入

## 背景与问题

用户需要上传已有图片，也需要现场画出布局或在图片上标记位置。现有 Chat 已提供文件上传和简单草图，绘图代码属于聊天目录，缺少独立组件边界。参考 CharcoalNarrative 的炭笔和图片分层合成能改善画图体验，但故事、年代和模拟 AI 不能成为 Chat 的依赖。

## 目标与边界

用一个前端组件包完成“打开草图、导入图片或手绘、修改、添加到消息、上传、发送、查看”的流程。包内按职责分模块，不拆成多个 package。草图输出为白底 PNG；绘图和图片解码均在浏览器本地完成。普通上传文件、粘贴和拖拽继续沿用原入口。

保持原 CharcoalNarrative 的纸张纹理画布、左上标识、右上悬浮图标工具栏、图层/橡皮工具箱、左侧纸片快照历史。提供炭笔、橡皮大小与图层目标、撤销/重做/清空、导入/替换图片、缩放/移动/视图复位、两层显隐及历史快照恢复。图片按比例置于画布中，描画位于图片上方；橡皮默认擦手绘，也可显式选择底图。视图缩放和移动帮助编辑，不改变导出范围或图片尺寸。不提供作品库、年代切换、叙事、AI 生图按钮、可编辑附件历史。AI 图片处理另见 [图像生成 PRD](image-generation.md)。

## 概念与规则

- 草稿：本输入框拥有的图片层和可撤销操作。在返回后保留，刷新、离开会话或更换输入框后不恢复；不同 Thread 不共享草稿。
- 导入图片：选择本地图片，在浏览器解码后作为底图；不上传、不发消息。解码成功后替换底图，保留手绘笔画；可撤销替换。图片的大小检查复用宿主现有上传限制，组件不设新配额。非图片、损坏图片或解码失败显示错误，原草稿保持不变。文件选择取消保持原状态。
- 绘制：炭笔生成颗粒笔触；每个笔画固定随机 seed，撤销/重做、重开及视图调整不会改变颗粒。橡皮默认仅移除笔画；选择图片层后以透明擦除底图，PNG 仍合成白底。图层按钮分别控制手绘/底图显示，导出当前可见层；两层都隐藏或无有效内容时不能添加。一次完整笔画、一次图片导入和一次清空各为一个历史操作；新操作结束重做分支。
- 清空：移除图片和笔画，可撤销，无确认弹窗。
- 历史：左侧纸片缩略图按最新操作在前排列，选择后恢复该步骤的图片、笔画及显示状态；新操作结束重做分支。清空历史保留当前两层内容作为新的起点，仅移除回退步骤，不上传、不影响消息历史。打开时聚焦关闭按钮，关闭、Escape 或恢复步骤后焦点返回历史入口，Escape 先关闭历史抽屉。
- 返回：直接回输入框并保留草稿；正在解码则取消此次解码，禁止迟到结果改写草稿。上传中的返回暂不可用，避免产生重复附件。
- 添加到消息：导出整张白底 PNG 并沿用 `handleFiles` 上传，不发消息、不调用模型。空白且无底图或仍在绘制时不能添加。白色图片仍属于有效已导入内容。
- 添加失败：保留图片和笔画，显示重试反馈；成功后清空草稿并关闭弹窗，进入现有待发送附件状态。
- 发送：等待上传成功，保持原 name/type/size/storageKey/url/workspacePath DTO；发送失败恢复文字与附件。历史只恢复已经发送的图片，不恢复笔画。

└────────────────────────────────────────────────────────┘

## 业务接入与验收

公开业务入口仍为 `AIInputDock` 的添加菜单。`SketchInputDialog` 负责 Modal/国际化/草稿与上传回调；`@ink-dream/sketch-input` 负责本地编辑和 PNG 输出。正式时序、状态、恢复及评审见 [交互设计](../../design/claude-agent/sketch-input-interaction-design.md)，范围与命令见 [本轮执行记录](../../exec/sketch-package-20261013.md)。[历史原文](sketch-input-v1-20261009.md) 保留旧功能边界和旧验收事实。

验收覆盖：图片选择取消、非法/损坏图片、导入/替换/撤销、图片上描画、笔画稳定重放、橡皮/大小、清空恢复、缩放移动不改输出、pointer 取消、返回重开、PNG 解码、上传/发送失败重试、移除、普通上传、文本/slash/Send/Stop、键盘、触摸及桌面/窄屏/短屏。另验收底图/笔画显隐、两种擦除目标、快照恢复/清空历史、双指视图手势，以及纸张/悬浮工具箱/历史抽屉与原组件的视觉结构。组件不依赖数据库或模型完成编辑；技术故障注入与正常账户上传/查看分别记录。

添加不自动启用 Workspace Mode。真实模型的视觉输入及图片工具仍取决于既有会话能力；本次组件迁移不改变它们。正常账户附件和历史验证不能扩大为模型理解或图片生成验收。

# frontend/src - Folder Contract

## Architecture Summary
React 19 app source for the Ink & Memory frontend.
Owns the app root, global styles, i18n setup, and first-level feature folders.
Routes every authenticated view through the single Story Workspace shell while feature folders own focused UI behavior.
`App.tsx` canonicalizes unsupported authenticated paths to Story Workspace Chat and projects Writing into the shared workbench; its related Thread reuses canonical Chat in a resizable right pane. Writing suggestions are explicit persistent Editor Cells whose Session-owned Claude Thread is created on the first click and restored from the opaque EditorState; only the latest suggestion remains regeneratable. The browser-only `/oauth/callback` route renders before authentication loading, submits the private callback URL directly to its actor-owned Dream operation, and never renders or stores authorization code/state.
The chat view is mounted in a fixed flex viewport so landing panels inherit a stable height and cannot push body/window scrolling.
Connector navigation now routes into Settings / Work's resource-link tab; Chat keeps only the lightweight connector landing panel and a Settings CTA. Claude MCP server details use a refresh-safe `mcp-server` query and return to the same Resources tab.

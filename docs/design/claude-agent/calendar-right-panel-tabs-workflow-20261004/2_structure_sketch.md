# Stage 2：页面结构草图

优化后的执行提示词：读取 Stage 1、现行 PRD 和附件，使用项目当前主题与图标语义，把日历左月历和右侧三个互斥栏目表达为结构草图。沿用 P01–P10 模块编号，展示桌面、窄屏、任务 LIST/RESULT、Notion 双分组及局部失败；明确切换后的状态保留、日期与重开规则、既有 Modal 的焦点边界。只输出中文文档，不生成 HTML、JavaScript 或功能代码，不把示意数据当作查询结果，不将 Search 可发现范围改称全部资源。

交付项：本结构稿与同目录清单条目；产品规则以[现行 PRD](../../../prd/calendar/calendar-right-panel-tabs-prd.md)为准，输入观察见 [Stage 1](./1_prd_draft.md)。

## 1. 背景与问题

当前右侧任务与日记同时展示，任务列表与结果已经在任务纸面内切换。附件提供的是导航密度规则：选中项同时呈现图标和名称，未选中项主要呈现图标。它没有指定本项目栏目、深色主题或内容布局。

## 2. 目标与边界

左月历保持原日期导航、日记标记及打开规则，右侧由页签栏和一张当前栏目纸面组成。已登录时栏目顺序为定时任务、日记、Notion，以下三个栏目草图均采用已登录场景。现有任务和日记业务入口保留；Notion 只读元数据与外链打开，不引入全文编辑、同步或资源选择流程。

## 3. 概念与规则

以下草图只用于说明结构，日期、时间、标题和数量均为示意，不是实际 Notion 查询或业务验收。`[钟]`、`[文]`、`[N]` 分别代表项目现有任务图标、文档图标与 Notion 字形，不是新增字符按钮。`(( ))` 表示选中项的圆角背景；颜色、字体和焦点样式由现有设计 token 决定。

P04 内只显示 P05、P06 或 P07–P09 组成的 Notion 内容。隐藏面板不能被辅助技术读出或进入键盘焦点顺序。保留状态不等于允许隐藏面板继续加载、轮询或显示 Portal。

## 4. 桌面结构

```text
┌ P01 现有日历 Modal ─────────────────────────────── 关闭 ┐
│ ┌ P02 月历纸面 ───────────┐  P03 日历栏目                 │
│ │ 上月    当前年月    下月 │  (([钟] 定时任务)) [文] [N]  │
│ │ 周一 …………………… 周日    │  ┌ P04 当前栏目纸面 ────────┐ │
│ │ 日期格、所选日、日记标记 │  │ P05 定时任务             │ │
│ │ 保留现有月历交互         │  │ 所选日期 · 安排输入       │ │
│ │                          │  │ 任务列表或任务结果        │ │
│ └──────────────────────────┘  │ 当前栏目独立滚动          │ │
│                                └──────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

页签始终位于右栏顶部；P04 承载当前内容，不在其后继续叠放第二张可见业务纸面。月历与右栏保持桌面并列。长结果延续既有正文滚动，栏目切换保持可达。

## 5. 窄屏结构

```text
┌ P01 日历 Modal ─────── 关闭 ┐
│ ┌ P02 月历纸面 ──────────┐ │
│ │ 年月导航与原有日期格    │ │
│ └────────────────────────┘ │
│ P03 [钟] (([文] 日记)) [N] │
│ ┌ P04 当前栏目纸面 ──────┐ │
│ │ P06 所选日的日记        │ │
│ │ 文档图标 · 日记标题     │ │
│ │ 当前日记标识 · 打开     │ │
│ │ 既有删除入口            │ │
│ └────────────────────────┘ │
└────────────────────────────┘
```

窄屏按月历、页签、当前内容顺序排列。只有选中项显示名称以控制导航宽度；所有页签始终有完整可访问名称。标题允许换行或省略，按钮组和内容容器允许收缩，不产生页面水平滚动。

## 6. 定时任务 LIST 与 RESULT

```text
P04 / P05 LIST                    P04 / P05 RESULT
┌────────────────────────────┐    ┌────────────────────────────┐
│ 定时任务 · 所选日期         │    │ 返回任务列表               │
│ 安排任务输入与既有发送入口  │    │ 任务标题 · 本次结果状态     │
│ 任务标题 · 状态 · 下次执行  │    │ 既有结果正文               │
│ 查看结果 · 更多操作         │    │ 既有精确执行 Thread 入口   │
│ 编辑 / 历史及现有任务动作   │    │                            │
└────────────────────────────┘    └────────────────────────────┘
                     P10 既有编辑或历史 Modal
                ┌─────────────────────────────────┐
                │ 原编辑字段或历史分页 · 关闭入口  │
                │ 原校验、保存失败与 revision 反馈 │
                └─────────────────────────────────┘
```

RESULT 不增设编辑或历史按钮，返回 LIST 后继续使用既有操作。P10 开启时沿用焦点陷阱，P01 背景中的月历、页签和内容均不可操作；关闭后恢复到原触发控件，目标失效时恢复到当前栏目可用位置。

同日切栏保留栏目滚动、任务结果选择与安排输入；编辑尚未提交时 P10 不允许通过背景切栏改变上下文，字段错误和保存失败由原状态 owner 保存。关闭或取消编辑仍沿用现有草稿丢弃行为，不新增确认弹窗。

换日期保持当前页签，任务重新读取并回到 LIST，各列表滚动回顶部，未发送的安排输入保留。关闭后重开采用 App 现有初始日期与默认页签并重新读取，不建立跨次打开缓存。已登录提供完整三个栏目并默认定时任务；未登录沿用现状隐藏任务项，仅日记/Notion且默认日记。登出使当前任务项消失时回日记，键盘只遍历可见项。

## 7. Notion 正常清单与资源行

```text
P03 [钟] [文] (([N] Notion))
┌ P04 ──────────────────────────────────────────────────┐
│ P07 今天的 Notion 文档                  刷新           │
│ 已发现 3 篇 · 上次读取 14:35                            │
│ P09 部分文档可能尚未显示，可刷新或在 Notion 查看。       │
│ P08 今天创建 · 已发现 2 篇                              │
│ [文] 会议记录  [创建] [编辑]              在 Notion 打开 │
│      创建 09:10 · 最近编辑 11:20                         │
│ [文] 未命名文档 [创建]                    在 Notion 打开 │
│      创建 08:40                                         │
│ P08 今天编辑 · 已发现 1 篇                              │
│ [文] 方案草稿  [编辑]                     在 Notion 打开 │
│      最近编辑 13:50                                     │
└────────────────────────────────────────────────────────┘
```

创建组先于编辑组，每组按对应上游时间降序。双命中文档只进入创建组、显示两个标识并只计一篇；总数为两个互斥组的已知唯一记录数。资源身份使用连接器 ID 与 page ID，标题与 URL 不用于去重。

行图标优先使用安全 emoji，否则使用项目资源图标；空标题显示“未命名文档”。显示用户现有时区下的对应时间，不将最新编辑时间解释为完整活动历史。图中数量只说明归组关系，不表示授权范围全集。

点击标题或打开入口按建议直接打开今日 DTO 经 HTTPS/服务器允许主机校验的 Notion URL；当前校验待补，仅复用现有新标签外链方式，不额外读取正文或请求 metadata 验证。URL 缺失时入口禁用并提供刷新操作。外站登录、权限或删除反馈由 Notion 页面提供；Dream 只能根据已收到的 401、403、404 或 URL 缺失反馈，不能从外链跳转实时识别删除，Search 刷新遗漏也不能直接判删除。

## 8. 日期限制、局部失败与恢复布局

```text
P04 / P07–P09 未连接或非今天       P04 / P07–P09 部分或刷新失败
┌────────────────────────────┐    ┌────────────────────────────────┐
│ 今天的 Notion 文档         │    │ 今天的 Notion 文档       刷新   │
│ P09 连接 Notion 后可查看。  │    │ P09 部分文档尚未读取。          │
│ 前往设置连接 Notion        │    │ 当前已发现 2 篇。  重新刷新     │
│ 或：仅展示今天的文档。     │    │ P08 仅展示已收到的有效资源行    │
│ 回到今天                   │    │ 或：刷新失败，保留上次读取列表。│
└────────────────────────────┘    └────────────────────────────────┘
```

未连接时保留 Notion 页签与 Settings 入口；未连接与非今天是两个独立状态，草图不表示同时展示。非今天只显示日期说明与“回到今天”，不请求上游、不展示今日列表；该按钮同步左侧所选日再加载。

首次加载显示骨架和读取提示，数量未知时不写 0。一次服务端请求仍在分页时，前端保持加载，不设计分页实时流式返回；返回部分结果才显示“已发现 N 篇”与局部恢复。刷新保留同上下文旧列表和滚动，成功原子替换，失败保留旧列表及上次读取时间。

授权失效、归属拒绝或登出清除旧列表，并提供对应登录或 Settings 入口；权限、网络、限流、上游不可用分别沿用 PRD 文案与恢复规则。空搜索候选和今日无命中各用独立提示，不能都显示“暂无数据”。连接返回先重读连接状态，只有今天且 Notion 可见时刷新一次。旧日期、旧连接或旧请求序号的响应不得覆盖当前内容。

## 9. 页签焦点与模块索引

P03 使用 tablist、tab 与对应 tabpanel 的关联语义，选中项设置 aria-selected。悬停提高表面层级，焦点使用可见轮廓，未选中名称提示同时支持鼠标和键盘焦点。方向键及 Home/End 移动焦点，Enter/Space 激活；点击或激活后焦点保留在页签，随后按 Tab 进入当前面板。

| 编号 | 草图模块 | 结构责任 |
| --- | --- | --- |
| P01 | 现有日历 Modal | 保留遮罩、关闭、滚动锁与焦点恢复。 |
| P02 | 左月历纸面 | 保留日期导航、日期格与日记标记。 |
| P03 | 三个图标页签 | 维护唯一选中栏目及独立焦点状态。 |
| P04 | 当前栏目纸面 | 只显示当前业务内容，提供栏目滚动容器。 |
| P05 | 定时任务 LIST/RESULT | 保留原任务动作、结果和安排输入。 |
| P06 | 所选日日记 | 保留打开、当前日记标识与既有删除。 |
| P07 | Notion 面板头 | 显示今天标题、已知数量、上次读取与刷新。 |
| P08 | Notion 两组清单 | 按上游时间分组、去重并提供外链打开。 |
| P09 | Notion 局部状态 | 提供连接、日期、加载、失败与恢复反馈。 |
| P10 | 原编辑或历史 Modal | 维持表单、历史分页和背景不可操作规则。 |

## 10. 下游必须保留的阻塞

Search 全页扫描结束仍不能证明完整枚举授权范围；当前创建时间投影、部分结果和明确 API 版本合同也待补齐。本结构支持“Search 可发现的今日页面”候选方案，不能替代用户尚未接受的严格全部目标。Stage 3 与正式交互稿必须保留该阻塞及只读权限边界，不加入新全文、历史或同步系统。

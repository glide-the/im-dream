# plugin-admin — Folder Contract

## Architecture Summary

Settings 中展示 Deck 工作流用途、内置 Dream Story Workflow 的创作范围和已安装工作流。清单、详情和动作只以 Deck 工作流身份为对象；执行依赖不投影为独立插件分类。Claude Code Plugins 使用相邻的独立组件与 API。

## File Table

| File | Pos | Function |
| --- | --- | --- |
| `PluginAdminPage.tsx` | 工作流目录入口 | 展示工作流定义、短剧创作范围、目录和详情，连接现有授权安装及维护动作。 |
| `PluginAdminList.tsx` | 工作流清单 | 展示读取、空清单、错误恢复和工作流卡片。 |
| `PluginAdminListItem.tsx` | 工作流卡片 | 展示名称、版本、来源、状态和授权操作。 |
| `PluginAdminDetail.tsx` | 工作流详情 | 展示工作流信息、状态、权限、记录及恢复入口。 |
| `PluginStatusBadge.tsx` | 状态反馈 | 展示安装登记、文件准备和加载结果。 |
| `PluginErrorCard.tsx` | 失败反馈 | 展示具体错误原因和对应恢复操作。 |
| `PluginCapabilityDiff.tsx` | 权限变化 | 展示已有升级的权限差异与授权决定入口。 |
| `PluginOperationProgress.tsx` | 操作进度 | 展示已有工作流维护操作结果。 |
| `index.ts` | 模块导出 | 导出工作流页面和辅助组件。 |

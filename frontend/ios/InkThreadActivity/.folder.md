# Thread系统组件

| 文件 | 职责 |
| --- | --- |
| `ThreadActivityAttributes.swift` | 主应用与扩展共享的hasActiveThread布尔协议 |
| `ThreadActivityWidget.swift` | 原启动图、品牌和二值展示，点击沿系统默认返回应用 |
| `Info.plist` | Widget扩展入口及与主应用一致的版本构建配置 |

原Assets.xcassets由Xcode目标资源共享。扩展独立于Python、Node与RN执行，不保存账户标识、正文或凭证。App可执行时更新；系统挂起后展示最后确认值，原后台执行资格保持。

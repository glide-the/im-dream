# iOS发布文档使用方重整记录

## 需求范围

用户要求对外文件以ink-dream为主体，减少功能叙述，服务文档使用方，并保持单一主题的阅读顺序。本次只调整文档及政策网页文字，应用实现、账号、签名、网站部署和商店操作退出执行范围。

## 判断与方案

发现：现行发布文件混合操作、现场账号、源码证据、历史构建、功能介绍和文档验证。定义：上架及安装手册服务执行人员，专项材料服务填报人员，政策服务应用使用者。方案比较选择保留原路径和必要操作，移动核查与回执，保留旧章节锚点；交付采用现有Markdown和HTML文件，文件系统及应用界面结构保持。

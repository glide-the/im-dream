# 笔记组件

| 文件 | 职责 |
| --- | --- |
| `notionArticleLines.ts` | 按正文换行符与链接源区间计算每一行。 |
| `notionArticleLinks.ts`、`notionArticleLinks.test.ts` | 保留 URL 原文、正文区间及页面标识，检查句中链接和相似域名。 |
| `NoteNotionTextCell.tsx`、`NoteNotionTextCell.css` | 在原文位置呈现引用，点击文字编辑原处，点击引用空白直接在下一行书写。 |
| `NoteNotionArticleReader.tsx` | 按当前身份读取单页，显示正文、原文与失败恢复操作。 |
| `noteShare.ts` | 有序TextCell投影、公开DTO及正文SHA-256。 |
| `NoteContent.tsx` | 公开页面与PNG共用的文字呈现，保留换行。 |
| `exportNoteImage.tsx` | 离屏正文渲染、复用原分片捕获并释放临时DOM。 |
| `NoteShareDialog.tsx` | 冻结正文、保存/发布、复制恢复、图片预览和平台交付的操作状态。 |

## 统一分享改造

NoteShareDialog以ShareLinkOption接入统一发布与逐次状态检查；图片沿原捕获，NoteContent保留文字呈现。

# backend/builtin_skills/notion/notion-session — Folder Contract

## Architecture Summary

Built-in read-only Notion Skill and the Settings Skill-detail source. It uses only `Read` to navigate the current thread's lightweight `.notion/` index and request an indexed page through the controlled on-demand page hook; Settings parses this package's title, description, body, revision, and `references/*.md` without exposing server paths. It never runs Notion MCP/CLI/Bash or reads credentials, token files, environment variables, or connector implementation paths.

When the current actor/thread has an effective Notion Runtime projection, the
workspace publishes this directory through an exact read-only source link.

## File Table

| File | Pos | Function |
|---|---|---|
| `SKILL.md` | skill manifest | Trigger rules, index-first `Read` workflow, on-demand page access, safe errors, and read-only boundaries. |
| `references/notion-search.md` | search reference | Locates pages by title, ID, or URL in the mounted lightweight index; not full-text search. |
| `references/notion-page-read.md` | page reference | Reads one indexed page through the Runtime hook and explains Markdown, metadata, and snapshot identity. |
| `references/notion-db-query.md` | database reference | Browses mounted database page IDs before requesting individual page Markdown. |

# frontend/public/

## 职责

本目录由 Next 提供静态资源。隐私、订阅与人工智能使用说明分别使用独立HTML，正文来源统一归`docs/user/`。实际公开域名、线上部署和App内链接由内部发布记录核对。

## 文件清单

| 文件 | 定位 | 职责 |
| --- | --- | --- |
| `privacy-policy.html` | 对外隐私政策草案 | 与[隐私政策正文](../../docs/user/privacy-policy.md)一致，说明个人信息处理和使用者权利。 |
| `subscription-and-usage.html` | 对外订阅与用量说明草案 | 与[费用和用量正文](../../docs/user/subscription-and-usage.md)一致，说明价格、周期、额度和取消。 |
| `ai-usage.html` | 对外人工智能使用说明草案 | 与[人工智能使用正文](../../docs/user/ai-usage.md)一致，说明提交内容、结果使用和问题反馈。 |
| `runtime-config.template.js`、`runtime-config.js` | 现有公开运行配置 | 提供浏览器可见的服务配置；生成方式归前端目录合同。 |
| 字体、图片及 `assets/` | 现有页面资源 | 为原页面、字体和产品说明提供静态字节；本次内容保持。 |

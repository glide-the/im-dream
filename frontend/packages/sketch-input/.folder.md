# @ink-dream/sketch-input

## Architecture Summary
One complete charcoal canvas component package, internally separated by responsibility.
Host owns Modal, labels, draft lifetime, upload policy and authenticated PNG consumption.
No reverse application imports, network services, model calls or global store.

## File Table

| File | Pos | Function |
| --- | --- | --- |
| `package.json` | pnpm package | Private workspace source/style exports, React peer and typecheck. |
| `tsconfig.json` | Package type boundary | Strict DOM/React TypeScript without the application's source aliases. |
| `src/` | Component modules | Drawing/history/image-input/editor modules; public entry and scoped CSS. |

## Integration

`SketchEditor` receives `SketchDocument`, `onDocumentChange`, `labels`, `maxFileBytes`, `onAdd(File): Promise<boolean>`, `onClose` and `onSavingChange`. Import `@ink-dream/sketch-input/styles.css` once in the host adapter. Keep the controlled document outside an unmounting Modal to retain a draft on return. Release a saving guard before the success close; upload and messages remain host-owned.

Reference: CharcoalNarrative `CanvasManager.ts` charcoal sampling/transparent eraser and `CharcoalScene.tsx` layer composition. Source is readonly and not a runtime dependency. Original paper frame, glass toolbar/toolbox, left fragment history and gestures are preserved. Seeded replay fixes source redraw randomness; fixed Chat output retains the existing PNG contract. Source story/era/store/AI placeholders are intentionally excluded.

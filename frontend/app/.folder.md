# frontend/app — Folder Contract

## Architecture Summary

The root `app/` directory is Dream's only Next.js App Router and application-source owner. Public routes are created only by the listed `page.tsx` and `route.ts` files; `_dream/` is a private, non-route module tree loaded through the explicit client or server boundary that owns each dependency.

## File Table

| File | Pos | Function |
|---|---|---|
| `layout.tsx` | Server Component root | Own metadata, runtime-config bootstrap, structured data, and the global `_dream/index.css` import without browser globals. |
| `client-shell.tsx` | Client boundary | Initialize browser-only i18n/theme/auth and dynamically mount the canonical `_dream/App.tsx`. |
| `[[...path]]/page.tsx` | Catch-all page | Mount the client shell for Dream's browser-managed product routes. |
| `_dream/` | Private application modules | Own React components, browser API clients, hooks, state, styles, tests, and view/router modules; never creates an App Router URL. |
| `_public-resource-proxy.ts` | Server helper | Proxy Python-owned public crawler resources under strict response rules. |
| `api/health/route.ts` | Public Route Handler | Expose the frontend health contract. |
| `api/mcp-apps/[serverRef]/route.ts` | Authenticated Route Handler | Adapt same-origin MCP Apps traffic to the server-only Runtime package. |
| `api/mcp-apps/phase1-status/route.ts` | Authenticated policy Route Handler | Project the fail-closed Browser Host policy without upstream connection material. |
| `mcp-apps-sandbox/route.ts` | Sandbox Route Handler | Serve the independently originated, zero-permission MCP Apps proxy. |
| `robots.txt/route.ts`, `sitemap.xml/route.ts`, `llms.txt/route.ts` | Public resource routes | Preserve Python-owned crawler-resource behavior through the Next shell. |

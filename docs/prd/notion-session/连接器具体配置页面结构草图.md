## 页面信息

### 1. 顶部导航

图片里最上方是轻量导航，不是重型侧边栏。

结构应为：

```txt
返回按钮 / 面包屑 / 当前连接器名称
```

用于告诉用户：
当前不是一个独立设置页，而是从“资源连接器”进入的某个连接器详情页。

---

### 2. 连接器头部区域

图片顶部中间有头像、标题、状态标签，右侧有两个操作按钮。

对应到你的业务：

```txt
连接器图标
连接器名称
连接器描述
连接状态
查看链接器设计稿
关闭连接
```

状态建议分成：

```txt
未认证
认证中
已连接
同步中
同步失败
已关闭
```

---

### 3. 主配置卡片

图片中间最大的卡片是多行配置表单，每一行左侧是说明，右侧是下拉选择。

适合承载：

```txt
连接器概览
资源选择
同步范围
权限范围
默认使用方式
```

不过你说“策略暂时不实现”，所以不要把策略做成完整表单。
否则页面会显得功能很多，但实际不可用。

---

### 4. 资源选择区域

图片中部有一个“+”按钮和一个虚线占位区域。

这部分适合变成：

```txt
资源选择 / 来源列表
```

未认证时：

```txt
禁用状态
展示空态说明
提示先完成 Notion 认证
```

认证后：

```txt
展示数据库列表
点击数据库
展开或切换显示对应页面
用户选择页面作为资源来源
```

交互草图：

```txt
数据库列表
  ├─ 数据库 A
  │   ├─ 页面 1
  │   ├─ 页面 2
  │   └─ 页面 3
  │
  ├─ 数据库 B
  │   ├─ 页面 1
  │   └─ 页面 2
```

---

### 5. 底部状态提示卡片

图片底部是一个带警告图标和开关的提示卡。

建议用来展示当前连接器的关键风险：

```txt
未完成认证
资源选择不可用
同步未开启
本地资源未连接
远程权限不足
```

不要只做普通提示文案。
这个区域应该承担“当前页面为什么不能操作”的解释。

## 关键交互规则

### 未认证状态

```txt
连接器概览：可查看
策略设计：显示占位，不可配置
资源选择：禁用
数据库列表：不展示
页面列表：不展示
底部提示：提示完成 Notion 认证
```

### 已认证状态

```txt
连接器概览：展示连接状态
资源选择：展示数据库
点击数据库：显示对应页面
点击页面：加入当前 connector 的可用资源
底部提示：展示同步状态或最近更新时间
```

### 关闭连接

```txt
点击关闭连接
弹出二次确认
确认后：
  - 状态变为已关闭
  - 资源选择禁用
  - 已选资源保留但不可用
  - 对话页不再调用该 connector
```

# Ink & Memory — 项目根目录

## 架构概述
Monorepo：`frontend/`（React/Vite SPA）+ `backend/`（FastAPI/Python）前后端分离，通过 nginx 反向代理整合。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| AGENTS.md | root/Agent 契约 | Agent 工作契约与治理规范 |
| Agent.md | root/维护规则 | README 中英文同源、SDK/Runtime 原子版本配对、依赖同步、PATH、Schema、Secret 和验证强制规则；产品内 Agent 交互另见 `docs/Agent.md` |
| README.md | root/英文使用入口 | 英文真相源：说明项目定位、拓扑边界、精确版本、Admin/Python/npm Runtime/Frontend 安装运行、验证、注意事项和故障排查 |
| README.zh.md | root/中文使用入口 | 与 `README.md` 保持同结构、同事实和同命令的中文镜像 |
| .vscode/settings.json | root/IDE 配置 | 固定 VS Code Python 默认解释器为 `backend/.venv/bin/python`，并在新终端中自动激活该后端环境 |
| docker-compose.yml | root/编排 | 本地 Docker 编排（Mihomo `tun-proxy` + 前端 nginx + 后端 uvicorn）；backend 共享 `tun-proxy` 网络命名空间，具备 Claude sandbox 权限，并把 Notion user credential root 与 `AGENT_CWD` 一起固定到持久 agentdata volume。 |
| deploy/ | 部署脚本集 | 平台化发布脚本入口：local、docker、remote-ssh、google-cloud；阿里云使用 remote-ssh，Dream 只发布 frontend/backend，Admin 数据平台归相邻仓库 |
| .storage-env | root/配置（gitignored） | setup-storage.sh 生成的桶名和 SA 邮箱 |
| .cloud-env | root/配置（gitignored） | setup-env.sh 生成的 Cloud Run 环境变量和 Secret 引用 |
| frontend/ | 前端服务 | React 18 + Vite SPA，nginx 容器化服务 |
| backend/ | 后端服务 | FastAPI + uvicorn，Python 容器化服务 |
| docs/ | 文档 | 架构/设计/规范文档 |
| assets/ | 静态资源 | 项目静态资源 |
| scripts/ | 仓库验证与运维脚本 | `run-dream-business-e2e.mjs` 使用自有临时 PostgreSQL/端口/本地 Provider 验证 Admin + Dream + 浏览器业务链；`INK_REGISTRATION_DEFAULTS_ONLY=1` 选择当前注册→Free→默认模型→首次调用车道，其中默认模型仅预置 Provider/Pricing、不预置 Entitlement，以覆盖真实自举失败；`verify_claude_registry_release.py` 在 SDK/Runtime 真正上架后以临时 venv/npm project 验证 PyPI/npm 精确制品、五包、零 source map、两个 CLI alias 与 SDK/API 合同，不调用模型 |

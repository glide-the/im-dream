# sketch-input/src

## Architecture Summary
History owns the controlled draft; drawing owns seeded rendering/composition/PNG.
Image input decodes File and releases object URLs; React owns local editor controls.
All authorization, uploading, i18n and Modal behavior stay outside this package.

## File Table

| File | Pos | Function |
| --- | --- | --- |

| `drawing.ts` | Drawing core | Reference charcoal geometry, deterministic seed, dual erase targets, layer composition, snapshot preview/baseline and white PNG. |
| `imageInput.ts` | Local decode | Type/host size/decode checks, AbortSignal, object URL release. |

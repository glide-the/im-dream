# backend/libs/claude_agent_kit/server — Folder Contract

## Architecture Summary

SDK/Runtime server adapters for Agent execution, workspace safety, internal MCP
namespaces, lazy connector reads, and snapshot/file projections. Application orchestration remains in
`backend/claude_agent`; this folder does not own connector persistence.

## File Table

| File / group | Pos | Function |
|---|---|---|
| `agent_runner.py` | Runtime composition node | Builds validated SDK options, tool permissions, sandbox/MCP configuration, and stream callbacks; Editor virtual Reads create private one-shot redirects inside the canonical thread `.claude-tmp` without changing turn/resume/cancel semantics. |
| `workspace.py` | thread workspace boundary | Creates validated thread roots, installs backend-owned Skills, configures sandbox denies, and maintains exact Runtime temporary paths. |
| `notion_read_hook.py` | Notion lazy-read boundary | Intercepts exact `.notion/pages/<page_id>.json` Reads, validates the page against the projected index and thread credential home, fetches only that page's current Markdown, and redirects to a private one-shot file. |
| `notion_snapshot.py` | Notion snapshot contract | Defines canonical identity/lifecycle structures and safe `.notion/` path resolution. |
| `sdk_env.py` | Runtime environment policy | Resolves the manifest-qualified Runtime and projects only server-owned environment capabilities. |
| `workspace_file_sync.py` | Skill/file sync helper | Reconciles server-owned and workspace Skill sources into Claude discovery links. |
| `editor_*.py` | Editor MCP nodes | Exposes virtual editor reads and controlled document mutation tools. |
| `story_workspace_*.py` | Story Workspace MCP nodes | Exposes story-workspace tools over the existing application boundary. |
| `memory_*.py` | optional memory nodes | Provides the explicitly enabled memory workspace/MCP compatibility path. |
| `necklace_*.py`, `touch_animation_tool.py` | disabled compatibility nodes | Retains imported legacy shapes without adding them to the default Ink tool surface. |
| `mcp_server.py`, `sessions_tool.py`, `user_mcp_stdio.py` | user MCP nodes | Provides core authenticated session retrieval tools. |
| `session_files.py`, `simple_cas_client.py`, `plugin_*.py` | Runtime support nodes | Handles transcript lookup, SDK client composition, and plugin launch/digest support. |
| `__init__.py` | package node | Exposes the supported server adapter surface. |

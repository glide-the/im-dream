# frontend/src/components/claude-mcp — Folder Contract

## Architecture Summary

Owns the Settings Resources presentation for the `claude-mcp` business domain. Components consume only the typed managed-DB Claude MCP API, persist one non-secret operation ID for a same-origin automatic OAuth callback, recover live operations from backend IDs, and render standard-MCP tools/resources/prompts inventory without executing them. Server list loading is independent from remote discovery; entering a detail page automatically performs cache-first discovery with no user-facing inventory control. Components never persist authorization URLs, callback URLs, codes, states, credentials, parse `/mcp` TUI output, or emulate CLI/OAuth state locally.

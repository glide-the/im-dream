# backend/notion — Folder Contract

## Architecture Summary
Notion resource connector backend package.
Dream owns the user-scoped connection lifecycle, PostgreSQL connector metadata,
server-owned agentdata credential/snapshot homes, scheduled synchronization,
and per-thread Runtime projections.
The pinned `ntn` CLI remains the authentication/API driver; it never chooses a
process-user home and is not exposed directly to the Agent.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | public-api node | Re-export Notion connector facade, auth helpers, persistence helpers, and canonical snapshot materializers for router/service callers. |
| `auth.py` | auth driver node | Runs `ntn login --no-browser`, hidden `ntn login poll`, and supported `ntn doctor` with an explicit provider-owned home and minimal environment. |
| `credentials.py` | actor agentdata provider node | Derives opaque actor roots under server agentdata, stages auth sessions, atomically promotes credentials, projects them per thread, and revokes both credential/index projections on disconnect. |
| `errors.py` | error node | Shared safe connector/auth/credential/permission exception hierarchy. |
| `factory.py` | facade node | User-scoped orchestration for auth, failed-reauth LKG, discovery, empty-scope clearing, immediate/explicit sync, policy transitions, actor snapshot publication, projection, and revocation. |
| `operations.py` | operations node | Fully paginated compact discovery/data-source query helpers plus the Runtime-only single-page Markdown call, all using an explicit server home; raw CLI output is classified and redacted. |
| `store.py` | PostgreSQL repository node | Persists connector metadata, selected resources, resource pages, snapshots, and thread attachments in the existing Admin-owned schema capability; stores no credential bytes or paths. |
| `sync.py` | sync node | Builds lightweight selected-resource indexes, minimizes connector metadata, intersects LKG with current selection, and materializes read-only thread index files plus a `notion-session` Skill index without page bodies. |
| `snapshot_store.py` | actor snapshot provider node | Atomically publishes index-only actor current state and projects only its current-scope public subset into a validated thread without remote I/O. |
| `sync_policy.py` | sync-policy node | Validates default/desired/effective/revision/status, allowed intervals, due decisions, and safe transitions in existing connector config JSON. |
| `sync_scheduler.py` | scheduled-sync worker node | Periodically refreshes due authenticated connectors outside Chat; isolates per-connector failures without a queue or new schema. |

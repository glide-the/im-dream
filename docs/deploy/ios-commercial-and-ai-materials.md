# ink-dream iOS 商业与AI材料填写指南（内部）

## 背景与问题

提交应用前，需要明确收费方式、适用地区、外部服务接收方及内容处理方式，并让审核说明与提交版本保持一致。

## 目标与边界

本指南用于准备App Store填写内容及审核附件。运营主体为 **suoxya**，联系邮箱为 **dmeck@suoxya.com**。整体步骤见[上架手册](ios-app-store-release.md)，政策及数据类型填报见[隐私与权限指南](ios-privacy-and-permissions.md)。

本指南属于内部填报资料。面向普通使用者的[订阅与用量说明](../user/subscription-and-usage.md)和[人工智能使用说明](../user/ai-usage.md)各自维护单一主题，正文同步和正式公布条件见[对外文件维护与上架采用](ios-user-documents.md)。

## 概念与规则

收费以已确定的发行方案和实际可用入口为准；套餐价格、周期和额度采用发布配置。外部服务按实际接收用户数据的主体登记。材料保留事实未核定状态，最终提交前补齐对应内容。

## 一、确定收费方式和地区

| 发行方式 | 采用条件 | 需准备材料 |
| --- | --- | --- |
| 免费提供服务 | 明确免费范围、持续提供方式、额度及限制 | 普通账户使用结果、商店描述及实际入口 |
| App内销售数字服务 | 完成适用App内购买接入及交易、权益验证 | 商品、价格、周期、购买、恢复、订阅管理及取消/退款说明 |
| 访问既有付费权益或站外购买 | 按地区及实际入口核定Apple适用条件 | 跨平台权益、外部购买入口、地区规则及适用资格依据 |

首发收费方式需要发布负责人确认。现有套餐与额度展示范围单独核对；付费渠道和完整购买流程在采用前完成真实验证。[Apple支付规则](https://developer.apple.com/app-store/review/guidelines/#payments)，查阅：2026-11-02。

### 采用App内购买时

提交前核对以下项目：

- 商店商品对应正确账户、套餐及权益，价格、币种、周期和地区展示一致。
- 购买确认后授予权益，恢复购买、账号变化、重复通知及失败具有对应结果。
- 升级降级、账单重试、取消、退款和相关通知按所售商品规则处理。
- 月度服务额度和单独购买的积分分别定义，核对积分有效期及恢复要求。
- 自动续订信息包含服务内容、周期、价格、取消方式及实际管理入口。

[购买与恢复规则](https://developer.apple.com/app-store/review/guidelines/#in-app-purchase)、[订阅配置](https://developer.apple.com/help/app-store-connect/manage-subscriptions/offer-auto-renewable-subscriptions/)，查阅：2026-11-02。

## 二、准备外部服务与共享说明

按首发实际配置填写下表，覆盖可能接收用户内容的全部服务方。模型名称及SDK名称用于识别产品与组件，接收主体按实际服务记录确定。

| 材料字段 | 填写内容 |
| --- | --- |
| 服务主体和用途 | 实际提供账户、内容存储、模型处理或其他数据处理的主体名称及职责 |
| 共享数据 | 当前输入、所需历史、附件、工具结果及已授权资源的实际范围 |
| 处理规则 | 保存期限、训练使用、删除方式、处理地区和适用协议 |
| 政策和日期 | 各接收方政策URL、协议版本及核对日期 |
| 用户入口 | 共享前告知、明确同意、拒绝及撤回的实际位置和结果 |

新增接收方或扩大共享范围前，完成相应告知和同意处理。政策正文与商店问卷采用同一份已确认资料。

### 共享前告知模板

填写全部占位内容后，按提交版本的真实入口采用：

> 本次操作需要将〈数据范围〉经suoxya服务发送至〈接收主体及用途〉。保存、训练使用、处理地区及删除规则见〈说明与政策URL〉。你可以选择同意或暂不使用，并在〈入口〉撤回后续共享的同意；已发送内容按接收方规则处理。

登录、阅读政策、工具批准和AI数据共享同意分别核对其授权对象。共享前的明确许可按[Apple数据共享要求](https://developer.apple.com/app-store/review/guidelines/#data-use-and-sharing)落实，查阅：2026-11-02。

## 三、准备内容处理和联系材料

| 材料 | 完成条件 |
| --- | --- |
| 内容范围与限制 | 明确可生成、上传、展示、导出及分享的范围，列出适用限制和反馈 |
| 过滤与安全处理 | 受限内容规则、拒绝结果及处理措施在最终候选可验证 |
| 举报与公开联系 | 举报入口、联系邮箱、处理责任及结果反馈可用 |
| 滥用处置 | 有相应授权人员执行处置并保存必要记录；存在用户交互时提供适用的用户屏蔽能力 |
| 年龄和地区 | 内容控制、分级、地区及商店描述一致 |
| 处理记录 | 仅保存处理所需信息，访问用户内容遵守相应权限及保存规则 |

公开联系邮箱为 **dmeck@suoxya.com**。邮箱、举报、内容过滤和处置分别完成检查。[Apple内容要求](https://developer.apple.com/app-store/review/guidelines/#user-generated-content)、[2026-10-16更新](https://developer.apple.com/news/?id=92th7e5i)，查阅：2026-11-02。

## 四、填写商店字段

| 操作位置 | 输入或准备材料 | 具体操作 | 预期结果 | 失败处理 |
| --- | --- | --- | --- | --- |
| App Store Connect → Pricing and Availability | App价格、服务收费及首发地区 | 按已确定发行方案填写 | 与实际入口及可用地区一致 | 收费或地区尚未确定时先完成决定 |
| Monetization → Subscriptions / In-App Purchases（适用时） | 正式商品、权益、周期、价格和本地化资料 | 配置商品及对应审核资料 | 商品可按所述方式购买和管理 | 先完成所选支付方案及真实验证 |
| App Privacy及政策URL | 接收方和处理规则 | 按隐私指南填写 | 政策、问卷和共享范围一致 | 事实缺项先补齐 |
| App Information → Age Ratings | 内容及控制措施 | 按实际能力回答问卷 | 分级与候选一致 | 控制缺项先处理再提交 |
| App Review Information → Notes | 收费、服务条件、共享和内容处理步骤 | 使用下方模板，附件提供必要操作资料 | 审核可在普通版本复现 | 占位符或不可用步骤先修订 |
| App Review Information → Sign-in information | 审核账号及适用测试条件 | 凭据只填受限字段，确认账号可访问提交范围 | 审核期间持续可用 | 修复登录、授权或服务条件后提交 |

## 五、审核说明模板

> 提交版本为〈版本及构建号〉。发行方式为〈免费范围或收费方式〉，适用地区为〈范围〉。适用付费商品及管理步骤为〈商品、入口与操作〉。
>
> 外部服务及用户数据处理说明见〈接收方清单〉。共享前告知和同意入口为〈位置〉，撤回及账户删除入口为〈位置〉。内容限制、举报、联系和处理反馈位置为〈位置〉。
>
> 请使用Sign-in information中的账户，按〈步骤〉完成审核。所需服务、资源与权限为〈实际条件〉，附件为〈必要资料〉。

最终提交前清零占位符，核对每个入口和操作结果。实现情况、使用限制及必要技术解释按实际候选填写。

## 六、提交前确认

- 收费方式、地区、免费范围和宣传内容已经确定。
- 适用购买、恢复、取消、退款和权益结果完成真实验证。
- 接收方、数据范围、处理规则及政策资料完整。
- 共享同意、拒绝和撤回在最终候选中可用。
- 内容限制、举报、滥用处置及公开联系具有对应结果。
- 审核账号、附件和说明与提交版本一致。

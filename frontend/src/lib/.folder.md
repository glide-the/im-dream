# frontend/src/lib - Folder Contract

## Architecture Summary
Shared frontend utility and transport modules for chat request types, Claude Agent streaming, and file proxy URL construction.
Feature components consume this folder for protocol contracts and API-adjacent helpers rather than duplicating request shapes.

## File Table

| File | Pos | Function |
|---|---|---|
| `chat-schema.ts` | `chat-schema type node` | Define frontend chat transport request body, attachment, model, tool, and metadata types. |
| `claude-agent-transport.ts` | `transport adapter` | Adapt Claude Agent SSE protocol events into AI SDK UI message chunks, including approval-request metadata for backend-driven tool confirmation UI. |
| `toFileProxyUrl.ts` | `file-proxy-url utility node` | Convert stored file keys into frontend-accessible proxy URLs. |

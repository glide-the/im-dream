# docs/design/kastention — Folder Contract

## Architecture Summary

思维模式首页按既有 policy 展示可用与系统 Deck，复用只读预览、Chat/Dream 入口及创建后维护弹窗；设置工作台负责完整管理和相关对话清理。
有效配置变更进入持久草稿，显式提交生成 Deck 内容版本；运行绑定历史为次级记录，工作流不属于当前管理界面。
Deck 工作流与 Claude Code Plugins 的独立交互见[插件设计目录](../kastention-plugin/.folder.md)，产品规则与页面骨架分别见[工作流 PRD](../../prd/kastention/kastention-workflow-plugin.md)和[Claude Code Plugins PRD](../../prd/kastention/claude-code-plugins.md)；旧工作流稿不决定当前插件分类。

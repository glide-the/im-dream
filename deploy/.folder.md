# deploy/

## 架构概述
Cloud Run 部署脚本集，三步初始化（setup-storage → setup-env → deploy），产物写到项目根目录的 gitignored 配置文件。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| setup-storage.sh | 存储初始化（一次性） | 创建 GCS bucket、服务账号 `ink-backend-sa`、IAM 授权；输出根目录 `.storage-env` |
| setup-env.sh | 环境变量初始化（按需） | 读 `backend/.env` → 敏感值存 Secret Manager，配置值汇总；输出根目录 `.cloud-env` |
| deploy.sh | 部署（可重复执行） | 并行构建+推送镜像；顺序部署后端（GCS 卷+Secret refs+env vars）和前端（注入 BACKEND_URL） |

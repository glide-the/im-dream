# backend/builtin_skills — Folder Contract

## Architecture Summary

Server-owned Agent Skills included by the backend-only Docker build and refreshed into every full thread workspace. Built-in names are authoritative; user/runtime-installed Skills with other names remain workspace-owned.

## File Table

| Path | Pos | Function |
|---|---|---|
| `notion-session/` | built-in-skill | Read-only Notion index navigation and virtual page-read guidance plus the Settings title/body/reference source; it uses only `Read` and never exposes CLI, MCP tools, credential paths, or tokens. |
| `notion-cli/` | built-in-skill | Upstream direct `ntn api` guidance imported under a distinct name; it uses Bash and coexists with `notion-session` without changing the server-owned credential boundary. |

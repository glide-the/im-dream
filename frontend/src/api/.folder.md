# frontend/src/api — Folder Contract

## Architecture Summary
Frontend API client helpers for backend REST/SSE calls.
Keeps endpoint construction and protocol details out of feature components.

## File Table

| File | Pos | Function |
|---|---|---|
| `resourceConnectorApi.ts` | `resource-connector api client node` | Provide connector CRUD, auth polling, resource discovery, resource selection, and sync helpers with local fallback storage plus backend-create response normalization. |
| `voiceApi.ts` | voice-api client node | Provide session/deck/voice API helpers, Claude Agent SSE helpers, Reflections section analysis (memory-init + claude-agent + messages API), and report storage. |

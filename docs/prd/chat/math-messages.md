# 对话中的数学公式

## 背景与问题

[原始需求](https://app.notion.com/p/40b30b7547c380cd9930c384ab35023c?v=40b30b7547c380f18b8c000c207f918f&source=copy_link#40e30b7547c380409a25c7283e33bc95)的相关原文为“支持数学公式显示”。2026-11-08通过Notion工具读取，返回页面标题“近期需求”，页面编辑时间为2026-11-07。该标题下为空段落，语法、操作及失败行为由参考证据和现有消息阅读约束确定。

用户需要在提问、回复及历史对话中直接阅读数学表达式。现有消息支持段落、代码、表格和Mermaid，公式缺少识别及排版。

## 目标与边界

在现有消息正文中显示行内和独立公式，覆盖网页桌面、网页窄屏与原生消息入口。消息原文、发送、停止、历史读取、复制和滚动继续由现有模块负责。公式编辑器、计算、独立预览、文件编译和公式工具栏退出本轮范围。图片分享继续采用其现有导出链，本轮验收覆盖消息阅读和文本复制。

## 概念与规则

| 内容 | 阅读规则 |
| --- | --- |
| 行内公式 | `\(x^2 + y^2\)`与同段文字共同排版；行内公式限同一行源码。 |
| 独立公式 | `\[x^2 + y^2\]`及`$$x^2 + y^2$$`在正文中独立成行，可包含连续换行。 |
| 普通金额 | 单个`$`保持文字，例如`$5`和`$10`；`$x$`保持文字。 |
| 转义与代码 | 转义后的定界符、行内代码及围栏代码保留文字。代码中的公式示例继续用于阅读源码。 |
| 生成中的内容 | 已闭合公式开始排版；未闭合部分保留源码。后续内容补齐后自动更新。 |
| 停止、失败与历史 | 显示最后取得的正文；未完成公式继续保留源码。重新进入时按保存的原文排版。 |
| 无法排版 | 当前公式保留含定界符的原文，其他内容继续显示。资源读取失败后，重新进入消息可再次加载。 |
| 复制整条消息 | 现有复制入口保留完整消息原文，包含原定界符。 |
| 选择内容 | 保留系统选择方式；网页选择范围触及公式时复制完整公式源码。原生含公式的文字区域保留系统选择与源码复制。 |
| 长公式 | 保持数学布局，在公式所在区域横向滚动；页面保持原宽度，纵向阅读由消息列表负责。 |
| 外观与操作 | 颜色和字号跟随正文；沿用浅色、深色及系统外观。公式直接可读，无新增点击、悬停、确认或弹窗。 |

原生含公式的段落通过局部文档显示，表格、列表及链接保留各自入口；消息整体复制仍在原生消息操作区。独立公式的空白段落分隔遵循Markdown段落边界；跨空白段落的未闭合写法保留可阅读原文。

## 桌面页面骨架

```text
应用导航 | 对话工具栏：原历史 / 文件 / 分享入口
         | 消息区域 ↕（原消息列表拥有纵向滚动）
         |   用户气泡：普通文本 + 行内公式
         |   原复制入口
         |   助手回复：普通文本 + 行内公式
         |     独立公式区域 ↔（仅超宽内容横向滚动）
         |   原回复操作与复制入口
         | 输入区：原发送 / 停止
```

## 窄屏页面骨架

```text
原对话工具栏与历史入口
消息阅读区 ↕
  用户消息：文字 / 公式 / 原复制
  助手消息：文字 + 行内公式
    超宽独立公式 ↔
  原回复操作
原输入区：发送 / 停止
原底部栏目：Chat / 卡片结构 / 更多
```

切换栏目、长用户消息展开及返回最新位置沿[消息阅读规则](message-reading.md)。本项无新增弹窗关系。

## 验收条件

1. 用户及助手消息显示三种定界符；同段多个公式和普通文字保持顺序。
2. 金额、转义字符、行内代码和围栏代码保持文字；表格、链接和Mermaid继续可用。
3. 未闭合→闭合、停止、失败及历史重新进入按最终正文显示，复制整条消息始终保留原文。
4. 窄屏和桌面阅读长公式时页面无横向溢出；局部横滚可到达公式末尾。
5. 浅色和深色公式颜色跟随正文；系统外观沿原主题设置切换。
6. 单条错误公式和渲染资源失败保留源码，其余内容及消息操作保持可用。

方案依据、评审、时序、状态和实际验证状态见[正式交互设计](../../design/claude-agent/chat-math-messages.md)。

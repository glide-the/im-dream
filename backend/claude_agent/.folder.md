# backend/claude_agent — Folder Contract

## Architecture Summary
Claude Agent 应用层，迁移自 Pawkeyland `application/claude_agent/`。  
提供流式 AI 写作助手的业务逻辑（会话管理、上下文组装、SSE 事件），  
依赖 `backend/libs/claude_agent_kit/` 提供 SDK 封装和类型。  
与现有 PolyCLI agent 会话完全隔离。

## Migration Source
Pawkeyland `application/claude_agent/`（已移除 pet/persona/mem0/necklace 专属逻辑）。  
Kit 层（types/runner/workspace）已移至 `backend/libs/claude_agent_kit/`。

## Two-Layer Architecture
```
backend/libs/claude_agent_kit/   ← Kit 层：SDK 封装、类型、工作区
backend/claude_agent/            ← 应用层：业务逻辑、会话编排（本目录）
```

## File Table

| File | Pos | Function |
|------|-----|----------|
| `__init__.py` | public-api node | 聚合导出（应用层 + kit 层 re-export）供 `server.py` 使用 |
| `observer.py` | observer node | `SessionLifecycleObserver`, `SessionObserverRegistry`, `LoggingObserver` |
| `tool_confirmation_store.py` | utility node | `ToolConfirmationStore`, `ToolConfirmationResult` — async Future 工具确认 |
| `thread_pool.py` | flyweight-state node | `AgentRunState`, `AgentRunStatePool`, `AgentRunStateSweeper` — TTL 会话池 |
| `context_builder.py` | context-assembly node | `ClaudeAgentContextBuilder` — 写作会话 system_prompt 组装 |
| `service.py` | core-business node | `ClaudeAgentService`, `ClaudeAgentRunRequest` — Phase 1 & 3 业务逻辑 |
| `thread_factory.py` | factory-entry node | `ClaudeAgentThreadFactory`, `build_session_id` — 四阶段生命周期编排 |

## Key Constraints
- 不导入 PolyCLI / polyagent / polycli 模块
- 不定义 `@session_def` — 路由在 `server.py` 注册
- Kit 层导入：`from libs.claude_agent_kit import ...`
- `session_id = user_id`（无 persona 维度；可扩展为 `user_id__tag`）

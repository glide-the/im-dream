# frontend/src/lib - Folder Contract

## Architecture Summary
Shared frontend utility and transport modules for runtime API base config, chat request types, Claude Agent streaming, and file proxy URL construction.
Feature components consume this folder for protocol contracts and API-adjacent helpers rather than duplicating request shapes.

## File Table

| File | Pos | Function |
|---|---|---|
| `apiBase.ts` | `frontend API base-url utility node` | Lazily resolve REST/SSE and WebSocket base URLs from runtime config, Vite env, or same-origin fallback. |
| `chat-schema.ts` | `chat-schema type node` | Define frontend chat transport request body, attachment, model, tool, and metadata types. |
| `claude-agent-sse-utils.ts` | `claude-agent reconnect SSE utility node` | Parse thread SSE reconnect frames and replay backend events into AI SDK 6 UIMessage parts. |
| `claude-agent-transport.ts` | `transport adapter` | Adapt Claude Agent SSE protocol events into AI SDK UI message chunks, including approval-request metadata for backend-driven tool confirmation UI. |
| `system-config-events.ts` | `system-config-events utility node` | Broadcast same-tab Settings changes, currently IM full-access approval mode, to chat components without page refresh. |
| `toFileProxyUrl.ts` | `file-proxy-url utility node` | Convert stored file keys into frontend-accessible proxy URLs. |

# 在笔记中引用 Notion 文章

## 背景与问题

用户写下“会议资料”，粘贴文章地址，再写“下周讨论”。长地址占据笔记版面，之前只能在文本框中选择和复制。需求指定在写作纸面上自动识别外部文章，并用已有阅读器显示可读取的正文。[近期需求](https://app.notion.com/p/40b30b7547c380cd9930c384ab35023c#42130b7547c3800aad38daaa6f003a8a)

## 目标与边界

从写作页完成引用、预览、打开原文、修改、撤销和保存。在当前账户的 Notion 连接允许读取文章时，用户可以留在笔记中阅读。原文入口从识别成功起可用。文章由 Notion 管理。笔记保存用户输入的文字和原始地址。

## 概念与规则

- 一处完整文章地址对应一处引用。标题式链接使用地址中的名称，纯编号地址显示 Notion 和页面编号摘要。阅读时显示连接器提供的标题。
- 粘贴完成即可操作引用。手动输入时，离开网址或结束编辑后显示引用。输入法组合期间保持写作位置。编辑时保留可选中、可撤销的原文，当前单元下方列出引用操作。离开编辑区后，在正文原位置呈现紧凑条目。单独一行的引用保留该行，句中的引用按文字顺序排列。
- 示例原文为“会议资料”＋本文来源地址（含区块锚点）＋“下周讨论”。粘贴后光标在原地址末尾，后续文字接在光标处。打开原文使用含查询参数和锚点的完整地址。预览显示整篇文章，关闭后可从笔记继续写。改动链接后引用随正文更新。移除链接后仅保留周围文字。
- 编辑或重开旧笔记沿用同一规则。普通网址、相似域名和缺少页面编号的地址保持文字。识别与保存均无需等待文章读取。
- 点击引用行右侧空白，文章留在原行，其下出现独立输入行。下一行已有正文时，原正文顺移；已有空行时直接复用。按回车继续另起一行。“另起一行”和正文末尾的空白区域用于在笔记末尾续写。桌面和手机使用纯色纸面。

在写作页打开日历，进入 Notion 栏目，点文章旁的“插入日记”。文章地址追加到当前编辑的日记末尾并独占一行。刚点击的按钮旁立即浮出保存提示，小箭头指向该按钮，保存完成后显示“已插入当前日记”。重复点击提示“当前日记已包含这篇文章”。保存失败提示重试，可以再次点击原按钮。结果提示稍后自动消失。日历所选日期决定文章列表。

示例笔记中实际保存的正文如下。链接可与中文直接相邻。

```text
会议资料https://app.notion.com/p/40b30b7547c380cd9930c384ab35023c?v=40b30b7547c380f18b8c000c207f918f&source=copy_link#42130b7547c3800aad38daaa6f003a8a下周讨论
```

### 桌面骨架

```text
写作导航 │ 写作纸面（纵向滚动）
         │ 会议资料 [N 文章名称 ↗] 下周讨论
         │ ▏点引用行右侧后，在这里直接输入
         │ 日历 → Notion → 文章名称 [插入日记] → 按钮旁浮出提示
         │ 点击文章名称 → 阅读窗口
         │                  文章标题  [打开原文] [关闭]
         │                  文章正文（单独纵向滚动）
```

条目跟随可用宽度换行。链接名称和打开原文各有独立触摸入口。编辑时，引用操作位于文本框下方，留出光标和前后文字所需空间。

## 验收

| 操作 | 用户可见结果 |
| --- | --- |
| 粘贴带区块锚点的链接，继续输入 | 一处引用，光标继续输入“下周讨论”，文字顺序正确 |
| 打开只有引用的笔记，点右侧空白直接打字，重开后点下方纸面再写 | 新内容从独立一行开始，重复点空白沿用当前空行，原地址和锚点完整 |
| 从日历插入、重复点击、保存失败后重试 | 当前编辑的日记仅新增一行文章，所点按钮旁浮出保存结果并自动消失 |
| 修改、删除、撤销地址 | 引用跟随当前文字出现或消失，周围文字保留 |
| 等待保存，重开两次，打开旧格式笔记 | 每次显示相同数量的引用，可继续编辑，原地址逐字保留 |
| 阅读已选文章并返回 | 显示文章标题和格式化正文，返回笔记后可在原位置继续写 |
| 打开未授权、未选或读取失败的文章 | 显示相应反馈，可打开原文，恢复权限或网络后可重试 |
| 在窄屏混合输入普通网址、相似域名和文章地址 | 只有受支持地址生成引用，写作和阅读操作均在可视区域内 |

# mobile/ios/runtime

| File | Responsibility |
| --- | --- |
| `host.cjs` | Bind the private loopback SDK transport, stage the pinned command root and pass App-owned paths to Runtime workers. Align Runtime TMPDIR with the original thread CLAUDE_CODE_TMPDIR. Explicit termination returns the original exit packet after Worker cleanup. |
| `worker.mjs` | Start the exact Runtime or fixed managed plugin Python with original arguments/cwd and the App command binding; preserve managed venv PATH precedence. Host original Next in its separate worker. |
| `ios-process-boundary.mjs` | Connect Runtime ChildProcess/Pipe and sync APIs to the linked App command candidate. Keep Next external commands at ENOSYS and prevent host-process signal forwarding. |

The endpoint file is private, mode 0600, and contains the current application PID. It is consumed by embedded Python, never by WebView. No remote host or command path is accepted. Runtime initialization, tools, cancellation and recovery require separate target execution receipts.

The deployment uses the existing `INK_AGENT_SANDBOX_ENABLED=false` key. Original SandboxManager and tool approval retain their owners. Per-command filesystem, network and proc isolation is outside the selected design. The latest original SDK target test passes Bash/shared files, permission refusal, MCP, resume, running-command interrupt and descriptor cleanup. The original Runner passes separately. Real tool business and physical-device execution remain pending.

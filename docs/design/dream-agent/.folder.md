# docs/design/dream-agent — 目录合同

## 架构摘要

Dream Agent 当前设计集，定义共享 Chat Thread runtime、Dream authority、工作台上下文、成功 Hook 同步、错误契约与验收边界。

## 文件清单

| 文件 | 定位 | 职责 |

# docs/design/claude-agent/edit-point — Folder Contract

## Architecture Summary
Claude Agent 与编辑器会话集成的模块化设计文档集。  
以三层架构为核心：EditorEngine 作为 MCP 资源服务器，EditorState 通过适配器映射到文件系统工作空间，  
UI/Hooks 层作为人类与 Agent 的协作面，涵盖操作确认、可视化与多 Agent 冲突仲裁。

# frontend/src/engine — Folder Contract

## Architecture Summary
EditorEngine owns the in-memory writing document state and editor command methods.
Widget data models live beside the engine so UI hooks/components consume one shared editor state contract.

## File Table

| File | Pos | Function |
|---|---|---|
| `EditorEngine.ts` | `editor-engine node` | Maintain EditorState, text/widget/comment commands, local weight accounting, load-state migration, and remote-load source markers; ordinary edits never call a model. |
| `ChatWidget.ts` | `chat-widget model node` | Define chat widget data shape consumed by editor widgets and chat UI. |
| `__tests__/` | engine behavior tests | Lock production EditorEngine state and network boundaries. |

# backend/tests — Folder Contract

## Architecture Summary
Unit and integration test suite for the Ink & Memory backend.
Claude Agent tests use SDK stubs; no real subprocess or server required.
Runner error coverage asserts both `on_error` behavior and backend traceback logging.
Runner PreToolUse policy tests capture the SDK hook closure from constructed
`ClaudeCodeOptions` to verify workspace-file allow, low-risk query/Skill allow,
camelCase hook payload compatibility, Settings disabled-network denial,
Settings full-access allow, the
AskUserQuestion full-access exception, full-access built-in file/search
workspace-boundary denial, and high-risk auto-mode confirmation decisions
without launching Claude Code.
Service SSE mapping tests cover event-shape regressions before frames reach the
frontend transport.

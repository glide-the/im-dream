# UI规范出版目录

## 职责

本目录维护Kastention应用界面规范的阅读版源文件与图示。正文引用现行产品和色彩合同；交互时序归[正式设计](../../../design/multi-platform/ui-guidelines-interaction.md)，范围与验证归[评审记录](../../../exec/ui-guidelines-review-20261102.md)。

## 文件清单

| 文件 | 定位 | 职责 |
| --- | --- | --- |
| `README.md` | 可编辑规范正文 | 背景、边界、视觉规则、组件、双端骨架、术语和来源；page注释用于出版分页 |
| `export_pdf.py` | 文档导出工具 | 读取正文、绘制矢量图、嵌入字体，输出PDF及排版检查记录；应用运行路径保持 |
| `assets/` | 可编辑SVG | 由导出工具生成的规范示意图；图内文案与几何源定义归export_pdf.py |

默认出版文件为仓库[docs/prd/Kastention-App-UI-Guidelines-v3.1.pdf](../../Kastention-App-UI-Guidelines-v3.1.pdf)，[可编辑源文件包](../../Kastention-UI-v3.1-Editable-Sources.zip)同放于docs/prd。文档维护与代码评审使用本目录源文件。

## 编辑与导出

文字在README.md中编辑，图形在export_pdf.py的figures函数中编辑；导出时SVG与PDF共同更新。SVG可独立在矢量编辑器中打开，重新导出采用Python中的图形源定义。

在仓库根目录执行：

```bash
python3 docs/prd/mobile-app/ui-guidelines/export_pdf.py
```

Python需具备reportlab，正文需中文TrueType字体。`INK_UI_BODY_FONT`可指定字体路径；本机默认查找Arial Unicode。手写样张读取仓库已有Xiaolai字体，色板读取当前tokens.css。该脚本服务于本文件出版，应用依赖与构建入口保持。

# frontend/ios

## Architecture Summary

The pinned Python/Node/guest runtime is qualified for arm64 iPhone and Apple Silicon Simulator. Project `ARCHS=arm64` matches those resources. Standard CocoaPods implicit dependency discovery works for the matching architecture; temporary cross-project dependency generation was removed after qualification.

The host initializes bundled CPython, starts Node24 in the same application process and binds the original Runtime endpoint to the interpreter. `backend/mobile_runtime/ios.py` owns a persistent ASGI event loop with the canonical 24 production router modules and shared public routes. The native bridge returns HTTP response metadata before bounded pull chunks and cancels document-owned transport independently of Agent tasks. Interpreter initialization is serialized; response reads and cancellation execute concurrently. Protected reads/writes retain the production authentication dependency. A build with an empty `DREAM_LAN_HOST` starts the original Next standalone server in a persistent Node worker and loads its configured IPv4/IPv6 loopback origin. Uvicorn/h11 serves the same composed ASGI application to the original Next HTTP proxy. The earlier optional relay remains a development connection with separately recorded Mac execution. Persistent WebKit storage retains normal Web form and Cookie behavior. The complete business capability remains unqualified pending full tool support and complete authenticated business qualification. The resource phase retains the original configuration owners: `backend/.env` becomes `app/.env` for Python, and `frontend/.env.local` is placed beside the original Next server for Node. The original BFF uses the same keys and authentication path. The configured loopback browser origin and exact published callback remain enforced. Missing configuration retains the original failure.

It neither calls a model nor changes a production CLI deadline or background execution mode. Results qualify the native command path separately from original Claude deadline behavior and real-account acceptance.

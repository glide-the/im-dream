# Workspace — Design Documents

> [Sync] 2026-09-15: storage API records Admin OAuth/Thread metadata before unchanged Mode/path/FS; settings migration remains pending.

Design documents for the workspace file management subsystem, ported from
[`claude-agent-next-kit`](https://github.com/glide-the/claude-agent-next-kit/tree/feat/claude-agent-kit).

> [Sync] 2026-06-07: `workspace-filesystem.md` documents the Runner PreToolUse
> policy that explicitly allows built-in file tools under the current workspace
> `files/` directory, low-risk query tools, `Skill`, and `switch_editor` in
> auto mode; high-risk tools use the frontend confirmation side-channel.
> [Sync] 2026-06-13: `workspace-storage-api.md` documents RFC 8187 download
> `Content-Disposition` handling for non-Latin workspace filenames.
> [Sync] 2026-06-13: `workspace-filesystem.md` documents per-thread Claude
> Code Bash sandbox settings written into `{workspace}/.claude/settings.json`.
> [Sync] 2026-06-14: `workspace-filesystem.md` documents automatic Docker
> nested sandbox detection for Claude Code Bash sandbox.
> [Sync] 2026-06-16: `workspace-filesystem.md` documents that sandbox
> `denyWrite` protects `.claude` internals without blocking `.claude/skills/`.
> [Sync] 2026-06-16: `workspace-filesystem.md` and
> `workspace-skills-flow.md` document importing real `.claude/skills/`
> writes into `workspace/skills/` before rebuilding discovery symlinks.
> [Sync] 2026-06-25: `workspace-filesystem.md` records that open sandbox
> network mode omits `sandbox.network` instead of writing `allowedDomains:["*"]`.
> [Sync] 2026-08-17: `workspace-storage-api.md` documents selected-folder ZIP
> downloads through the existing authenticated file download endpoint.
> [Sync] 2026-08-22: `workspace-storage-api.md` documents the no-create,
> Thread-owner-bound `files/` content endpoint used by Chat `workspace://` references.
> [Sync] 2026-09-01: `builtin-skills-platform-layout.md` defines common/platform
> source namespaces, canonical `.skill` unpacking, connector-bound platform
> activation, and unchanged flat Runtime discovery.

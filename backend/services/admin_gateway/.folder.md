# backend/services/admin_gateway — Folder Contract

- 本目录只通过已认证的 Admin Gateway 公共协议取得模型目录、选择与 Claude Runtime 认证投影；Dream 不直接查询 Admin 模型表，也不拥有 Drizzle migration。
- `models.py` 严格解析 catalog 闭集。`context_window/max_output_tokens` 保持 Gateway 公开能力语义；最终模型的正整数 `max_output_tokens` 同时投影为 `INK_CLAUDE_CODE_MODEL_MAX_OUTPUT_TOKENS`，`claude_code_auto_compact_window/claude_code_max_context_tokens` 是 server-only nullable Runtime 配置且不进入 `public_dict()`。
- `selection.py` 根据 canonical user、保存偏好、callable catalog 和客户端一致性检查返回最终 `GatewayModel`；alias wrapper 仅为兼容投影，不能丢失生产 turn 所需 Runtime metadata。
- `errors.py` 提供 catalog 与 selection 共享的安全错误类型；包级 `__init__.py` 只导出当前 Chat/Dream/Settings 能力。
- `config.py`、`token.py`、`sdk.py`、`models.py`、`selection.py` 是当前 Chat/Dream/Settings 路径；旧 `inference.py` 与环境模型 alias 已随每日图片生成链路删除。
- Runtime 数值只接受 `1..2_147_483_647`；未配置返回空 env 投影。目录不接受浏览器、Deck、Plugin、用户环境或任意 env key。

# backend/

## 架构概述
FastAPI + uvicorn Python 服务，端口 8765，提供 REST/SSE/WebSocket API，SQLite 持久化，可选 PolyCLI 编排。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| Dockerfile | 容器构建 | python:3.9-slim，安装系统依赖与 Python 包，运行 uvicorn |
| .dockerignore | 构建优化 | 排除 data/、__pycache__、.env、测试文件等 |
| docker-compose.yml | 单服务编排（旧） | 仅后端容器编排，已被根目录 docker-compose.yml 替代 |
| server.py | 后端入口 | FastAPI app、路由挂载、调度器启动 |
| config.py | 配置中心 | 从环境变量读取 LLM/API 配置 |
| database.py | 数据层 | SQLite 连接与模型定义 |
| auth.py | 认证 | HTTP Bearer token 验证 |
| routers/ | 路由模块 | 各业务领域的 FastAPI router |
| tools/ | Agent 工具 | MCP 工具实现 |
| claude_agent/ | Agent 运行时 | Claude agent 会话管理 |
| data/ | 运行数据 | SQLite DB 与文件存储（volume 挂载） |
| requirements.txt | 依赖锁定 | 带 hash 校验的 pip 依赖 |

# frontend/app/_dream/components/claude-mcp — Folder Contract

## Architecture Summary

Owns the Settings Resources presentation for the `claude-mcp` business domain. Components consume only the typed managed-DB Claude MCP API, persist one non-secret operation ID for a same-origin automatic OAuth callback, recover live operations from backend IDs, and render standard-MCP tools/resources/prompts inventory without executing them. Each Server detail owns one unified usage-policy form for actor desired App visibility and interaction controls while presenting server-effective availability separately. Server list loading is independent from remote discovery; entering a detail page automatically performs cache-first discovery with no user-facing inventory control. Components never persist authorization URLs, callback URLs, codes, states, credentials, sandbox URLs, service tokens, deployment policy, parse `/mcp` TUI output, or emulate CLI/OAuth state locally.

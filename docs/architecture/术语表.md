## 6. 模块间关系链（权威叙事）

```
Deck 插件（制品，profile 声明 surfaces[]）
  → Dream 页选 Deck 点 Chat → 创建 thread（锁 deck_id）
  → 首个 agent turn：pack_workspace_plugins()
      → 物理映射 .dream/（仅声明 dream surface 时）+ 写 launch-manifest / pack-receipt
  → GET plugin-load-receipt 透出 surfaces → useWorkspaceSurfaces
  → Agent 产出（story-workspace-output SSE 帧）→ 打开 Dream 审阅面板
  → 用户审阅确认（review_status → confirmed，Gate 服务端聚合校验）
  → StoryWorkspaceSurfaceLinkButton → 独立执行页
  → 指导侧边栏 → POST …/guidance（幂等）→ 同 thread 新 turn 注入 Agent
  → 审计承载于 chat_message.metadata（ReviewEvent action=guide 语义）
```

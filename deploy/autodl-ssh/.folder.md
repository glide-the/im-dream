# deploy/autodl-ssh

## 定位

该目录是 Dream frontend/backend 在 AutoDL/SeetaCloud SSH 主机上的直接发布平台，与 `deploy/remote-ssh` 的 Docker、nginx 和 TUN 组合路径分离。

## 合同

- Vite Preview 监听 `127.0.0.1:6006` 并同源代理到 `127.0.0.1:8765` FastAPI；Admin 监听 `127.0.0.1:6008`，公网只映射前端与 Admin。
- 发布安装固定 Node/Python 依赖、构建版本化 frontend/backend release、SDK 0.2.144、Runtime 0.1.1 和官方 CLI 回滚件；不使用 Docker 或 nginx。
- Dream 从 Admin 生成的安全 env 读取 PostgreSQL 身份，只消费 Admin-owned schema，不执行 migration 或 runtime DDL。
- Claude 插件的不可变 artifacts 位于数据盘的持久 runtime root；发布可幂等补充，但不得随版本化 release 删除，验收必须校验默认 Deck 插件。
- `AGENT_CWD`、`ARTIFACT_WORKSPACE_ROOT`、本地文件、服务 home 与 Claude plugin runtime 全部位于 `AUTODL_DATA_ROOT`；`init-dream-data.sh` 拒绝符号链接并幂等校正 owner/group/mode。
- Admin 与 embedded PostgreSQL 的 home 固定为 `/root/ink-autodl/data`，数据库目录为其下的 `postgres`；不得放回 Dream 数据根或 `/var/lib`。
- AutoDL env 投影从 Admin env 的 `DREAM_DIAGNOSTICS_TOKEN` 映射 Dream 专用 token，且不得打印其值。Agent 策略仅接受零项或四项齐全的 `AUTODL_AGENT_*` 平台值，按 Admin 同一边界校验后映射既有 `INK_AGENT_*`；partial、empty、0、非整数、无限或越界全部 fail closed。零项继续使用应用默认。
- 源码同步排除仓库根目录的虚拟环境、构建输出、artifact 与本地验证缓存；这些目录不得进入远端 source mirror 或版本化 release。
- npm 私有访问通过可选 `AUTODL_NPM_TOKEN` 生成临时 mode-0600 npmrc；安装完成立即删除，不写 runtime env 或日志。
- `screen` 只负责 SSH 断开后的进程存活；Dream 的 Vite Preview、FastAPI/Claude 及监督进程以 `root` 运行，确保 `/root` 下 workspace 安全协议可逐级固定目录描述符；Admin/PostgreSQL 仍使用独立非 root 用户。
- `runtime/start-ink-memory.sh` 仅恢复已经发布的 Admin → Dream 进程，不执行 GPU 探测、构建、migration、restore 或未知进程替换。
- `rollback` 只切换 Dream application release，不修改数据库、workspace 或 Admin。

## 入口

- `prepare-env.sh`：将 Dream 与 Admin 安全配置投影为 gitignored `.env`，并固定全部 Dream 持久资源根。
- `platform.env`：从 `platform.env.example` 复制的、gitignored 的 SSH、端口、公网映射与可选四项 Agent desired 配置；`prepare-env.sh` 和 `deploy.sh` 自动读取。
- `deploy.sh`：`check|plan|sync|build|deploy|start|stop|status|logs|verify|rollback`。
- `runtime/start-dream.sh`：screen 内同时监督 Vite Preview 与 uvicorn 的前台入口。
- `runtime/init-dream-data.sh`：部署与独立启动共用的持久目录初始化器。
- `runtime/start-ink-memory.sh`：由 Dream `sync/deploy` 安装到 `/root/ink-autodl/start-ink-memory.sh` 的独立幂等启动脚本。
- `test-topology.sh`：provider-free 校验 env 投影、目录幂等性、owner/mode 与 symlink fail-closed。
- `README.md`：面向 AutoDL 使用者的应用介绍、启动步骤、状态检查和日志入口。

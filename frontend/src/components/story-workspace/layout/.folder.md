# frontend/src/components/story-workspace/layout — Folder Contract

## Architecture Summary

Shared Story Workspace shell, sidebar, review, toolbar, and split-pane layout components.
Writing keeps its canvas beside a canonical, accessible, resizable right-side Thread Chat.

# backend/services/events — Folder Contract

## Files

| File | Pos | Function |
|---|---|---|
| `event_consumer.py` | ordered event consumer | Validate `EventEnvelope`, deduplicate IDs, buffer aggregate gaps and emit timeout alerts through injected callbacks. |

## Boundaries

- This folder does not open PostgreSQL, write audit rows, create schema or own a queue.
- Business persistence must use a named Admin DTO → service → typed Drizzle Repository
  operation defined from a real caller's permission, transaction and idempotency needs.
- EventBus, SSE and Runtime delivery remain owned by their existing Dream modules; this
  pure helper cannot grant user, Thread, Run or Workspace authority.

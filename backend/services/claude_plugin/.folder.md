# backend/services/claude_plugin — Folder Contract

## Architecture Summary

Owns the production Claude Code plugin install, artifact, Deck-reference, and
Admin-approved Remote Marketplace consumption boundary. Remote Marketplace
governance and DDL stay in Admin; Dream never creates schema or treats local
paths/constants as the new managed catalog.

## File Table

| File | Pos | Function |
|---|---|---|
| `marketplace_service.py` | global catalog reader | Require the exact Admin capability, return one user-agnostic active/approved/valid catalog, project shared ready state by exact digest, and resolve immutable install receipts. |
| `install_service.py` | real install orchestrator | Reuse the shared operation/artifact pipeline; Remote entry installs add/update `remote_url[#ref]`, verify managed checkout origin/commit/manifests, and compare the complete plugin digest before ready. |
| `digest.py` | canonical digest facade | Re-export the single plugin-tree digest shared with the Claude Agent kit and artifact store. |
| `cli.py` | Claude CLI boundary | Execute the configured real Claude binary in the server-managed runtime and capture bounded evidence. |

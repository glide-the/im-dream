# Dream Chat 用户消息轮次导航 — 当前 UI 规范

> 配套：[PRD](./turn-navigation.md)、[结构草图](./turn-navigation-structure.md)、[层级逻辑](./turn-navigation-hierarchy.md)。[初版视觉稿](./turn-navigation-ui-v1.md)仅供回溯。本稿按用户追加的局部参考图修订：参考图的文字与产品颜色不作为 Dream 的文案或指令。

## 背景与问题

初版把导航刻度拉成了等距分散的标尺，另加贯穿纵线和较大的多层浮卡。它占用注意力，也没有表现参考图中“当前刻度带动邻近刻度伸缩”的动态关系。导航应帮助人在长 Thread 中辨认位置，同时让消息正文保持主角。

## 目标与边界

- 桌面轨道只占消息阅读区左缘约 `2.5rem`，不增加独立侧栏或背景面板。导航只包含用户实际发送并可读取的消息，顺序、定位和摘要数据规则沿用 [PRD](./turn-navigation.md)。
- 每条消息是一根独立短横。当前阅读位置或正在悬浮、聚焦的刻度为波峰；相邻刻度按距离逐级缩短、变淡。移动指针或滚动阅读时长度平滑过渡，不循环播放。
- 摘要紧贴被指向的刻度，默认只展示用户预览与一行助手结果；无结果时展示明确状态。完整内容仍在原消息中阅读。定位失败时才增加重试反馈。
- 颜色、字体与背景使用 Dream 现有语义 token 和字体；不复制参考产品的黑灰面板、白色硬编码或气泡。约 `31rem` 以下的阅读容器沿用可展开列表。

## 概念与规则

| 元素 | 当前表现 | 行为依据 |
| --- | --- | --- |
| 轨道 | 无纵线、无按钮底色；自身可滚动，视觉上是紧凑的短横序列 | 消息区左侧最多约 `2.5rem` 的布局宽度；输入 Dock 不受影响 |
| 刻度波峰 | 约 `2.2rem`、`3px`，使用 `--color-text-primary` | 悬浮或键盘焦点优先；否则使用当前阅读位置 |
| 相邻刻度 | 距波峰 1／2／3 项逐级缩到约 `1.75`／`1.3`／`0.95rem`；其余约 `0.55rem` | 每项仍有自己的按钮区域；长度和透明度表达距离 |
| 过渡 | 宽度约 `280ms` 缓出，颜色和透明度约 `220ms` | 焦点、悬浮或阅读位置改变时触发；系统减少动态效果时取消 |
| 摘要 | 宽度上限约 `18rem`、高度上限约 `8rem`；紧凑圆角卡，正文最多两行信息 | 一行用户预览，一行助手预览或状态；仅定位进度／失败额外占行 |
| 当前项 | 保留 `aria-current="location"`；键盘焦点显示完整轮廓 | 视觉波峰与语义当前位置分开：悬浮可移动波峰，但不改变实际阅读位置 |

这些尺寸是当前界面实现参数，不是消息数量或业务配额。长 Thread 的轨道独立滚动；当前项移出视野时，轨道将其带回可见区域。参考图只决定“紧凑、邻近联动”的节奏，不决定刻度数量。

## 页面层次

```text
消息阅读区
├─ B1 紧凑刻度列    ─  ━  ─  ·  ·   （波峰随悬浮／阅读位置移动）
│   └─ C1 悬浮摘要  用户消息短预览
│                  对应助手结果／当前状态
└─ D1 原消息滚动区  D2 原用户消息定位锚点
E1 原输入 Dock
```

刻度列与消息滚动区是同级元素；摘要覆盖消息区左上层，不进入消息的滚动裁切层。卡片按被指向按钮的纵坐标定位，并在阅读区边缘夹紧；阅读区很短时卡片内部滚动。没有可导航消息时不渲染轨道。

## 交互、状态与失败反馈

1. 进入 Thread 后，当前阅读刻度较长、相邻刻度呈递减序列。轨道没有额外贯穿线、序号或装饰。
2. 鼠标经过或键盘聚焦另一刻度时，波峰平滑移动；小卡从左侧轻微位移并淡入。离开刻度与卡片、焦点移出或按 Escape 时，卡片关闭，刻度回到阅读位置的波峰。
3. 点击、Enter 或 Space 定位原消息；滚动阅读后，`aria-current` 随实际阅读位置更新。卡片打开本身不移动消息。
4. 助手进行中、失败、停止、暂无回复或状态待核对时，用文字表达；不通过亮度推断业务状态。纯附件显示文件名或“已发送附件”。
5. 索引未完整取得时保留已加载刻度，轨道底部提供重试入口。定位较早消息失败时留在原处，卡片显示重试。切换 Thread 后旧动画与定位请求不继续作用于新 Thread。
6. 阅读容器过窄时，使用现有“本对话消息”展开列表；触屏可直接选择，列表避开输入 Dock 和移动端底部导航。减少动态效果偏好下，刻度和卡片直接切换，滚动定位不使用平滑动画。

## 验收

- 在桌面同一 Thread 的多个刻度之间移动指针：波峰与邻近短横连续伸缩，其他刻度保持紧凑；轨道宽度不超过约 `2.5rem`，不出现贯穿竖线和大片按钮背景。
- 悬浮摘要只占短小卡片，用户与助手预览可读，长正文截断；键盘聚焦得到相同内容与可见焦点。
- 点击刻度、加载旧历史和手机列表行为仍符合 [PRD 验收](./turn-navigation.md#验收)；亮暗主题、右侧面板展开和侧边任务聊天不产生页面横向滚动。
- 在减少动态效果模式下，CSS 不运行刻度宽度过渡或卡片进入动画。

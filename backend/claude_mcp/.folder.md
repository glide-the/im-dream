# backend/claude_mcp — Folder Contract

## Architecture Summary

Owns the `claude-mcp` business domain for Resources discovery, prompt-free public-SDK tool inventory, and official Claude Code MCP OAuth argv operations. Authentication runs before any thread in a server-owned, platform-user-scoped config and secure-storage identity. Every Agent turn and inventory probe receives opaque `mcpServers` definitions through the public SDK; Linux additionally projects file-backed `mcpOAuth`, while macOS keeps secrets inside Claude Code's user Keychain and passes only the secure-store selector to Agent. No database schema, whole-home copy, Keychain payload access, tool invocation, shell command, TUI parsing, or private SDK control subtype belongs here.

## File Table

|---|---|---|
| `__init__.py` | package boundary | Export the domain service. |
| `contracts.py` | stable contract layer | Define connection/auth states, config scopes/removability, safe DTOs, runtime identity, and semantic error codes. |

| `credentials.py` | credential delivery boundary | Canonicalize platform user IDs, return opaque `mcpServers` for public SDK injection, remove obsolete config snapshots, project/revoke Linux file-backed `mcpOAuth`, remove stale macOS plaintext projections, and expose only the user secure-storage home. |
| `keychain.py` | non-secret identity metadata | Derive Claude's deterministic service label for diagnostics; deliberately exposes no Keychain read/write/delete operation. |
| `parser.py` | CLI compatibility seam | Parse bounded status/scope/transport plus stable `Authentication`/`Failure-Code` lines, validate absolute HTTP(S) server URLs, preserve colon-bearing names, and redact secrets. |
| `driver.py` | subprocess/PTTY adapter | Execute official `claude mcp` argv commands and clean process groups. |
| `inventory.py` | public SDK discovery adapter | Poll `ClaudeSDKClient.get_mcp_status()` to a bounded terminal state and return sanitized tool metadata/annotations without prompts or tool calls. |
| `service.py` | operation orchestration | Own user-scoped in-memory OAuth lifecycle, explicit-login state gates, semantic failure projection, idempotency, concurrency, post-logout truth, verification, and fail-closed user-scope removal authorization. |

## Architecture Summary

Deck-domain application services. This folder resolves server-owned Deck
plugin policy, runtime locks/context, default provisioning, and Story Workflow
operations without accepting filesystem paths or installation identities from
the browser.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | package init | Mark the Deck service package. |
| `admin_gateway.py` | Deck Plugin admin adapter | Materialize server-published runtime locks for Deck Plugin administration. |
| `agent_type.py` | Deck Agent type policy | Derive `chat` / `dream` from active published Deck Plugin capabilities and expose list-safe decoration. |
| `agent_type_runtime.py` | Agent-type local verifier | Derive Registry129 immutable evidence from Admin's closed candidate using the configured shared artifact store, manifest parser and current Claude CLI; no paths or persistence cross the API. |
| `builtin_plugin.py` | built-in plugin source | Seed and resolve the repository-owned Dream Story plugin. |
| `chat_context.py` | chat Deck context | Validate persisted Deck Claude-plugin refs and expose provenance to Chat. |
| `defaults.py` | Deck-default local verifier | Verify Admin's configured six-field candidate against shared artifact bytes and the current Claude CLI, then return the four-field evidence used by Admin-owned Deck transactions. |
| `runtime_context.py` | runtime compatibility adapter | Resolve server-owned Deck Plugin runtime compatibility facts. |
| `sharing.py` | Deck sharing policy | Derive publication eligibility and reject system-default publishing, self-collection, and collection of unpublished Decks. |
| `content_versioning.py` | Deck content version service | Normalize the existing mutable Deck aggregate as one durable draft, preview changes, and append explicit immutable vN snapshots with CAS. |
| `story_workflow_application.py` | Story Workflow application service | Authorize remaining Run-scoped Dream operations and expose body-free Episode/selected artifacts; original Run error method reuses the unchanged shared mapping. Public read/create/retry, Guidance and confirmation persistence now use Admin DTOs; confirmation keeps the local shared-filesystem projection and Runtime coordinator, while other SQL callers remain tracked. |

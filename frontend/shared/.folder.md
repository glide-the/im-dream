# 共享运行库资源

`bridge/contract.json`定义已有消息协议。RN主业务直接使用HTTP，局部网页适配继续按原协议校验。`build/`为历史资源生成物，排除Git及新Next源码装配。

`deck-icons.json`为原Web的12个Deck/Agent图标路径及5个token名的固定投影，生成器归`native-scripts/prepare-deck-icons.mjs`。JSON的source字段持有原路径、安装包版本、署名和许可，替代代码文件头。Native只消费路径和token名，Web继续原组件及CSS。

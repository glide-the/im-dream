## Architecture Summary
React context providers for authenticated frontend state and workspace UI state.
Contexts should centralize shared app state that crosses view/component folders.

AuthContext checks Browser owner snapshot identity before committing async session results; a stale result cannot restore user state after logout or replace a newer session.

## File Table

| File | Pos | Function |
|---|---|---|
| `AuthContext.tsx` | auth-context provider node | 同源BFF公开user/session，登录注册共用Admin email/signup/Google UI；仅current snapshot提交异步user；成功revoke才清状态，失败保留并提示；无OAuth storage/fragment adoption/renewal。 |
| `WorkspaceContext.tsx` | workspace-context provider node | Provide active workspace session ID plus Settings-backed Workspace Mode enabled state for chat/file UI gating. |

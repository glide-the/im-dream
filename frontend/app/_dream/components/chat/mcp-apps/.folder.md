# MCP Apps Browser Host

Client-only Phase 1-3 Host. The Browser connects only to the same-origin Next
endpoint, consumes a revisioned intersection of actor-owned connection choices
and server-owned zero-permission policy, and always leaves the ordinary tool
result visible. Resource reads are the baseline;
low-risk tool calls, `ui/message`, and `window.im` are independently gated by
the plugin manifest and effective policy.

| File | Function |
|---|---|
| `result.ts` | Consumes only the versioned server-owned result projection, including its optional workspace scope, and rejects error results, output-metadata spoofing, mismatch, and sensitive material. |
| `result.test.ts` | Locks lossless parsing of the official data-only CallToolResult plus descriptor-derived projection, and fail-closed ordinary fallback without Browser or network state. |
| `host-policy.ts` | Validates Host/plugin/App-settings identity, desired/effective transitions, revision-bound current-entry sandbox URL and opaque document isolation. |
| `host-policy.test.ts` | Locks compatibility, lifecycle, feature ceiling, origin, and revision anti-spoofing behavior. |
| `session-cleanup.ts` | Bounds standard session DELETE, retries with a fresh signal after SDK connect abort, always closes the local Client, and suppresses obsolete lifecycle errors. |
| `session-cleanup.test.ts` | Reproduces normal, connect-aborted, stalled, and lifecycle-switch cleanup without a live service. |
| `McpAppHostPanel.tsx` | Polls the authenticated connection-scoped plugin/runtime/App-settings snapshot, carries trusted workspace scope, pings the live session, and owns close/reopen/retry/revision teardown through standard MCP DELETE before local close. |
| `ImMcpAppHostAdapter.tsx` | Validates descriptor/resource metadata, owns the two-layer sandbox, uses no auto-forwarding SDK Client, and manually exposes only enabled calls/messages/context. |

# deploy/local/

## 架构概述
本地直跑发布脚本目录，复用 `backend/server.py` 与根 Next.js 项目 `frontend/package.json` 的 pnpm 启动方式；
数据库由相邻 Admin `@ink-memory/db` supervisor 管理，Dream 只从 mode-0600 Admin env 文件读取连接串。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | 本地发布入口 | 以 `pnpm run build` / `pnpm run dev` 运行根 Next.js 前端；检查 Dream 配置和 Admin env，使用 `LOCAL_ADMIN_ENV_FILE` 选择 embedded PostgreSQL 连接来源；当前未投影 Browser Voice WS base，stop/clean 只信任 PID 文件/容器名而未强校验所有权；Vite 只允许作为显式具名不可变回滚镜像 |

# 原生品牌图片

| 文件 | 职责 |
| --- | --- |
| `app-icon-reference.png` | 用户第一张160×134图标参考；高清图标位于iOS AppIcon资源集 |
| `startup.png` | 用户第二张1254×1254原图，保留来源参考 |
| `startup-artwork.json` | 角色轮廓、五官与蓝白帽子的七条矢量路径；RN组件直接使用，脸部及画布透明 |
| `startup.svg` | 同一路径生成的独立透明SVG，线稿使用currentColor |

`node frontend/ios/scripts/sync-startup-artwork.mjs --write`生成独立SVG及iOS `StartupArtwork.imageset/`内的深浅色SVG；`--check`验证路径一致性。iOS线稿色读取`inkColors.ts`现有文字色，主背景由启动画面或StartupScreen提供。PNG参考图保持原始字节。图片内容作为视觉素材。

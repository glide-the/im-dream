## Maintenance Rules

- 优先复用现有模块和合同，新增路径前先证明没有 canonical 实现。
- 每个 task/requirement 都要列明可写闭集、禁止范围、技术依赖、验收命令、失败语义和回滚。
- 实施是否可开始只由列明的技术依赖和安全边界决定。
- 缺少 capability、配置、制品或安全证明时 fail closed，并记录真实缺口。
- 修改任务合同后同步本文件和对应设计、阶段或执行证据的引用。

# Reflections 的 L2 蒸馏与 L3 行为设置

## 背景与问题

本次采用处理阶段的定义：用户主动触发 Reflections 回顾属于 L2 检索与蒸馏；`traits`、`echoes`、`patterns` 是同次回顾的三种分析视角。缺口是把每次保存的分析报告转换为 `memory_distillation.md`，为 Agent 提供读取工具，再将 L2 内容转换为有来源的 L3 主题及实际回应策略。

L3 当前没有结构、策略执行器或行为设置页面。本次先确定它们的合同，才设计设置页面。先前“报告内提取、人工挑选记忆、独立记忆列表”的方案已撤回，原文见[历史PRD](reflections-agent-memory-prd-pre-l2-l3-20261015-history.md)。

## 目标与边界

1. 每份实际保存的 Reflections 报告生成独立、可追溯的 `memory_distillation.md`。生成不需要用户再次点击提取或逐条确认；这是回顾的派生产物，保留原结论的范围和推断性质。
2. Agent 按任务查找并读取 L2 文档，能够跨 Thread 使用同一用户的回顾内容。
3. L3 从 L2 生成四主题及细分标签，结合当前对话和用户设置决定回应行为。
4. 页面只增加现有 Settings 中的“记忆回应”设置，配置 L3 行为。Reflections、报告阅读、时间轴、Deck/Agent 编辑器均不增加页面或按钮。

本轮只修订设计，不实现代码、数据库或真实文件产物，不调用模型验收。正式稿中的文件、接口、工具和策略执行器均为建议、未实现。

## 概念与规则

| 对象 | 产品规则 |
| --- | --- |
| Reflections报告 | 保留原三视角和现有成功/部分失败/报告保存恢复合同 |
| L2文档 | 每份报告对应一个文档，固定文件名memory_distillation.md，记录事件/主题、情感基调、人物/实体、行为倾向、后续任务与核心诉求；没有来源支持的内容不补造 |
| 版本 | 普通重试沿原operation；规则变化或授权后台明确重生成使用新generation_key创建新版本，旧文件保留，不新增重生成按钮 |
| L3主题 | 挫折、防御、压力、价值；十六个原始标签是服务端词表，不是十六项用户画像或设置开关 |
| L3输出 | memory_theme.md保存对应L2版本的主题记录，必须能回到具体L2片段及报告；历史主题不代表当前心理状态 |
| 当前触发 | 当前表达和任务仍符合具体条件，才应用主题回应；用户否定、拒绝话题、内容为引用或任务规范时排除 |
| 行为设置 | 认证用户的个人回应偏好；不随Deck复制或发布，不让Agent修改，不包含任意可执行提示词 |
| default | 服务端版本化默认策略；主动主题回应默认关闭，各主题默认行为已定义，启用后使用 |
| desired | 用户保存的总开关、主题启用和允许的回应方式，带独立revision |
| effective | 每轮服务端解析出的不可变策略；保存影响下一轮，当前回应不切换策略 |

## L2转换与Agent使用

原流程：用户生成回顾→三栏目执行→Admin保存报告。本次在报告确认保存后后台生成L2文档，再生成L3主题文件；任一步失败都不能把已完成报告改成失败。

部分失败报告只处理已成功栏目并标出缺失；没有报告不登记派生artifact，已有报告无有效蒸馏项为empty，不造空事实。相同内容可合并描述，但来源、时间、矛盾和例外不能丢；traits仍是观察/推断。

Agent使用建议的 `list_memory_distillations` 查目录、`read_memory_distillation` 读具体版本；工具返回文件内容和来源，而非任意路径。需要L3回应时使用 `resolve_memory_behavior`，它解析当前情境及服务端设置；不替用户保存偏好或修改L2内容。

## L3行为与设置项

| 主题 | 初始回应方式（总开关启用后） | 可选方式 |
| --- | --- | --- |
| 挫折 | 简短回应具体困难，再继续帮助完成任务 | 只提供实际帮助；询问希望得到哪类支持 |
| 压力 | 帮助明确优先级和下一步 | 简短回应后继续任务；询问支持方式 |
| 防御 | 尊重距离，按用户当前要求回应 | 询问支持方式；只提供实际帮助。明确拒绝话题始终停止，不受选项影响 |
| 价值 | 结合用户明确的目标或热爱，帮助当前选择 | 简短回应；只提供实际帮助 |

设置只包含总开关、四主题启用和各主题回应方式。暂停、呼吸练习、心理诊断、强制换话题、关系承诺、阈值和标签编辑不进入首期设置。提供“恢复默认”将本页草稿恢复为默认值，点击“保存设置”才提交，不弹重复确认。

## 唯一页面入口与完整交互

从现有Settings导航进入“记忆回应”（建议路径 `/story-workspace/settings/behavior`）。首次显示已发布默认值；已有配置时显示服务端已保存值。编辑生成本页草稿，保存使用原revision和请求标识。

保存成功显示“已保存，下一次回应使用此设置”，只表示desired已提交。正在执行的回应保留旧effective；下一轮重新读取并解析。读取失败不显示假默认覆盖已有配置；保存失败保留草稿；结果未知查询原收据，不换请求标识重新提交。版本冲突展示新已保存值，保留本地选择供用户合并。

总开关关闭时，四主题控件不可编辑但保留选择；它关闭主题辅助回应，不禁止Agent为普通任务读取L2。缺少L2/L3不妨碍保存偏好，也不触发新分析，显示“有可用回顾内容时使用”。来源不足、服务不可用或无当前匹配时按原任务回应，不伪称已应用主题策略。

```text
StoryWorkspaceSettingsPage（沿用现有外壳）
┌ 原设置导航 ───┬ 记忆回应 ─────────────────────────────┐

│ [记忆回应]     │ 保存后用于下一次回应                   │
│               │                                      │
│               │ [✓]挫折 [简短回应后继续帮助        ▾]  │
│               │ [✓]压力 [帮助明确优先级和下一步    ▾]  │
│               │ [✓]防御 [尊重距离与当前要求        ▾]  │
│               │ [✓]价值 [结合目标帮助当前选择      ▾]  │
│               │ 控件在同一内容区域纵向滚动             │
```

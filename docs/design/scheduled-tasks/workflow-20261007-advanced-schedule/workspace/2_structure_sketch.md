## 2. 重复下拉与模型下拉

### 2.1 桌面重复菜单

```text
┌─ C1 日程卡片 ───────────────────────────────────────────────────────────┐
│ C2 重复                                           自定义            [⌃] │
│                                                   ┌─ G1 重复菜单 ─────┐│
│                                                   │ G2 每小时          ││
├───────────────────────────────────────────────────│ G3 每天            ││
│ C3 高级日程                            [编辑规则] │ G4 工作日          ││
└───────────────────────────────────────────────────│ G5 每周            ││
                                                    │ G6 自定义        ✓ ││
                                                    └────────────────────┘│
```

- G1 锚定在 C2 当前值下方，向左扩展以容纳最长标签；空间不足时向上翻转，不能遮住 A4。
- G2—G6 顺序固定，当前 desired 项显示勾选。方向键移动、Enter 选择、Escape 关闭后，焦点回到 C2。
- 选择 G2—G5 后更新 C2 与 C3；缺少时间或星期时打开 H1。选择 G6 时直接打开 H1，取消编辑则恢复打开前的 desired。

### 2.2 桌面模型菜单

```text
┌─ D6 模型选择 ──────────────────────────────────────────────────────────┐
│ 模型                                           GPT-5.6 Sol         [⌃] │
└───────────────────────────────────────────────┬────────────────────────┘
                                                │ ┌─ J1 模型菜单 ────────┐
                                                │ │ J2 当前有效模型    ✓ │
                                                │ │    展示名            │
                                                │ │    modelAlias        │
                                                │ ├──────────────────────┤
                                                │ │ J3 其他可调用模型    │
                                                │ │    展示名            │
                                                │ │    modelAlias        │
                                                │ ├──────────────────────┤
                                                │ │ J4 已保存旧值        │
                                                │ │    不可用（禁选）     │
                                                │ └──────────────────────┘
```

- J1 只列当前用户可调用模型；主文案为展示名，辅助文案为 `modelAlias`。
- 已保存模型已停用时使用 J4 保留原值并标注“不可用”，不自动改选其他模型。
- 加载失败、空目录等状态留在 D7；列表过高时只有 J1 内部滚动。

## 6. 结构约束摘要

- 桌面 A3 与窄屏 K3 都是各自主弹窗的唯一页面级滚动区；所有菜单或二级 sheet 只滚动自己的超高内容。
- 桌面用锚定浮层表达重复与模型选择，用二级 dialog 编辑规则；窄屏统一使用 bottom sheet，避免横向溢出。
- D1 收起时隐藏 D2，但 D4 与 D6 的 desired 值保留。模型错误或新聊天配置错误需要处理时，可自动展开并定位 E1/D7。
- C2 是频率摘要，C3 是日期、星期、时间和时区摘要；用户无需进入二级编辑器即可检查关键规则。
- H13 只应用到当前表单草稿，F2 才保存 revision。保存后的 effective 以服务端完整回执为准。

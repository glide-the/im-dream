# backend/services/story_workspace — Folder Contract

## Architecture Summary

Server-owned Story Workspace application and infrastructure services. The folder resolves actor-scoped Dream launch/re-entry authority, validates immutable workflow provenance, projects canonical artifacts, and integrates successful Agent turns without adding a second Chat transport or runtime schema path.

## File Table

| File | Pos | Function |
|---|---|---|
| `agent_integration.py` | Agent output parser | Parse a complete Agent response into the strict Story proposal contract; performs no SQL, ORM, HTTP, filesystem or Runtime action. |
| `artifact_story_index_*.py` | Story Index projection family | Project, reconcile, store, and serve canonical Story Index facts. |
| `canonical_project_instruction.py` | canonical prompt contract | Define server-owned project/workbench instructions. |
| `dream_artifact_turn_hook.py` | post-turn hook | Validate canonical project/stage collections before projection writes, synchronize contiguous Episode registry facts from one changed or uniquely discovered Episode, publish trusted successful Dream artifacts from any valid current same-Deck Agent, and revalidate exact trusted/stale roots for a marked repair Turn. |
| `dream_auto_repair_service.py` | auto-repair message service | Build one allowlisted, redacted, stable-id user message whose body and server-owned `projectCleanup` metadata name the trusted root, stale roots, and one-way merge; settle dispatch state through the existing `chat_message` table and expose a safe bounded final reason. |
| `dream_confirmation_service.py` | confirmation Runtime coordinator | Claim through Registry121, build the existing Workflow/Deck/turn persistence owner, start it before the same-Thread Runtime and drain it before ACK; performs no SQL, ORM or PostgreSQL connection. |
| `dream_file_service.py` | Dream file service | Read and project actor/thread-scoped Dream workspace files. |
| `dream_launch_*.py` | launch application family | Validate launch input, use request-scoped Admin Runtime scope/current/replay DTOs, persist remaining launch provenance, and expose the canonical launch endpoint. |

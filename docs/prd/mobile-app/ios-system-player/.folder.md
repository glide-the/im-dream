# iOS角色与播放器设计资产

媒体、确认回执与准备回执均为虚构示例。演示不连接服务、扫描设备或播放音频。

| 文件 | 职责 |
| --- | --- |
| `preview.html` | 默认v4.2角色、Agent请求、原AskUserQuestion区域、不播放/取消/超时、播放请求返回后准备、播放/暂停、关闭返回与主题的离线演示。 |
| `default-role.png` | 默认角色截图，无媒体标题、进度和播放控制。 |
| `media-confirmation.png` | 原对话媒体确认区域截图，新的播放器尚未展示。 |
| `clock-cover-light.svg` | 原v4.2七条角色路径、十二时位与三根指针的浅色静态封面。 |
| `clock-cover-dark.svg` | 相同几何的深色封面。 |
| `player-light.png` | 用户回答播放、MCP返回且模拟资源就绪后的浅色播放器。 |
| `player-dark.png` | 相同已确认布局的深色播放器。 |

原型复用原脸型路径与开心/悲伤嘴部形态，保留三种交互入口；原v4.2完整动效与逐秒时钟由原组件负责。iOS系统区域布局、字体和材质以系统实际呈现为准；系统入口遵循允许的显示生命周期。

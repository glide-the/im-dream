## 1. 结构判断

目标图表达的核心不是“两栏线框页面”，而是覆盖在应用上方的一块透明 Modal 画布，以及直接浮在画布上的纸张对象：左侧月历是一张大纸张卡；右侧 Scheduled tasks 与 Diary 是两张自然高度、彼此分开的纸张卡。画布本身不构成第四张卡，也不显示重复的 `Calendar` 标题或独立日期摘要。

以下红框只存在于输入截图的评注意图中，不属于产品结构；生产界面不渲染红框。

### 2.1 宽屏比例与对齐

- B1 与右侧卡栈顶部对齐；月历保持较大的稳定纸面，右侧两张卡按内容自然增高。
- A2 和右侧卡栈均保持透明，B1、C1、D2 的完整圆角、纸色和阴影必须直接接触透明间隙。
- C6 是真实可见的遮罩画布间隙，不能被共享白色父容器填满。
- D1 独立置于画布安全区，不创建顶栏；界面不显示 `Calendar` 页面标题。
- C2/D3 内组合所选日期与业务名称；不存在位于 C1、D2 之外的独立日期摘要卡。

```text
┌────────────── A0 应用视口 ──────────────┐

│ · ╭────── B1 月历悬浮纸张卡 ─────────╮ · │
│ · │ B2 ‹      2026 年 9 月       ›    │ · │

│ · ├────────────────────────────────────┤ · │

│ · ╰────────────────────────────────────╯ · │

│ ·                                        · │
│ └····································┘ │
└───────────────────────────────────────────┘
```

### 3.1 窄屏规则

1. DOM 与视觉顺序固定为 B1 月历 → C1 Scheduled tasks → D2 Diary。
2. 三张卡都保留完整圆角和阴影；不能拼成一张连续白色长面板。
3. C5 的元信息、状态和操作可换行，但不能引发横向滚动。
4. D1 不遮挡 B2、C2 或 D3；必要时为首张卡留出关闭按钮安全空间。
5. 窄屏仍不恢复可见 `Calendar` 标题或独立日期摘要。

## 4. 滚动与裁切边界

### 4.1 宽屏默认与内容增长

```text
A0 视口（固定）
└─ A1 遮罩（固定；背景不可滚动）
   └─ A2 透明画布（E1 主滚动边界）
      ├─ B1 月历卡（自身不随 C5 展开而拉高）
      └─ E2 右侧透明卡栈
         ├─ C1 任务卡
         │  └─ C4 状态插槽
         │     └─ C5 任务列表/编辑/历史（自然向下展开）
         ├─ C6 透明间隙
         └─ D2 日记卡
```

- E1 在宽屏对应右侧卡栈、在单列对应 `.calendar-popup`；每个断点只有一个任务/日记滚动边界，内容增长时不撑开 dialog，背景应用不得滚动。
- 宽屏短视口中，B1 月历纸面可独立滚动日期网格以保证最后一周可达；纸面位置不随右侧 E1 滚动。
- 当 B1、C1、D2 总高度未超过可用视口时，A2 不出现无意义滚动条。
- 当任务编辑、历史或长列表展开超过可用高度时，由 E1 纵向滚动；B1 不被强制拉伸，D2 继续位于 C1 下方。
- 除非既有详情控件已经明确提供内部列表滚动，C4/C5 不新增第二个常驻纵向滚动容器，避免嵌套滚动。
- A2 必须给 B1/C1/D2 的阴影保留外侧安全区，不能用 `overflow: hidden` 截断卡片高度阴影。
- 所有断点均禁止横向滚动。

### 4.2 窄屏滚动

```text
┌────── E1 可视窗口/画布滚动起点 ──────┐
│ D1 关闭按钮（可达、不盖内容）          │
│ B1 月历完整卡                         │
│ C6 透明间隙                           │
│ C1 任务完整卡                         │
│   C5 展开编辑/历史后继续自然增高       │
│ C6 透明间隙                           │
│ D2 日记完整卡                         │
└────── E3 底部滚动安全留白 ────────────┘
```

E3 确保最后一张卡的圆角和阴影可完全滚入视口，不停在裁切边缘。

## 5. Scheduled tasks 局部状态骨架

C1 的卡头始终保留；下列状态只互斥替换 C4，不影响 B1 或 D2。

### 5.1 Loading

```text
╭──────── C1 Scheduled tasks 悬浮纸张卡 ────────╮
│ C2 日期化任务标题                  C3 数量待定 │
├───────────────────────────────────────────────┤
│ C4 [加载指示] 正在载入定时任务…               │
╰───────────────────────────────────────────────╯
```

### 5.2 Error

```text
╭──────── C1 Scheduled tasks 悬浮纸张卡 ────────╮
│ C2 日期化任务标题                  C3 数量未知 │
├───────────────────────────────────────────────┤
│ C4 暂时无法载入任务。                 [重试]   │
╰───────────────────────────────────────────────╯
             D2 Diary 仍独立可交互
```

### 5.3 Empty

```text
╭──────── C1 Scheduled tasks 悬浮纸张卡 ────────╮
│ C2 日期化任务标题                       C3 0项 │
├───────────────────────────────────────────────┤
│ C4 这一天没有定时任务。                        │
╰───────────────────────────────────────────────╯
```

### 5.4 List

```text
╭──────── C1 Scheduled tasks 悬浮纸张卡 ────────╮
│ C2 日期化任务标题                 C3 2项 · 1关注│
├───────────────────────────────────────────────┤
│ C5 标题                    [Paused]   [恢复]   │
│    每天 09:00 · Asia/Shanghai                 │
│    下次执行… · 最近结果…             [更多]   │
│                                               │
│    · · · 低对比分组间距/必要时单线 · · ·      │
│                                               │
│ C5 标题                    [Active] [立即运行] │
│    一次 · 2026-09-29 15:38                    │
│    已完成 · [打开会话]                [更多]   │
╰───────────────────────────────────────────────╯
```

列表态中计划、时区、下次执行和最近结果属于文本组，不各自包裹成事实框。编辑与历史在对应 C5 内自然展开，可使用极浅背景区分，但不增加完整边框和重阴影。

## 6. Diary 局部状态骨架

D2 与 C1 独立；任务加载或失败时，D2 仍使用自己的状态。

### 6.1 Empty

```text
╭────────── D2 Diary 悬浮纸张卡 ──────────╮
│ D3 日期化日记标题                  D4 0篇 │
├─────────────────────────────────────────┤
│ D5 这一天还没有日记。                    │
╰─────────────────────────────────────────╯
```

### 6.2 List

```text
╭────────── D2 Diary 悬浮纸张卡 ──────────╮
│ D3 日期化日记标题                  D4 2篇 │
├─────────────────────────────────────────┤
│ D6 12:00  [当前笔记]             [删除] │
│    Untitled                             │
│                                         │
│ D6 09:40                         [删除] │
│    Morning notes                       │
╰─────────────────────────────────────────╯
```

D6 是卡内轻量条目，不具备与 D2 相同的悬浮高度。当前笔记可用细绿色边、极浅绿色底和文字标识共同表达。

## 7. 模块索引

| 编号 | 模块 | 结构职责 | 可见表面/滚动 |
| --- | --- | --- | --- |
| A0 | 应用视口 | 承载背景应用和弹窗覆盖层 | 固定，不作为纸张 |
| A1 | 半透明遮罩层 | 压暗背景、隔离背景交互 | 透明暖灰遮罩，固定 |
| A2 | Modal 布局画布 | 管理 dialog 尺寸和焦点语义 | 完全透明；自身不滚动 |
| B1 | 月历悬浮纸张卡 | 选择日期 | Paper Cream、完整圆角、暖棕高度阴影 |
| B2 | 月份导航 | 切换月份 | 无独立边框或标题栏 |
| B3 | 星期行 | 解释日期列 | 以留白组织 |
| B4 | 日期网格 | 展示和选择日期 | 普通格无常驻边框；状态格保留语义反馈 |
| C1 | Scheduled tasks 悬浮纸张卡 | 展示所选日期任务 | 独立纸张表面和阴影 |
| C2 | 日期化任务标题 | 合并日期上下文和业务身份 | 卡头文字，不生成摘要卡 |
| C3 | 任务数量/关注摘要 | 展示本卡数量与可行动项 | 卡头次级文字 |
| C4 | 任务局部状态插槽 | 互斥承载 loading/error/empty/list | 仅一条卡头正文分隔线 |
| C5 | 扁平任务条目 | 展示任务信息、操作、编辑和历史 | 文本组/浅表面；无多层事实框和重阴影 |
| C6 | 卡片透明间隙 | 显示卡片各自完整轮廓与高度 | 透明，不属于任何卡 |
| D1 | 关闭按钮 | 关闭弹窗并恢复焦点 | 画布独立控件，无可见顶栏 |
| D2 | Diary 悬浮纸张卡 | 展示所选日期日记 | 独立纸张表面和阴影 |
| D3 | 日期化日记标题 | 合并日期上下文和业务身份 | 卡头文字，不生成摘要卡 |
| D4 | 日记篇数 | 展示本卡数量 | 卡头次级文字 |
| D5 | 日记局部状态插槽 | 互斥承载 empty/list | 不受 C4 状态覆盖 |
| D6 | 日记条目 | 打开/删除日记并标识当前笔记 | 卡内轻量行，无悬浮阴影 |
| E1 | 响应式主滚动边界 | 宽屏只滚动右侧任务/日记卡栈；单列滚动三张纸面 | 月历在宽屏固定；不撑开 dialog；禁止背景和横向滚动 |
| E2 | 右侧透明卡栈 | 顺序排列 C1、C6、D2 | 无背景、边框和包围阴影 |
| E3 | 底部安全留白 | 让最后一张卡阴影完整进入视口 | 透明留白 |

## 8. 结构禁区

1. A2 不显示可见大 Modal 白底、外框、圆角或包围 B1/C1/D2 的阴影。
2. 不增加 `Calendar` 页面标题、独立日期标题、日期摘要、统计面板或新的创建入口。
3. E2 不画共享右栏纸面；C1 和 D2 必须通过 C6 分开，分别拥有完整圆角与阴影。
4. C5 不把每项事实、操作、编辑区和历史区继续包成多层线框。
5. B1、C1、D2 之外的容器不得伪装成同级悬浮卡。
6. 阴影和留白只表达视觉高度，不改变现有 Task、Thread、Run、revision、日记持久化和操作语义。

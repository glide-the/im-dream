# 第一阶段：外部链接管理需求草稿

## 背景与问题

用户需要在设置中管理AI对话与笔记生成的公开链接，并对单条链接执行失效。
两张参考图给出分类概览、分类名单和行更多入口，具体示例人物、网站及表单类别留在原始参考中。

现有设置桌面导航由`StoryWorkspaceSettingsPage.tsx`所有，原生分类由同名`.native.tsx`所有。
当前栏目为常规、订阅、工作台、记忆回应、AI模型、关于。
现有设置地址为`/story-workspace/settings`，外部链接拟使用独立同层栏目。

## 目标与边界

分类固定为AI对话与笔记。概览展示有效链接数量，点击后进入对应分类列表。
单条管理包括复制、打开公开页面、查看原内容、使链接失效和查看已失效信息。
本阶段交付PRD，管理页面、状态持久化、AI链接创建和删除联动均待实现。
本次保持自动测试暂停，未执行功能验证。

## 概念与规则

### 当前能力

| 模块 | 已观察到的源码能力 | 缺口 |
| --- | --- | --- |
| 设置 | 常规、订阅、工作台、记忆回应、AI模型、关于 | 外部链接栏目和检索名称。 |
| AI对话分享 | 图片导出与预览 | 公开链接创建、管理目录和失效。 |
| 笔记分享 | 正文快照文件、公开读取页面 | 所有者目录、有效状态和主动失效。 |

### 方案比较与收敛

| 方案 | 判断 |
| --- | --- |
| 每个分享弹层分别管理 | 跨业务查看时需要反复寻找原内容。 |
| 设置中混合长列表 | 两类内容需要用户逐行辨别。 |
| 设置中的两类概览与分类名单 | 与参考层级及当前两类业务对应，选用。 |

### 关键决定

1. 概览有效数量按链接条数统计，同一内容的不同链接分别计数。
2. 分类名单默认有效，可切换已失效；时间排序采用发布时间从近到远。
3. 单用户归属页面省略首次发布人列，保留标题、链接、发布时间、状态与行更多。
4. 失效直接提交并反馈，保留原内容；旧链接保持单向失效，重新分享生成新链接。
5. 原内容删除联动关闭全部关联公开访问，失效记录标记删除原因。
6. 结果未知是操作反馈，提供刷新核对；服务端确认后展示已失效。
7. 已失效页面隐藏正文和原内容信息。
8. 现有文件快照须新增服务端归属与状态记录；共享Schema依照Admin Drizzle合同交付。

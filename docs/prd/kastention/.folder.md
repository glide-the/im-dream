# docs/prd/kastention

## Architecture Summary

本目录按思维模式业务归属保存产品规则与页面骨架。Deck 是现有代码与接口中的承载形式。
正式交互图由关联的 `docs/design/kastention/` 或 `docs/design/kastention-plugin/` 设计稿负责。

## File Table

| File | Pos | Function |
| --- | --- | --- |
| `kastention.md` | 现行思维模式 PRD | 定义产品名称、概念、中文用语范围、桌面与窄屏骨架、状态及验收。 |
| `kastention-workflow-plugin.md` | Deck 工作流插件 PRD | Dream Story Workflow 用途、设置目录及 Deck 维护桌面/窄屏骨架、工作流版本和连接边界。 |
| `claude-code-plugins.md` | Claude Code Plugins PRD | Admin 已发布插件的思维模式选择边界、桌面/窄屏骨架、失败反馈和待实施范围。 |

# deploy/autodl-ssh

## 架构概述

AutoDL/SeetaCloud 直宿主发布脚本的历史实现与迁移边界。当前脚本仍绑定已删除的 Vite/npm 源码形状，不兼容根 Next.js/pnpm workspace，因此本目录是阻塞的代码迁移目标，不是当前发布入口。

## 文件清单

| File | Pos | Function |
|---|---|---|
| `README.md` | 当前状态与迁移合同 | 说明确定性阻塞证据、历史拓扑、必须保留的安全边界和重新启用门槛 |
| `deploy.sh` | 历史直宿主发布实现 | 仍检查 `package-lock.json`/`vite.config.ts`、执行 Vite build 并要求 `dist/index.html`；在完成 Next.js/pnpm 代码迁移前不得用于当前发布 |
| `prepare-env.sh` | 历史环境投影 | 保留 Secret 与持久根投影逻辑，同时仍投影 Vite host 配置；未来迁移必须移除前端旧变量而不削弱安全边界 |
| `platform.env.example` | 历史平台配置模板 | 记录 SSH、端口、公网映射和 Vite host 变量；Next.js 迁移后必须重新审查字段 |
| `runtime/` | 直宿主运行脚本 | 包含持久目录初始化和历史 Vite/FastAPI supervisor；当前 `start-dream.sh` 不兼容 Next.js frontend |
| `test-topology.sh` | 历史拓扑校验 | 仍断言已删除的 Vite 源码和环境投影，不能资格化当前 frontend |

## 必须保留的安全边界

- Dream 只消费 Admin-owned PostgreSQL schema，不执行 migration、runtime DDL、备份或恢复。
- Dream workspace、Notion credential、Artifact、本地文件、plugin Runtime 与 service home 必须位于显式数据根，拒绝符号链接并保持既有 owner/group/mode。
- 历史 AutoDL 外层容器固定 `INK_AGENT_SANDBOX_ENABLED=false`；这意味着 approved Bash 以 Dream root 身份运行且没有 bubblewrap 文件系统或网络隔离。迁移不得隐去或自动改变该事实。
- 发布、启动、停止和回滚只能影响本目录明确命名并拥有的 Dream release、process 和 link，不能替换未知进程或修改 Admin 数据。
- Claude Runtime、内置 Skill catalog、默认 Deck Plugin、crawler routes 与 rollback 都必须在新 Next.js release 形状上重新验证。

# backend/routers — Folder Contract

## Architecture Summary
FastAPI router modules for authenticated REST/SSE API boundaries.
Routers validate request ownership and delegate persistence/workspace behavior to database and service modules.
Business logic stays in focused backend modules rather than route handlers when reusable.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | router package init | Marks router modules as an importable package. |
| `admin.py` | admin route node | Register admin and scheduler-related endpoints. |
| `auth.py` | auth route node | Register login/register/import-data endpoints and auth flows. |
| `claude_agent.py` | claude-agent route node | Register `/api/claude-agent*` SSE, thread, session, and tool confirmation endpoints. |
| `deps.py` | shared dependency node | Provide shared auth/date/text dependencies for routers. |
| `friends.py` | friend route node | Register friend invite and relationship endpoints. |
| `pictures.py` | picture route node | Register daily picture generation/read endpoints. |
| `preferences.py` | preferences route node | Register user preference endpoints. |
| `reports.py` | reports route node | Register analysis report endpoints. |
| `sessions.py` | sessions route node | Register writing session CRUD endpoints. |
| `storage.py` | storage route node | Register file storage upload/download proxy endpoints. |
| `system_config.py` | system-config route node | Register user system/SDK config endpoints, including IM full-access approval mode. |
| `voices.py` | deck-and-voice route node | Register deck and voice management endpoints, including Memory config fields. |
| `workspace.py` | workspace route node | Register workspace file APIs (`/api/workspace/files*`). Memory init endpoint and `.claude/memory/` fallback both removed. |
| `reflections.py` | reflections route node | Register Reflections endpoints: `POST /api/reflections/memory-init` (section memory workspace init, user config priority), `GET/PUT/DELETE /api/reflections/config/{section}` (per-user prompt file customisation). |

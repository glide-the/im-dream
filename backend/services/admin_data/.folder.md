# Admin authentication/data consumers

## 架构概述

统一消费Admin OAuth和领域数据协议，无PG/SQL/fallback。现Product客户端绑定HS256与Product专属过滤，不能复用为全域transport；保留其业务DTO，接入时迁移authority。

| File | Pos | Function |
| --- | --- | --- |
| `__init__.py` | 包公开边界 | 导出配置、安全错误与OAuth verifier |
| `config.py` | server-owned配置 | 固定Admin origin/issuer/resource/service secret和timeout/JWKS/响应大小 |
| `models.py` | wire DTO | strict Pydantic principal/capabilities/browser-session/receipt，canonical ID保持string |
| `client.py` | 唯一transport | 独立service ID/credential与用户Bearer；注册领域DTO、capability匹配、无自动重试、未知提交/receipt恢复 |
| `errors.py` | 错误边界 | 不保存HTTP request/token/body，区分未知提交 |
| `jwt_verifier.py` | Resource Server | PyJWT ES256/at+jwt/时间/issuer/audience/scope；有界JWKS缓存刷新；不猜canonical用户ID |
| `resource_models.py` | Resource policy DTO | strict desired/state union，精确安全整数/组合字节，RootModel 保持原 wire JSON |
| `resource_data.py` | Resource domain adapter | Admin 实际双向 contract hash；composition root 后台 reader/observer；unknown 原 request_id 回执恢复 |

资源操作 input/output 版本均为1；pins来自Admin实际 [operation artifact](../../../docs/architecture/admin-auth-data-interaction.md)。缺广告/hash不匹配/网络或响应错误 fail closed；provider保留LKG。observer未知写尚无committed回执时阻止后续snapshot写入，不能认为absent意味着失败。历史 `resource_postgres_sink` 名称继续作为内部标识，已无SQL；不借文档清理更改Agent接口。

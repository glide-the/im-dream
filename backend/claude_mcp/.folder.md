# backend/claude_mcp — Folder Contract

## Architecture Summary

Owns Dream's database-managed MCP resource boundary. Online list/get/CRUD read the
Admin-published PostgreSQL schema through actor-scoped UoWs and exact capability
hash validation. Discovery uses the standard Python MCP SDK directly over
Streamable HTTP, SSE, or server-owned stdio profiles. OAuth protocol state remains
inside the SDK and persists only AES-256-GCM envelopes. Runtime snapshots are
detached in-memory projections for Agent SDK injection; they never write config
files or log credentials. Legacy CLI driver/parser/identity modules remain isolated
compatibility/import evidence and are not referenced by normal managed paths.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | package boundary | Export managed service and shared default-service/snapshot-loader accessors. |
| `contracts.py` | DTO/domain contract | Define managed transports, scopes, CRUD/CAS inputs, safe states, and closed error codes. |
| `repository.py` | PostgreSQL repository | Consume the exact Admin capability with actor/workspace ownership, CAS, encrypted credential, snapshot, and import-receipt UoWs；只缓存精确验证成功的 capability，缺失、漂移或瞬时查询失败均保持可重试；never issues DDL. |
| `crypto.py` | credential envelope | Encrypt/decrypt bounded credentials with AES-256-GCM and actor/server/kind/version AAD. |
| `inventory.py` | protocol discovery | Use standard MCP ClientSession clients with declared-capability discovery, same-session bounded tools/resources/prompts pagination, bounded Server concurrency, timeout, partial success, single-flight, and revision cache；交互式 OAuth 使用独立、可直接取消且不与普通 inventory single-flight 混用的 SDK session。 |
| `oauth.py` | SDK OAuth adapter | Reuse OAuthClientProvider and TokenStorage with process-local callback/cancel operations and encrypted persistence；首轮 callback 前只在 operation 内暂存 client registration，拿到 Token 后才与 SDK 已验证的 authorization metadata 共同加密落库；从数据库恢复绝对过期时间与 token endpoint，使 SDK 在进程重启后仍走自身 refresh 流程；浏览器等待使用 OAuth operation timeout，不继承 inventory item/request 短超时。 |
| `runtime_snapshot.py` | Agent injection seam | Project enabled user/current-workspace rows to a redacted in-memory `mcp_servers` mapping；workspace keys override user keys；过期 OAuth 先经有界 standard-MCP discovery 刷新并持久化，失败则拒绝注入旧 bearer。 |
| `service.py` | application orchestration | Expose actor-scoped managed capability, CRUD, discovery, OAuth/logout, and the process singleton shared by Router and Chat. |
| `importer.py` | offline cutover adapter | Read an explicit bounded legacy JSON file once, preserve a boolean OAuth intent, reject normalized secret/stdio argv fields, and write canonical no-overwrite receipts. |
| `settings.py` | policy configuration | Resolve discovery, cache, concurrency, OAuth, stdio-profile, and retained importer bounds without deployment-name branching. |
| `driver.py`, `parser.py`, `identity.py`, `credentials.py`, `keychain.py` | legacy compatibility | Retained for explicit migration/compatibility tests only; normal managed API/service/discovery/snapshot paths do not import them. |

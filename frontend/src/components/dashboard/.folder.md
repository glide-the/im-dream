# frontend/src/components/dashboard - Folder Contract

## Architecture Summary
Dashboard components for chat-adjacent navigation, file access, quick actions, model settings, and legacy sidebar surfaces.
These components should reuse existing chat icons, design tokens, and parent-owned callbacks instead of owning route state.
Vertical navigation currently exposes a theme-adaptive collapsible chat rail for files, chat history, and workspace controls; Settings is owned by top/mobile app navigation.

## File Table

| File | Pos | Function |
|---|---|---|
| `FileSidebar.tsx` | `file-sidebar component node` | Render file workspace sidebar UI and file list/actions for a session. |
| `ModelConfigSection.tsx` | `settings-model-config component node` | Render Settings page AI model/theme/system-prompt/workspace/full-access controls and API interactions; emits same-tab full-access changes. |

| `const.ts` | `dashboard-constants node` | Define dashboard quick action card data. |

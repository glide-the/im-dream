# 分析历史与时间轴

## 背景与问题

AnalysisView 已有三张预览的显示边界，但只读取最近十份已保存报告，并把无 task link 的同日报告合并。历史回顾标题没有导航操作。CollectionsView 内的 TimelinePage 只读取日记和历史图片，并按日历日虚拟滚动；没有分析报告数据。

现有 `analysis-report.list` 按报告保存时间排序，只有 limit，容量由 Admin 配置限制。任务完成、重试保存时间可能与任务创建时间不同，扩大 limit 不能保证完整历史或正确排序。旧设计的按日合并规则保留为历史，现行规则以本文为准。

## 目标与边界

分析首页最多展示按真实分析创建时间倒序排列的三份已保存报告；同一天的独立分析不合并。历史回顾是键盘可激活的现有时间轴导航入口，空态和失败时也保留。

TimelinePage 在原日记、图片时间轴中加入分析卡片，支持读取超过三份及全部更早报告。使用现有报告阅读组件，在时间轴内打开并返回原位置。刷新或重新进入遵循现有页面合同：重新读取历史，报告阅读状态是本地状态，刷新回到时间轴。

不增加筛选器、另一个历史页面、配置中心、确认弹窗、后台控制或模型调用；不改账户、历史正文、任务状态机或数据库 schema。

## 概念与规则

| 对象 | 规则 |
| --- | --- |
| 已保存任务报告 | 一份 `analysis_reports` 记录对应一张卡片；服务端通过已有 `reflection_task_id` 关联本账户 task，使用 `reflection_task.created_at` |
| 无任务关联的旧分析 | 使用其 `analysis_reports.created_at`，这是现有分析记录自己的创建时间；不根据 JSON 内任意 task_id 猜关联 |
| 时间错误 | 关联任务缺失或创建时间缺失时返回读取错误；不使用 updated_at、completed_at、日记日期、分析范围或浏览器当前时间替代 |
| 同时刻 | 数据库以分析创建时间倒序、报告 bigint id 倒序作为稳定顺序；前端保留字符串 id，不丢失精度 |
| 首页 | 读取原默认一页作为既有栏目结果来源，历史区域只显示最多三张；不合并同一天的结果 |
| 时间轴 | 沿原“较早在上、最新在下”的顺序，将分析独立卡片插入创建日期；同日多份逐张可打开；日期和时间采用账户时区及既有语言规则 |
| 分页 | 追加只读 `analysis-report.history-page`，输入 limit 和上一页末尾的创建时间/id 游标；读取 limit+1 判定是否还有记录，没有日期上限；旧 list/save 描述保持原样 |
| 完成和失败 | 只列已经保存的报告；部分失败报告保留成功栏目及失败信息；进行中任务和无结果失败任务不制造历史报告 |
| 加载与重试 | 首页有加载、空、失败及重试；时间轴首次及更多记录失败可重试，加载更多失败保留已读记录和原游标，不重复或跳过记录 |
| 返回与重入 | 阅读关闭回到相同时间轴位置及原卡片焦点；重新进入/刷新重新请求第一页，浏览器返回由现有 Story Workspace 路由处理 |
| 可访问性 | 标题入口和报告卡片为原生按钮，有可访问名称，Enter/Space 可激活；窄屏单列、页面不横向溢出；时间轴保持原有单一滚动容器 |

### 桌面页面骨架

```text
Story Workspace 侧栏 | AnalysisView（页面垂直滚动）
                      | 统计、[历史回顾 → 时间轴]
                      | [报告1] [报告2] [报告3]（创建日期、栏目数量）
                      | 加载 / 空 / 读取失败 [重试]
                      | 生成分析 / 分析内容 / 栏目配置（原入口）

侧栏 | TimelinePage（原滚动容器，较早在上，最新在下）
     | [加载更早分析] / 加载或失败 [重试]
     | 创建日期 —— 分析卡片（时间、栏目数量、内容摘要）
     | 日历日期 —— 原日记/图片卡片
     | 创建日期 —— 同日的另一份分析卡片
     | 点击分析 → ReflectionBlogPage（原栏目和详情阅读）
     |              [返回] → 原时间轴位置和卡片焦点
```

### 窄屏页面骨架

```text
侧栏沿原移动导航规则
┌ AnalysisView（纵向滚动）────────┐
│ 统计 / [历史回顾 → 时间轴]     │
│ [最新报告]                     │
│ [第二份报告]                   │
│ [第三份报告]                   │
│ 原生成入口 / 原分析内容面板     │
└────────────────────────────────┘
┌ TimelinePage（同一纵向滚动）───┐
│ [加载更早分析] / 失败 [重试]   │
│ 日期、时间、报告摘要           │
│ [分析卡片 → 阅读报告]          │
│ 原日记/图片卡片                │
│ 同日其他分析卡片               │
└────────────────────────────────┘
报告使用原窄屏栏目按钮和详情布局；返回恢复时间轴。
```

正式时序、状态和验收见 [交互设计](../../design/memory/reflections-history-design.md)。判断与评审见 [执行记录](../../exec/reflections-history-20261014.md)。

# deploy/

## 架构概述
平台化发布脚本入口，按 local、docker、google-cloud 分目录组织；根目录保留旧 Cloud Run 脚本兼容路径。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| README.md | 脚本入口说明 | 三类平台脚本入口、旧 Cloud Run 脚本兼容映射、通用参数约定 |
| local/ | 本地发布脚本 | 本地直跑检查、构建、启动、验证、停止和清理入口 |
| docker/ | Docker 发布脚本 | Docker Compose 检查、构建、启动、验证、停止和清理入口 |
| google-cloud/ | Google Cloud 发布脚本 | Cloud Run 目录化入口，包装旧根脚本并提供 dry-run/check/verify/rollback |
| setup-storage.sh | 兼容：存储初始化 | 创建 GCS bucket、服务账号 `ink-backend-sa`、IAM 授权；输出根目录 `.storage-env` |
| setup-env.sh | 兼容：环境变量初始化 | 读 `backend/.env`，指定 key 写入 Secret Manager，其余配置汇总；输出根目录 `.cloud-env` |
| deploy.sh | 兼容：Cloud Run 部署 | 并行构建+推送镜像；顺序部署后端（GCS 卷+Secret refs+env vars）和前端（注入 BACKEND_URL） |
| sync-data.sh | 兼容：云数据同步 | 上传本地 SQLite 数据文件到 GCS，并用完整 Cloud Run 配置触发后端重启 |

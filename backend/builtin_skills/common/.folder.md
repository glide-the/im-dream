# backend/builtin_skills/common — Folder Contract

## Architecture Summary

Platform-independent builtin Skill namespace. Every full thread workspace
selects these packages; directory packages are exposed through exact read-only
source symlinks and keep their canonical flat Skill IDs at Runtime.

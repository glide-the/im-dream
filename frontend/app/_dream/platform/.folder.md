# frontend/app/_dream/platform

## Architecture Summary

This folder owns the browser side of the versioned mobile host protocol. It validates envelopes, correlates request identifiers, handles cancellation and events, and keeps iOS/Android global objects out of product components.

## File Table

| File | Position | Function |
| --- | --- | --- |
| `mobileHost.ts`、`mobileHost.test.ts` | RN宿主显示与导航 | 依据只读宿主标志过滤移动排除路径，并仅报告路径和登录布尔值；Web路由与业务协议保持。 |
| `mobileHost.css` | RN布局适配 | 仅在RN宿主内取消网页底栏预留，并让Writing填满业务WebView。 |
| `mobileBridge.ts` | native-host transport adapter | Detect WKWebView or Android WebMessage host, validate generation-aware v1 messages, and expose allowlisted typed calls/events. |
| `mobileBridge.test.ts` | deterministic contract test | Verify correlation, stale-generation rejection, cancellation, and ordered event delivery. |
| `mobileRuntimeTransport.ts` | local runtime fetch adapter | Open allowlisted relative Dream requests, validate bounded response chunks, and expose pull-based streams with pre/post-head cancellation. |
| `mobileRuntimeTransport.test.ts` | provider-free transport test | Verify scoped routing, response validation, URL/credential gates, and pre-head/reader cancellation. |

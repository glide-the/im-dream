# mobile/

## Architecture Summary

`mobile/` owns the iOS and Android application containers plus the protocol used to request operating-system capabilities. It does not own a second Ink & Memory business UI or a second Dream business service.

The hosts retain the canonical React source under `frontend/app/_dream`. iOS mounts the RN App entry and retains the original WKWebView as one persistent business surface. Its independent path runs original Next standalone and the same Python ASGI app inside the application; Android retains its generated-resource scaffold. The hosts expose an allowlisted bridge and own operating-system UI and lifecycle integration. `backend/mobile_runtime` owns the Python-side protocol adapter and qualification probes.

## File Table

| Path | Position | Function |
| --- | --- | --- |
| `README.md` | mobile workspace entry | Explain build order, source ownership, current capability gates, and validation commands. |
| `shared/bridge/contract.json` | bridge protocol source | Define protocol version, allowlisted methods, events, ownership, and stable error codes. |
| `scripts/check-bridge-contract.mjs` | deterministic contract check | Reject duplicate names, unsafe generic capabilities, invalid identifiers, and method/event inventory drift; payload schema generation remains future work. |
| `scripts/check-web-assets.mjs` | resource integrity check | Recompute generated file size and SHA-256 values and compare the exact asset manifest. |
| `ios/` | iOS native host | Swift/WKWebView application, lifecycle and system capability adapters, and explicit Python/Claude qualification state. |
| `react-native/` | RN应用入口 | 启动、一级导航、More、恢复反馈与持久业务表面；当前接入iOS原工程。 |
| `android/` | Android native host | Kotlin/WebView application with the same protocol and Android-specific lifecycle/system adapters. |

## Boundaries

- A platform method must correspond to a current mobile user task.
- JavaScript receives opaque file handles. Native filesystem paths remain inside the host.
- The bridge does not expose arbitrary shell, eval, native-class dispatch, credentials, or unrestricted filesystem methods.
- `runtime.request`, `runtime.response.read`, and `runtime.cancel` are reserved for a qualified local Dream Python runtime. A host without that runtime returns `CAPABILITY_UNAVAILABLE`.
- Generated files under `shared/build/` are build artifacts and remain outside Git.

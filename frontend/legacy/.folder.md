# 旧容器归档

`ios-tests/`保留依赖已退役InkBusinessSurface的整页路由测试原文；该测试退出当前RN编译和验收，当前原生整页及真实业务验收继续实施。

`mobile-container/`保留原mobile目录剩余文件与独立RN依赖记录；`container-app/`保留整页WebView RN界面；`mobile-web-entry/`、`build-mobile-assets.mjs`、`build-web-assets.sh`、`tsconfig.mobile.json`保留旧静态网页构建；`android-webview/`保留旧Activity及Gradle配置。主构建不消费这些入口，禁止按旧包结果声明RN业务验收。

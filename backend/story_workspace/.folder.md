# backend/story_workspace/

## 架构

Story Workspace 的稳定领域合同与纯领域辅助类。该目录不拥有 Claude Agent runtime、SSE、Workflow 状态机或数据库迁移。

## 文件

| 文件 | 职责 |
|---|---|
| `contracts.py` | Story Workspace 严格存储/响应 DTO 与 Artifact 合同；Story Index 明确区分 Project/Episode 标题，Dream re-entry 返回生命周期一致的初始/进行中 outcome |
| `dream_workbench_context.md` | Dream 工作台的 Agent 可读静态业务合同；随 Dream surface 初始化部署，不包含运行态身份 |
| `dream_asset_collaboration.md` | Agent 通过自然语言增删改人物、场景、分镜时的唯一文件操作、稳定 ID 与引用完整性合同 |
| `dream_workbench_context.py` | 初始化/刷新 `.dream/WORKBENCH.md` 和 `.dream/ASSET-COLLABORATION.md`，并为每个 Dream turn 渲染实际路径上下文 |

## 约束

- 2026-08-26：Dream re-entry 对已授权但 Thread workspace 已缺失的历史 Run 逐项隔离，仅省略该条 artifact 投影；不创建替代目录，权限、符号链接、路径、合同和 I/O 错误继续 fail closed。
- Dream 与 Chat 共用 ClaudeAgentService、thread、session 和 SSE。
- Dream re-entry 只有初始/进行中：生成或等待确认是初始，确认后的执行或最近活动是进行中；Workflow 终态不得扩展成 Dream 页面第三种状态。
- Workbench 与 asset collaboration context 只提供服务端可信业务定位/操作合同，不是第二状态源，也不进入公开 Claude Agent DTO；静态正文由 Markdown 源文件维护，Python 不复制第二份规则。
- Skill 任意执行；Hook 按文件事实同步；Observer 只做非控制型投影。
- Dream 展示标题只有一个解析顺序：已有 Project 时读取 Story Index `projectTitle`；Project 尚未构建时才读取创作目标前 80 个字符。Execution、Dream 回访列表和 Admin 列表必须一致。
- Episode 标题继续来自 Episode artifact；Project 展示标题不得被 Episode、Deck、workflow summary 或页面局部状态覆盖。
- Dream stage 的 `summary` 只服务列表；成功根 turn 的 Hook 同 revision 发布可选完整资产
  `content`，Execution 聚焦页据此阅读人物/场景全部文档。页面不得绕过 Hook 直读 canonical
  文件，旧 stage 缺少正文时回退摘要。

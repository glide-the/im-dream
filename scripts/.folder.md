# scripts — Folder Contract

## Architecture Summary

Scripts here are explicit entry points for validation and maintenance. They must identify any database or process they own before writing or cleanup. Production schema migrations remain in the Admin Drizzle repository; Dream scripts cannot create runtime schema or use a test database as normal business data.

# deploy/remote-ssh/

## 架构概述
Remote SSH 发布脚本目录，用于把仓库同步到已安装 Docker 和 `docker-compose` 的远程服务器，并在远端运行专用 Compose 栈。

## 文件清单

| File | Pos | Function |
|------|-----|----------|
| deploy.sh | Remote SSH 发布入口 | 检查本地 SSH/rsync 与远端 docker-compose，rsync 同步源码和配置，在远端执行 Compose 构建、启动、验证、日志、清理和上一版镜像回滚；默认创建远端 `backend/data`、`file-storage`、`agent-workspace`；向 nginx setup 传递前后端 host 端口 |
| docker-compose.yml | 远端 Compose 模板 | 复用 backend/frontend Dockerfile；默认资源规格对齐 Cloud Run，后端仅绑定远端本机端口，前端暴露 HTTP；显式设置后端容器内部 `PORT`，避免与 host 映射端口脱节；文件存储和 Agent 工作区使用远端服务器文件系统 |
| setup-nginx.sh | Host 级 nginx 安装脚本 | 通过 SSH/SCP 在远端服务器安装 nginx、部署按 `REMOTE_BACKEND_PORT` / `REMOTE_FRONTEND_PORT` 渲染后的 `nginx/ink-and-memory.conf` 虚拟主机配置、启用站点；SSH 端口传给 `ssh -p` 与 `scp -P`；安装/启动前检查主机 `80` 端口，非 nginx 占用时中止，已有 nginx 占用时刷新配置并 reload；自动备份并禁用同域名旧 nginx 配置；支持 `WITH_SSL=1` 自动申请 Let's Encrypt 证书；使用前须设置 `REMOTE_SSH_HOST` |
| nginx/ink-and-memory.conf | Host 级 nginx 反向代理配置 | 默认按域名路由：`ink-backend.suoxya.com` → `127.0.0.1:8765`，`ink-frontend.suoxya.com` → `127.0.0.1:8080`；由 `setup-nginx.sh` 在部署时按 Remote SSH 端口环境变量渲染；含 WebSocket 升级、SSE 长连接、SSL 模板 |

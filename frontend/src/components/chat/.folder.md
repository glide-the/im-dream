# frontend/src/components/chat - Folder Contract

## Architecture Summary
Chat workspace UI components for input, messages, tool output, modal/toast feedback, and the composed chat view.
`ChatView.tsx` owns thread/file sidebar state and delegates message streaming to `ChatPanel.tsx`.
Settings navigation is not owned by this folder; app-level top/mobile navigation owns that route entry.

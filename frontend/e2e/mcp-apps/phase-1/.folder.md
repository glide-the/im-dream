# frontend/e2e/mcp-apps/phase-1

## Purpose

This directory owns the provider-free Phase 1-3 browser lane for MCP Apps. It mounts the real `ToolMessagePart` → `McpAppHostPanel` → `ImMcpAppHostAdapter` tree, adapts the real Next Route Handlers in isolated Vite processes, and uses unmodified official current/previous AppServer artifacts. It never invokes a model or touches real Ink & Memory business data.

## Files

| File | Role |

| `official-phase1-3.spec.ts` | Current/previous official protocol matrix plus the 1.7.5 Browser security, workspace scope, Phase-1 call-bypass, independent policy/plugin revision, message-ingress, refresh, standard DELETE, and zero-leak lifecycle journey. |

## Runtime contract

- `INK_MCP_APPS_OFFICIAL_ARTIFACT_CURRENT` must be the absolute prepared 1.7.5 artifact root.
- `INK_MCP_APPS_OFFICIAL_ARTIFACT_PREVIOUS` must be the absolute prepared 1.7.4 artifact root.
- All listeners use ephemeral loopback ports, and teardown stops only processes and servers created by the current test.
- The Vite-only HTTP adapter treats exact `AbortError`/`aborted` MCP long-poll cancellation as normal transport teardown so its development overlay cannot mask product UI assertions.
- Screenshots are written only below gitignored `frontend/output/playwright/`.

# frontend/src/constants — Folder Contract

## Architecture Summary
Frontend source-of-truth constants for cross-module behavior.
Keeps storage keys and session sync timing values centralized instead of scattering literals in feature code.

| File | Pos | Function |

| `sessionSync.ts` | `edit-session sync constants node` | Central timing values for Edit Session auto-save debounce, SSE reconnect, Agent write fallback reload, and completed toolCallId cache cleanup. |
| `deck.ts` | `Deck presentation constants node` | Own the fourteen-item enabled launch projection, Deck list pagination, and original create-flow visual defaults. |

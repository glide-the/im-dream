# frontend/e2e — Folder Contract

## Architecture Summary

Playwright business-journey specifications for the production frontend entry
points. Provider-free tests use production-shaped API fixtures and strict
unexpected-request/browser-diagnostic audits; explicitly named real tests use
their documented PostgreSQL, Gateway, and model harnesses.

## File Table

| File | Pos | Function |
|---|---|---|
| `story-workspace-default-entry.spec.ts` | authenticated-entry journey | Prove root password login enters canonical Story Workspace Chat, exposes exactly Chat/Dream/Decks in order, applies the default font, and survives refresh. |
| `chat-first-deck-defaults.spec.ts` | Deck-default journey | Prove Chat-first login, screenplay-only Deck visibility, five creative roles, zero-ref default-team repair, atomic new-Deck `drama-forge` `1.0.1` selection, editable refs, refresh persistence, and zero unexpected diagnostics. |
| `story-workspace-real-default-deck-plugin.spec.ts` | opt-in real default-account journey | Use the existing local account and normal Decks UI/API to prove the default screenplay team persists and renders an enabled ready `drama-forge` `1.0.1` ref. |
| `deck-dream.spec.ts` | Deck-to-Dream journey | Exercise Deck selection and Dream handoff behavior. |
| `dream-*.spec.ts` | Dream journeys | Cover provider-free and explicitly named PostgreSQL/real-model Dream flows. |
| `story-workspace-*.spec.ts` | Story Workspace journeys | Cover subscription, execution, artifact, title, skill, and workbench behavior. |
| `model-settings-gateway*.spec.ts` | model settings journeys | Cover mocked and real Gateway model selection behavior. |
| `registration-defaults-postgres-real.spec.ts` | isolated full-stack registration journey | Cover canonical registration, Free defaults bootstrapped from a priced model without prior entitlement, Admin model selection, and first Agent call through the dedicated harness. |
| `fixtures/` | browser harness fixtures | Provide reusable Story Workspace and model-settings harnesses. |
| `helpers/` | E2E helper scripts | Read or prepare bounded test facts for explicitly scoped workflows. |

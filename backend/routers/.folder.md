# backend/routers — Folder Contract

## Architecture Summary
FastAPI router modules for authenticated REST/SSE API boundaries.
Routers validate request ownership and delegate persistence/workspace behavior to database and service modules.
Business logic stays in focused backend modules rather than route handlers when reusable.

## File Table

| File | Pos | Function |
|---|---|---|
| `__init__.py` | router package init | Marks router modules as an importable package. |
| `admin.py` | admin route node | Register admin and scheduler-related endpoints. |
| `auth.py` | auth route node | Register login/register/import-data endpoints plus `/auth/me` and `/auth/logout` aliases for OAuth-capable clients. |
| `claude_agent.py` | claude-agent route node | Register `/api/claude-agent*` SSE, thread, session, stop, and tool confirmation endpoints; attachment workspace initialization uses Settings-backed sandbox mode only when Workspace Mode is enabled. |
| `deps.py` | shared dependency node | Provide shared auth/date/text dependencies for routers; current-user auth accepts Bearer tokens or system auth cookies. |
| `device_oauth.py` | device-oauth route node | Register OAuth 2.0 Device Authorization Grant endpoints: `/oauth/device/code`, `/oauth/device/verify`, and `/oauth/token`. |
| `friends.py` | friend route node | Register friend invite and relationship endpoints. |
| `pictures.py` | picture route node | Register daily picture generation/read endpoints. |
| `preferences.py` | preferences route node | Register user preference endpoints. |
| `reports.py` | reports route node | Register analysis report endpoints. |
| `sessions.py` | sessions route node | Register writing session CRUD endpoints plus authenticated `/api/sessions/events` SSE for Edit Session update/delete notifications. |
| `storage.py` | storage route node | Register file storage upload/download proxy endpoints. |
| `system_config.py` | system-config route node | Register user system/SDK config endpoints, including IM full-access approval mode and sandbox network policy; `PUT` returns merged config data for Settings hydration after save. |
| `voices.py` | deck-and-voice route node | Register deck and voice management endpoints, including Memory config fields. |
| `workspace.py` | workspace route node | Register workspace file APIs (`/api/workspace/files*`) including RFC 8187-safe download headers and Settings-backed workspace sandbox initialization. Memory init endpoint and `.claude/memory/` fallback both removed. |
| `reflections.py` | reflections route node | Register Reflections endpoints: `POST /api/reflections/memory-init` (section memory workspace init, user config priority), `GET/PUT/DELETE /api/reflections/config/{section}` (per-user prompt file customisation). |
| `oauth.py` | google-oauth route node | Register Google OAuth/OIDC login and callback routes backed by Authlib and local system token issuance. |
